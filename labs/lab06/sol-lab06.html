  • 面向对象编程的主要目标是什么？
  • 类在使用与数据实现之间建立了抽象屏障。类作为所有该类型对象的模板，你可以创建多个对象来存储不同的数据。

面向对象编程

这里有一段面向对象编程的复习。如果你卡住了，可以直接跳到问题，需要时再回来参考。

面向对象编程（OOP）使用对象和类来组织程序。下面是一个类的例子：

class Car:
    max_tires = 4

    def __init__(self, color):
        self.tires = Car.max_tires
        self.color = color

    def drive(self):
        if self.tires < Car.max_tires:
            return self.color + ' car cannot drive!'
        return self.color + ' car goes vroom!'

    def pop_tire(self):
        if self.tires > 0:
            self.tires -= 1

类：一个对象的类型。Car 类（如上所示）描述了所有 Car 对象。

对象：类的一个单一实例。在 Python 中，新对象通过调用一个类来创建。

>>> ferrari = Car('red')

这里，ferrari 是一个绑定到 Car 对象的名字。

类属性：属于一个类并通过点号访问的变量。Car 类有一个 max_tires 属性。

>>> Car.max_tires
4

实例属性：属于某个特定对象的变量。每个 Car 对象有一个 tires 属性和一个 color 属性。与类属性一样，实例属性通过点号访问。

>>> ferrari.color
'red'
>>> ferrari.tires
4
>>> ferrari.color = 'green'
>>> ferrari.color
'green'

方法：属于一个对象并通过点号调用的函数。按照惯例，方法的第一个参数是 self.

当对象的某个方法被调用时，该对象会隐式作为 self 的参数传入。例如，drive 类的 ferrari 对象以空括号被调用，因为 self 被隐式绑定到 ferrari 对象的名字。

>>> ferrari = Car('red')
>>> ferrari.drive()
'red car goes vroom!'

我们也可以调用原始的 Car.drive 函数。原始函数不属于任何特定的 Car 对象，因此我们必须为 self.

>>> ferrari = Car('red')
>>> Car.drive(ferrari)
'red car goes vroom!'

__init__：当创建类的新实例时自动调用的特殊函数。

注意 drive 方法接收 self 作为参数，但我们好像没有传入！这是因为点号 隐式地 传入了 ferrari 作为 self 给我们。所以在这个例子中，self 被绑定到全局帧中名为 ferrari 的对象。

要计算表达式 Car('red')，Python 会创建一个新的 Car 对象。然后，Python 调用 __init__ 的 Car 类的 self，其中 color 绑定到新对象，'red'.

Q1：银行账户

扩展 BankAccount 类以包含一个 transactions 属性。该属性应是一个列表，用于记录该账户上的每笔交易。每当 deposit 或 withdraw 方法被调用时，应创建一个新的 Transaction 实例并加入列表，即使操作未成功.

一个 Transaction 类的实例应具有以下属性：

  • before：交易前的账户余额。
  • after：交易后的账户余额。
  • id：交易 ID，即该账户上之前发生的交易（存款或取款）数量。某个特定 BankAccount 实例的交易 ID 必须唯一，但此 id 不必在所有账户间唯一。换句话说，你只需确保同一个 Transaction 创建的 BankAccount 对象不会拥有相同的 id.

此外，Transaction 类应具有以下方法：

  • changed()：返回 True，如果余额发生变化（即 before 与 after 不同），否则返回 False.
  • report()：返回一个描述该交易的字符串。该字符串应以交易 ID 开头，并描述余额的变化。请查看 doctests 以了解预期输出。
class Transaction:
    def __init__(self, id: int, before: int, after: int):
        self.id = id
        self.before = before
        self.after = after

    def changed(self) -> bool:
        """Return whether the transaction resulted in a changed balance."""

        return self.before != self.after

    def report(self) -> str:
        """Return a string describing the transaction.

        >>> Transaction(3, 20, 10).report()
        '3: decreased 20->10'
        >>> Transaction(4, 20, 50).report()
        '4: increased 20->50'
        >>> Transaction(5, 50, 50).report()
        '5: no change'
        """
        msg: str = 'no change'
        if self.changed():

            if self.after < self.before:
                verb = 'decreased'
            else:
                verb = 'increased'
            msg = verb + ' ' + str(self.before) + '->' + str(self.after)
        return str(self.id) + ': ' + msg

class BankAccount:
    """A bank account that tracks its transaction history.

    >>> a = BankAccount('Eric')
    >>> a.deposit(100)    # Transaction 0 for a
    100
    >>> b = BankAccount('Erica')
    >>> a.withdraw(30)    # Transaction 1 for a
    70
    >>> a.deposit(10)     # Transaction 2 for a
    80
    >>> b.deposit(50)     # Transaction 0 for b
    50
    >>> b.withdraw(10)    # Transaction 1 for b
    40
    >>> a.withdraw(100)   # Transaction 3 for a
    'Insufficient funds'
    >>> len(a.transactions)
    4
    >>> len([t for t in a.transactions if t.changed()])
    3
    >>> for t in a.transactions:
    ...     print(t.report())
    0: increased 0->100
    1: decreased 100->70
    2: increased 70->80
    3: no change
    >>> b.withdraw(100)   # Transaction 2 for b
    'Insufficient funds'
    >>> b.withdraw(30)    # Transaction 3 for b
    10
    >>> for t in b.transactions:
    ...     print(t.report())
    0: increased 0->50
    1: decreased 50->40
    2: no change
    3: decreased 40->10
    """

    # *** 你需要在该类的多个地方进行修改 ***

    def next_id(self) -> int:
        # 实现这个计数器有很多种方式，例如使用一个实例
        # 属性来跟踪下一个 ID。
        return len(self.transactions)

    def __init__(self, account_holder: str):
        self.balance: int = 0
        self.holder = account_holder

        self.transactions = []

    def deposit(self, amount: int) -> int:
        """Increase the account balance by amount, add the deposit
        to the transaction history, and return the new balance.
        """

        self.transactions.append(Transaction(self.next_id(), self.balance, self.balance + amount))
        self.balance = self.balance + amount
        return self.balance

    def withdraw(self, amount: int) -> int | str:
        """Decrease the account balance by amount, add the withdraw
        to the transaction history, and return the new balance.
        """
        if amount > self.balance:

            self.transactions.append(Transaction(self.next_id(), self.balance, self.balance))
            return 'Insufficient funds'

        self.transactions.append(Transaction(self.next_id(), self.balance, self.balance - amount))
        self.balance = self.balance - amount
        return self.balance

Q2：电子邮件

一个电子邮件系统包含三个类：Email、Server，否则返回 Client。一个 Client 可以 compose 一封电子邮件，并将其 send 的名字映射到对应的 Server。Server 随后将其投递到 inbox 的另一个 Client。为此，一个 Server 拥有一个名为 clients 的字典，它将 Client 的名字映射到对应的 Client 实例。

假设一个 Client 从不改变它所使用的 Server，并且它只能使用该 Email 来撰写一封 Server.

填写下面的定义以完成实现！Email 类已经为你完成。

重要：在开始之前，请确保阅读整个代码片段，以理解各类之间的关系，并注意方法的参数类型。思考在每个方法中你可以访问哪些变量，以及如何利用它们来访问其他类及其方法。

注意：

  • 该sender 参数来自 __init__(self, msg, sender, recipient_name) 类的 Email 方法，它是一个 Client 实例。
  • 该client 参数来自 register_client(self, client) 类的 Server 方法，它是一个 Client 实例。
  • 该email 参数来自 send(self, email) 类的 Server class is an Email 实例。
class Email:
    """An email has the following instance attributes:

        msg (str): the contents of the message
        sender (Client): the client that sent the email
        recipient_name (str): the name of the recipient (another client)
    """
    def __init__(self, msg: str, sender, recipient_name: str):
        self.msg = msg
        self.sender = sender
        self.recipient_name = recipient_name

class Server:
    """Each Server has one instance attribute called clients that is a
    dictionary from client names to client objects.

    >>> s = Server()
    >>> # Dummy client class implementation for testing only
    >>> class Client:
    ...     def __init__(self, server, name):
    ...         self.inbox = []
    ...         self.server = server
    ...         self.name = name
    >>> a = Client(s, 'Alice')
    >>> b = Client(s, 'Bob')
    >>> s.register_client(a) 
    >>> s.register_client(b)
    >>> len(s.clients)  # we have registered 2 clients
    2
    >>> all([type(c) == str for c in s.clients.keys()])  # The keys in self.clients should be strings
    True
    >>> all([type(c) == Client for c in s.clients.values()])  # The values in self.clients should be Client instances
    True
    >>> new_a = Client(s, 'Alice')  # a new client with the same name as an existing client
    >>> s.register_client(new_a)
    >>> len(s.clients)  # the key of a dictionary must be unique
    2
    >>> s.clients['Alice'] is new_a  # the value for key 'Alice' should now be updated to the new client new_a
    True
    >>> e = Email("I love 61A", b, 'Alice')
    >>> s.send(e)
    >>> len(new_a.inbox)  # one email has been sent to new Alice
    1
    >>> type(new_a.inbox[0]) == Email  # a Client's inbox is a list of Email instances
    True
    """
    def __init__(self):
        self.clients = {}

    def send(self, email: Email):
        """Append the email to the inbox of the client it is addressed to.
            email is an instance of the Email class.
        """

        self.clients[email.recipient_name].inbox.append(email)

    def register_client(self, client):
        """Add a client to the clients mapping (which is a 
        dictionary from client names to client instances).
            client is an instance of the Client class.
        """

        self.clients[client.name] = client

class Client:
    """A client has a server, a name (str), and an inbox (list).

    >>> s = Server()
    >>> a = Client(s, 'Alice')
    >>> b = Client(s, 'Bob')
    >>> a.compose('Hello, World!', 'Bob')
    >>> b.inbox[0].msg
    'Hello, World!'
    >>> a.compose('CS 61A Rocks!', 'Bob')
    >>> len(b.inbox)
    2
    >>> b.inbox[1].msg
    'CS 61A Rocks!'
    >>> b.inbox[1].sender.name
    'Alice'
    """
    def __init__(self, server: Server, name: str):
        self.inbox: list = []
        self.server = server
        self.name = name

        server.register_client(self)

    def compose(self, message: str, recipient_name: str):
        """Send an email with the given message to the recipient."""

        email = Email(message, self, recipient_name)
        self.server.send(email)

继承

两个类可能具有相似的属性，但其中一个是另一个的特殊情况。例如，一个 Nickel 是 Coin 的特殊情况。我们说 Nickel 是 Coin，否则返回 Coin 是 Nickel 的基类（或超类）。在 Python 中，class Nickel(Coin): 这一行建立了这种关系。

class Coin:
    cents = None  # This will be provided by subclasses, but not by Coin itself

    def __init__(self, year):
        self.year = year

class Nickel(Coin):
    cents = 5

（例如 Coin__init__) are also methods for Nickel。例如，每个 Nickel 实例有一个 year 属性。但在 Nickel 类中定义的类属性或方法会先被找到。

>>> c = Nickel(1990)
>>> c.year
1990
>>> c.cents
5

Q3：铸币厂

铸币厂是制造硬币的地方。在这个问题中，你将实现一个 Mint 类，它可以输出一个带有正确年份和价值的 Coin。

  • 每个 Mint 实例有一个 year 印记。该 update 方法将 year 实例的印记设置为 present_year 类的 Mint 类.
  • 该create 方法接收一个 Coin（不是 实例！），然后 创建并返回一个带有 Mint 的年份（如果尚未更新，可能不同于 Mint.present_year）的该子类的实例。
  • 一个 Coin 的 worth 方法返回 cents 硬币的价值，再加上超过 50 年后每多一年加一 分。硬币的年龄可以通过用 present_year 类的 Mint 类的年份减去硬币的年份来确定。
class Mint:
    """A mint creates coins by stamping on years.

    The update method sets the mint's stamp to Mint.present_year.

    >>> mint = Mint()
    >>> mint.year
    2025
    >>> dime = mint.create(Dime)
    >>> dime.year
    2025
    >>> Mint.present_year = 2105  # Time passes
    >>> nickel = mint.create(Nickel)
    >>> nickel.year     # The mint has not updated its stamp yet
    2025
    >>> nickel.worth()  # 5 cents + (80 - 50 years)
    35
    >>> mint.update()   # The mint's year is updated to 2105
    >>> Mint.present_year = 2180     # More time passes
    >>> mint.create(Dime).worth()    # 10 cents + (75 - 50 years)
    35
    >>> Mint().create(Dime).worth()  # A new mint has the current year
    10
    >>> dime.worth()     # 10 cents + (155 - 50 years)
    115
    >>> Dime.cents = 20  # Upgrade all dimes!
    >>> dime.worth()     # 20 cents + (155 - 50 years)
    125
    """
    present_year = 2025

    def __init__(self):
        self.update()

    def create(self, coin):

        return coin(self.year)

    def update(self) -> None:

        self.year = Mint.present_year

class Coin:
    cents = None # will be provided by subclasses, but not by Coin itself

    def __init__(self, year: int):
        self.year = year

    def worth(self) -> int:

        return self.cents + max(0, Mint.present_year - self.year - 50)

class Nickel(Coin):
    cents = 5

class Dime(Coin):
    cents = 10

Q4：下一个 Virahanka 斐波那契对象

实现 next 类的 VirFib 方法。对于这个类，其 value 属性是一个斐波那契数。该 next 方法返回一个 VirFib 实例， 其 value 是下一个斐波那契数。该 next 方法应只花费 常数时间。

注意在 doctests 中，并没有打印任何内容。相反，每次对 .next() 的调用都会返回一个 VirFib 实例。每个 VirFib 实例的显示方式由它的 __repr__ 方法之外也可以。

提示：通过在 next 内部设置一个新的实例属性来记录前一个数字， 。你可以在任何时候为对象创建新的实例属性， 即使在 __init__ 方法之外也可以。

class VirFib():
    """A Virahanka Fibonacci number.

    >>> start = VirFib()
    >>> start
    VirFib object, value 0
    >>> start.next()
    VirFib object, value 1
    >>> start.next().next()
    VirFib object, value 1
    >>> start.next().next().next()
    VirFib object, value 2
    >>> start.next().next().next().next()
    VirFib object, value 3
    >>> start.next().next().next().next().next()
    VirFib object, value 5
    >>> start.next().next().next().next().next().next()
    VirFib object, value 8
    >>> start.next().next().next().next().next().next() # Ensure start isn't changed
    VirFib object, value 8
    """

    def __init__(self, value: int = 0):
        self.value = value

    def next(self):

        if self.value == 0:
            result = VirFib(1)
        else:
            result = VirFib(self.value + self.previous)
        result.previous = self.value
        return result

    def __repr__(self) -> str:
        return "VirFib object, value " + str(self.value)

请记住 next 必须返回一个 VirFib 对象！基于此，我们的 首要目标是计算出下一个 VirFib 对象并将其返回。一种 方法是先确定基准情形（self.value == 0），然后决定 下一次调用 next.
