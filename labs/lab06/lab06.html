面向对象编程

下面是面向对象编程的复习内容。你也可以直接跳到题目，卡住了再回来参考这里。

面向对象编程（OOP）使用对象和类来组织程序。下面是一个类的示例：

class Car:
    max_tires = 4

    def __init__(self, color):
        self.tires = Car.max_tires
        self.color = color

    def drive(self):
        if self.tires < Car.max_tires:
            return self.color + ' car cannot drive!'
        return self.color + ' car goes vroom!'

    def pop_tire(self):
        if self.tires > 0:
            self.tires -= 1

类：对象的类型。上面的 Car 类描述了所有 Car 对象的特征。

对象：类的一个单个实例。在 Python 中，通过调用一个类来创建一个新对象。

>>> ferrari = Car('red')

这里，ferrari 是绑定到 Car 对象的一个名称。

类属性：属于某个类、通过点号记法访问的变量。Car 类有一个 max_tires 属性。

>>> Car.max_tires
4

实例属性：属于某个特定对象的变量。每个 Car 对象都有一个 tires 属性和一个 color 属性。与类属性一样，实例属性通过点号记法访问。

>>> ferrari.color
'red'
>>> ferrari.tires
4
>>> ferrari.color = 'green'
>>> ferrari.color
'green'

方法：属于某个对象、通过点号记法调用的函数。按照惯例，方法的第一个参数是 self。

当调用某个对象的方法时，该对象会作为 self 的实参被隐式传入。例如，ferrari 对象的 drive 方法是通过空括号调用的，因为 self 被隐式绑定到了 ferrari 对象。

>>> ferrari = Car('red')
>>> ferrari.drive()
'red car goes vroom!'

我们也可以调用原始的 Car.drive 函数。原始函数不属于任何特定的 Car 对象，因此我们必须为 self 提供一个显式的实参。

>>> ferrari = Car('red')
>>> Car.drive(ferrari)
'red car goes vroom!'

__init__：当创建一个类的新实例时会自动调用的特殊函数。

注意，drive 方法接收了 self 作为参数，但看起来我们并没有传入它！这是因为点号记法将 ferrari 作为 self 隐式地传了进去。所以在这个例子中，self 被绑定到了全局帧中名为 ferrari 的对象。

要计算表达式 Car('red')，Python 会创建一个新的 Car 对象。然后，Python 调用 Car 类的 __init__ 函数，其中 self 绑定到新对象，color 绑定到 'red'。

继承

两个类可能具有相似的属性，但其中一个是另一个的特殊情况。例如，Nickel（五分镍币）是 Coin（硬币）的一种特殊情况。我们说 Nickel 是 Coin 的子类，而 Coin 是 Nickel 的基类（或父类）。在 Python 中，class Nickel(Coin): 这一行建立了这种关系。

class Coin:
    cents = None  # This will be provided by subclasses, but not by Coin itself

    def __init__(self, year):
        self.year = year

class Nickel(Coin):
    cents = 5

Coin 的方法（例如 __init__）同样也是 Nickel 的方法。所以，例如，每个 Nickel 实例都有一个 year 属性。但在 Nickel 类中定义的类属性或方法会被优先找到。

>>> c = Nickel(1990)
>>> c.year
1990
>>> c.cents
5
