可变性

Python 中有些对象，例如列表和字典，是可变的， 也就是说它们的内容或状态可以被改变。 其他对象，例如数值类型、元组和字符串，是不可变的， 也就是说它们在被创建之后就无法被改变。

列表最常用的两种变更操作是元素赋值和 append 方法。

>>> s = [1, 3, 4]
>>> t = s  # 同一个列表的第二个名称
>>> t[0] = 2  # 将列表的第一个元素改为 2，s 和 t 都会受影响
>>> s
[2, 3, 4]
>>> s.append(5)  # 在列表末尾添加 5，s 和 t 都会受影响
>>> t
[2, 3, 4, 5]

还有许多其他的列表变更方法：

  • append(elem)： 将 elem 添加到列表末尾。返回 None。
  • extend(s)： 将可迭代对象 s 中的所有元素添加到列表末尾。返回 None。
  • insert(i, elem)： 在索引 i 处插入 elem。如果 i 大于或等于列表的长度， 则 elem 会被插入到末尾。这不会替换任何已有元素，只是添加新的元素 elem。返回 None。
  • remove(elem)： 移除列表中第一个出现的 elem。返回 None。 如果 elem 不在列表中则报错。
  • pop(i)： 移除并返回索引 i 处的元素。
  • pop()： 移除并返回最后一个元素。

字典也有元素赋值（经常使用）和 pop（很少使用）。

>>> d = {2: 3, 4: 16}
>>> d[2] = 4
>>> d[3] = 9
>>> d
{2: 4, 4: 16, 3: 9}
>>> d.pop(4)
16
>>> d
{2: 4, 3: 9}

迭代器

可迭代对象是指任何可以被逐个遍历、一次经过一个元素的对象。我们使用过的一种遍历可迭代对象的语句是 for 语句：

for elem in iterable:
    # do something

一般来说，可迭代对象是一个对象，对其调用内置函数 iter 会返回一个迭代器。迭代器是一个对象，对其调用内置函数 next 会返回下一个值。

例如，列表就是一个可迭代的值。

>>> s = [1, 2, 3, 4]
>>> next(s)       # s 是可迭代的，但不是迭代器
TypeError: 'list' object is not an iterator
>>> t = iter(s)   # 创建一个迭代器
>>> t
<list_iterator object ...>
>>> next(t)       # 在迭代器上调用 next
1
>>> next(t)       # 在同一个迭代器上调用 next
2
>>> next(iter(t)) # 在迭代器上调用 iter 会返回它自身
3
>>> t2 = iter(s)
>>> next(t2)      # 第二个迭代器从 s 的开头开始
1
>>> next(t)       # 第一个迭代器不受第二个迭代器的影响
4
>>> next(t)       # 没有剩余元素了！
StopIteration
>>> s             # 原始的可迭代对象不受影响
[1, 2, 3, 4]

你也可以在 for 语句中使用迭代器，因为所有迭代器都是可迭代的。但请注意，由于迭代器会保留自己的状态，它们只能用来遍历一个可迭代对象一次：

>>> t = iter([4, 3, 2, 1])
>>> for e in t:
...     print(e)
4
3
2
1
>>> for e in t:
...     print(e)

有些内置函数会返回迭代器。这些内置的 Python 序列操作被称为惰性计算。

>>> m = map(lambda x: x * x, [3, 4, 5])
>>> next(m)
9
>>> next(m)
16
>>> f = filter(lambda x: x > 3, [3, 4, 5])
>>> next(f)
4
>>> next(f)
5
>>> z = zip([30, 40, 50], [3, 4, 5])
>>> next(z)
(30, 3)
>>> next(z)
(40, 4)

生成器

我们可以通过编写生成器函数来创建自定义的迭代器，生成器函数会返回一种特殊类型的迭代器，称为生成器。生成器函数的函数体中使用 yield 语句，而不是 return 语句。调用生成器函数会返回一个生成器对象，并且不会执行函数体。

例如，我们来看下面这个生成器函数：

def countdown(n):
    print("Beginning countdown!")
    while n >= 0:
        yield n
        n -= 1
    print("Blastoff!")

调用 countdown(k) 会返回一个从 k 倒数到 0 的生成器对象。由于生成器是迭代器，我们可以对其结果对象调用 iter，这只返回同一个对象。注意，此时函数体并没有执行：没有任何内容被打印，也没有任何数字被输出。

>>> c = countdown(5)
>>> c
<generator object countdown ...>
>>> c is iter(c)
True

那么倒计数是如何进行的呢？同样，由于生成器是迭代器，我们调用 next 来获取下一个元素！第一次调用 next 时，执行从函数体的第一行开始，一直持续到遇到 yield 语句。此时会返回 yield 语句中表达式的计算结果。下面的交互会话接在上一个会话之后。

>>> next(c)
Beginning countdown!
5

与我们在本课程中见过的一般函数不同，生成器函数可以记住自己的状态。在之后任何连续调用 next 时，执行会从上次执行过的 yield 语句之后的那一行继续。与第一次调用 next 一样，执行会一直持续到下一个 yield 语句。注意，正因如此，Beginning countdown! 不会被再次打印。

>>> next(c)
4
>>> next(c)
3

接下来的 3 次 next 调用会依次产生递减的整数，直到 0。在下一次调用时，会抛出 StopIteration 错误，因为没有更多的值可以产生了（即函数体在到达 yield 语句之前就已经执行到了末尾）。

>>> next(c)
2
>>> next(c)
1
>>> next(c)
0
>>> next(c)
Blastoff!
StopIteration

对 countdown 的分别调用会创建各自拥有独立状态的生成器对象。通常，生成器不应重新开始。如果你想重置序列，可以再次调用生成器函数来创建另一个生成器对象。

>>> c1, c2 = countdown(5), countdown(5)
>>> c1 is c2
False
>>> next(c1)
5
>>> next(c2)
5

以下是对上述内容的总结：

  • 生成器函数含有 yield 语句，并返回生成器对象。
  • 在生成器对象上调用 iter 函数会返回同一个对象，且不改变其当前状态。
  • 生成器函数的函数体在对其结果生成器对象调用 next 之前不会被求值。对生成器对象调用 next 函数会计算并返回其序列中的下一个对象。如果序列已耗尽，则抛出 StopIteration。

  • 生成器会为下一次 next 调用"记住"自己的状态。因此，

    • 第一次 next 调用的工作方式如下：

      1. 进入函数并执行，直到出现带有 yield 的那一行。
      2. 返回 yield 语句中的值，但为后续的 next 调用记住函数的状态。

    • 后续的 next 调用的工作方式如下：

      1. 重新进入函数，从上次执行过的 yield 语句之后的那一行开始，一直执行到下一个 yield 语句。
      2. 返回 yield 语句中的值，但为后续的 next 调用记住函数的状态。
  • 调用生成器函数会返回一个全新的生成器对象（就像在可迭代对象上调用 iter 一样）。
  • 除非是那样定义的，生成器不应重新开始。要想从生成器中的第一个元素重新开始，只需再次调用生成器函数来创建一个新的生成器即可。

生成器的另一个实用工具是 yield from 语句。yield from 会产生一个迭代器或可迭代对象中的所有值。

>>> def gen_list(lst):
...     yield from lst
...
>>> g = gen_list([1, 2, 3, 4])
>>> next(g)
1
>>> next(g)
2
>>> next(g)
3
>>> next(g)
4
>>> next(g)
StopIteration
