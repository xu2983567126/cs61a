重要： 如果 python3 命令无效，请尝试使用 python 或 py。

以下是在文件上运行 Python 最常见的方式。

  1. 不使用任何命令行选项，会运行你提供的文件中的代码，并将你返回到命令行。如果你的文件只包含函数定义，那么除非存在语法错误，否则你看不到任何输出。

    python3 lab00.py

  2. -i：-i 选项会运行你提供的文件中的代码，然后打开一个交互式会话（带有 >>> 提示符）。此后你可以求值表达式，例如调用你定义的函数。要退出，请输入 exit()。你也可以使用键盘快捷键：在 Linux/Mac 机器上为 Ctrl-D，在 Windows 上为 Ctrl-Z Enter。

    如果你在交互式运行期间编辑了 Python 文件，则需要退出并重新启动解释器，这些改动才能生效。

    以下是我们以交互方式运行 lab00.py 的方法：

    python3 -i lab00.py

  3. -m doctest：运行文件中的 doctest，即函数文档字符串中的示例。

    文件中的每个测试由 >>> 后跟一些 Python 代码及其预期输出组成。

    以下是我们运行 lab00.py 中 doctest 的方法：

     python3 -m doctest lab00.py

    当我们的代码通过所有 doctest 时，不会显示任何输出。否则，会显示有关失败测试的信息。


在 CS 61A 中，我们使用一个名为 Ok 的程序来自动评分实验、作业和项目。

要使用 Ok 测试一个函数，请运行以下命令（将 FUNCTION 替换为该函数的名称）：

python3 ok -q FUNCTION

如果你的函数包含一行以 "DEBUG:" 开头的对 print 的调用，那么 OK 会忽略这一行。（否则，额外的 print 调用可能会因为产生多余的输出而导致测试失败。）

print("DEBUG:", x)

在 使用 OK 页面 上介绍了更多功能。你可以在 ok-help 快速生成大多数 ok 命令。

x % y == 0

你定义的大多数函数都会包含一个 return 语句，用于提供调用该函数时所用调用表达式的值。

当 Python 执行一条 return 语句时，函数调用会立即终止。如果 Python 到达函数体末尾却仍未执行任何 return 语句，函数会返回 None。

相比之下，print 函数用于显示值。与 return 语句不同，当 Python 求值对 print 的调用时，函数不会立即终止。

def what_prints():
    print('Hello World!')
    return 'Exiting this function.'
    print('This course is awesome!')

>>> what_prints()
Hello World!
'Exiting this function.'

还要注意，print 显示文本时不带引号，而 return 会保留引号。
