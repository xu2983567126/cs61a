重要： If the python3 command doesn't work, please try using python or py.

以下是在文件上运行 Python 最常见的方式。

  1. Using no command-line options will run the code in the file you provide and return you to the command line. If your file just contains function definitions, you'll see no output unless there is a syntax error.

    python3 lab00.py

  2. -i: The -i option runs the code in the file you provide, then opens an interactive session (with a >>> 提示符）。然后你可以求值诸如调用你定义的函数之类的表达式。要退出，输入 exit(). You can also use the keyboard shortcut Ctrl-D on Linux/Mac machines or Ctrl-Z Enter 在 Windows 上。

    如果你在交互式运行时编辑了 Python 文件，你需要退出并重新启动解释器，才能使这些更改生效。

    Here's how we can run lab00.py 交互式地：

    python3 -i lab00.py

  3. -m doctest：运行文件中的 doctest，即函数文档字符串中的示例。

    Each test in the file consists of >>> 后面跟着一些 Python 代码和预期输出。

    Here's how we can run the doctests in lab00.py:

     python3 -m doctest lab00.py

    当我们的代码通过了所有 doctest 时，不会显示任何输出。否则， 会显示有关失败测试的信息。

Most functions that you define will contain a return statement that provides the value of the call expression used to call the function.

When Python executes a return statement, the function call terminates immediately. If Python reaches the end of the function body without executing a return statement, the function returns None.

In contrast, the print function is used to display values. Unlike a return statement, when Python evaluates a call to print, the function does 不 立即终止。

def what_prints():
    print('Hello World!')
    return 'Exiting this function.'
    print('This course is awesome!')

>>> what_prints()
Hello World!
'Exiting this function.'

Notice also that print will display text 不带引号，但是 return 会保留引号。

第4题：递减阶乘

Let's write a function falling, which is a "falling" factorial that takes two arguments, n and k, and returns the product of k consecutive numbers, starting from n and working downwards. When k 为 0，函数应该返回 1。

def falling(n, k):
    """Compute the falling factorial of n to depth k.

    >>> falling(6, 3)  # 6 * 5 * 4
    120
    >>> falling(4, 3)  # 4 * 3 * 2
    24
    >>> falling(4, 1)  # 4
    4
    >>> falling(4, 0)
    1
    """

    total, stop = 1, n-k
    while n > stop:
        total, n = total*n, n-1
    return total

使用 Ok 测试你的代码：

python3 ok -q falling

第5题：被 k 整除

Write a function divisible_by_k that takes positive integers n and k. It prints all positive integers less than or equal to n that are divisible by k 从最小到最大。然后，它返回打印了多少个数字。

def divisible_by_k(n, k):
    """
    >>> a = divisible_by_k(10, 2)  # 2, 4, 6, 8, and 10 are divisible by 2
    2
    4
    6
    8
    10
    >>> a
    5
    >>> b = divisible_by_k(3, 1)  # 1, 2, and 3 are divisible by 1
    1
    2
    3
    >>> b
    3
    >>> c = divisible_by_k(6, 7)  # There are no integers up to 6 that are divisible by 7
    >>> c
    0
    """

    count = 0
    i = 1
    while i <= n:
        if i % k == 0:
            print(i)
            count += 1
        i += 1
    return count

使用 Ok 测试你的代码：

python3 ok -q divisible_by_k

第6题：双八

写一个函数，接收一个数并判断其数字中是否包含两个相邻的 8。

def double_eights(n):
    """Return true if n has two eights in a row.
    >>> double_eights(8)
    False
    >>> double_eights(88)
    True
    >>> double_eights(2882)
    True
    >>> double_eights(880088)
    True
    >>> double_eights(12345)
    False
    >>> double_eights(80808080)
    False
    """

    prev_eight = False
    while n > 0:
        last_digit = n % 10
        if last_digit == 8 and prev_eight:
            return True
        elif last_digit == 8:
            prev_eight = True
        else:
            prev_eight = False
        n = n // 10
    return False

# 备选解法（没有不必要的基例）
def double_eights_alt_e(n):
    if n % 100 == 88:
        return True
    elif n < 100:
        return False
    return double_eights_alt_e(n // 10)

# 备选解法
def double_eights_alt(n):
    while n:
        if n % 10 == 8 and n // 10 % 10 == 8:
            return True
        n //= 10
    return False

使用 Ok 测试你的代码：

python3 ok -q double_eights

第8题：选取一位数字

Implement digit, which takes positive integers n and k and has only a single return statement as its body. It returns the digit of n that is k positions to the left of the rightmost digit (the one's digit). If k is 0, return the rightmost digit. If there is no digit of n that is k 位于最右边数字左边的位置，返回 0。

提示： Use // and % and the built-in pow function to isolate a particular digit of n.

def digit(n, k):
    """Return the k-th digit from the right of n for positive integers n and k.

    >>> digit(3579, 2)
    5
    >>> digit(3579, 0)
    9
    >>> digit(3579, 10)
    0
    """

    return n // pow(10, k) % 10

使用 Ok 测试你的代码：

python3 ok -q digit

第9题：中间数

Implement middle by writing a single return expression that evaluates to the value that is neither the largest or smallest among three different integers a, b, and c.

提示： Try combining all the numbers and then taking away the ones you don't want to return by using the built-in min and max 函数。

>>> max(1, 2, 3)
3
>>> min(-1, -2, -3)
-3
def middle(a, b, c):
    """Return the number among a, b, and c that is not the smallest or largest.
    Assume a, b, and c are all different numbers.

    >>> middle(3, 5, 4)
    4
    >>> middle(30, 5, 4)
    5
    >>> middle(3, 5, 40)
    5
    >>> middle(3, 5, 40)
    5
    >>> middle(30, 5, 40)
    30
    """

    return a + b + c - min(a, b, c) - max(a, b, c)

使用 Ok 测试你的代码：

python3 ok -q middle

第10题：数字求和

写一个函数，接收一个非负整数并求其各位数字之和。（在这里使用向下取整除法和取模可能会有帮助！）

def sum_digits(y):
    """Sum all the digits of y.

    >>> sum_digits(10) # 1 + 0 = 1
    1
    >>> sum_digits(4224) # 4 + 2 + 2 + 4 = 12
    12
    >>> sum_digits(1234567890)
    45
    >>> a = sum_digits(123) # make sure that you are using return rather than print
    >>> a
    6
    """

    total = 0
    while y > 0:
        total, y = total + y % 10, y // 10
    return total

使用 Ok 测试你的代码：

python3 ok -q sum_digits
