SQL

一条 SELECT 语句根据输入行描述一张输出表。编写它的方式是：

  1. 描述 输入行，使用 FROM 和 WHERE 子句。
  2. 分组 这些行，并使用 GROUP BY 和 HAVING 子句来确定哪些组应当作为输出行出现。
  3. 格式化并排序 输出行 以及列，使用 SELECT 和 ORDER BY 子句。

SELECT （步骤 3） FROM （步骤 1） WHERE （步骤 1） GROUP BY （步骤 2） HAVING （步骤 2） ORDER BY （步骤 3）;

步骤 1 可能涉及连接表（使用逗号），以形成由现有表中两行或多行组成的输入行。

这些 WHERE, GROUP BY, HAVING、以及 ORDER BY 子句是可选的。

如果你需要复习 SQL，可以参考下拉菜单。如果卡住了，也可以直接跳到题目，需要时再回来看这里。

SQL 基础

示例表

下面是一个名为 big_game 的表，在下面的示例中会用到它，它记录了 每年 Big Game 的比分。该表有三列：berkeley、 stanford，以及 year。

CREATE TABLE big_game (
    berkeley INTEGER, stanford INTEGER, year INTEGER);

INSERT INTO big_game (berkeley, stanford, year) VALUES
    (30, 7, 2002),
    (28, 16, 2003),
    (17, 38, 2014);

你可以在 sqlite 中这样查看它：

sqlite> .mode column
sqlite> SELECT * FROM big_game;
berkeley  stanford  year
--------  --------  ----
30        7         2002
28        16        2003
17        38        2014
如果 .mode column 命令在你的 sqlite 版本中无法使用，也没关系。直接忽略它即可。

从表中查询

通常，我们会使用一条 SELECT 语句从现有表创建新表：

SELECT [columns] FROM [tables] WHERE [condition] ORDER BY [columns] LIMIT [limit];

我们来拆解这条语句：

  • SELECT [columns] 告诉 SQL 我们想在 输出表中包含给定的列；[columns] 是逗号分隔的列名列表，而 * 可用于选择所有列
  • FROM [table] 告诉 SQL 我们想要选择的列来自 给定的表
  • WHERE [condition] 通过只包含那些 值满足给定 [condition] 的行来过滤输出表；其中 是一个布尔表达式
  • ORDER BY [columns] 按给定的 逗号分隔的列列表对输出表中的行排序；默认情况下，值按升序（ASC）排列，但你也可以使用 DESC 按降序排列
  • LIMIT [limit] 按整数 限制输出表中的行数 [limit]

下面是一些示例：

从 big_game 表中查询 Berkeley 的所有比分，但只包含 2002 年之后的比分：

sqlite> SELECT berkeley FROM big_game WHERE year > 2002;
28
17

查询 Berkeley 获胜年份两所学校的比分：

sqlite> SELECT berkeley, stanford FROM big_game WHERE berkeley > stanford;
30|7
28|16

查询 Stanford 得分超过 15 分的年份：

sqlite> SELECT year FROM big_game WHERE stanford > 15;
2003
2014

SQL 运算符

在 SELECT, WHERE、以及 ORDER BY 子句中可以包含 以下一个或多个运算符：

  • 比较运算符：=, >, <, <=, >=, <> 或 !=（“不等于”）
  • 布尔运算符：AND, OR
  • 算术运算符：+, -, *, /
  • 连接运算符：||

输出每年 Berkeley 与 Stanford 比分的比值：

sqlite> select berkeley * 1.0 / stanford from big_game;
0.447368421052632
1.75
4.28571428571429

输出两支队伍得分均超过 10 分的年份的比分总和：

sqlite> select berkeley + stanford from big_game where berkeley > 10 and stanford > 10;
55
44

输出一个只有单列单行、且值为 "hello world" 的表：

sqlite> SELECT "hello" || " " || "world";
hello world

连接

要从多个表中查询数据，我们可以使用连接。连接的类型有很多， 但我们只需要关注内连接（inner join）。要对两个或多个表执行 内连接，只需在 FROM 子句中列出所有这些表， 在一条 SELECT 语句里：

SELECT [columns] FROM [table1], [table2], ... WHERE [condition] ORDER BY [columns] LIMIT [limit];

我们可以从多个不同的表中查询，也可以多次从同一个表中查询。

假设我们有下面这张表，其中包含 2002 年以来 Cal 的主教练姓名：

CREATE TABLE coaches (
    name TEXT,
    start INTEGER,
    end INTEGER
);

INSERT INTO coaches (name, start, end)
VALUES
    ('Jeff Tedford', 2002, 2012),
    ('Sonny Dykes', 2013, 2016),
    ('Justin Wilcox', 2017, 2025);

当我们连接两个或多个表时，默认的输出是一个 笛卡尔积。例如， 如果我们把 big_game 与 coaches 连接，会得到如下结果：

sqlite> SELECT * FROM big_game JOIN coaches;
berkeley  stanford  year  name           start  end
--------  --------  ----  -------------  -----  ----
30        7         2002  Jeff Tedford   2002   2012
30        7         2002  Sonny Dykes    2013   2016
30        7         2002  Justin Wilcox  2017   2025
28        16        2003  Jeff Tedford   2002   2012
28        16        2003  Sonny Dykes    2013   2016
28        16        2003  Justin Wilcox  2017   2025
17        38        2014  Jeff Tedford   2002   2012
17        38        2014  Sonny Dykes    2013   2016
17        38        2014  Justin Wilcox  2017   2025

如果我们想把每场比赛与该赛季的教练对应起来，就必须在 WHERE 子句中比较两张表的列：

sqlite> SELECT * FROM big_game JOIN coaches ON year >= start AND year <= end
   ...> ;
berkeley  stanford  year  name          start  end
--------  --------  ----  ------------  -----  ----
30        7         2002  Jeff Tedford  2002   2012
28        16        2003  Jeff Tedford  2002   2012
17        38        2014  Sonny Dykes   2013   2016

在上面的查询中，列名都没有歧义。例如，很明显 start 列来自 coaches 表，因为 big_game 表中没有同名列。然而，如果一个列名 出现在多个被连接的表中，或者我们对表自身进行连接，就必须使用点记法和别名来消除列名的歧义。

举个例子，我们来看看每支队伍在 big_game 比赛与任意此前比赛之间的比分差。由于该表中的每一行代表 一场比赛，要比较两场比赛，我们必须把 big_game 与它自身连接：

sqlite> SELECT b.Berkeley - a.Berkeley, b.Stanford - a.Stanford, a.Year, b.Year
   ...>   FROM big_game AS a, big_game AS b WHERE a.Year < b.Year;
b.Berkeley - a.Berkeley  b.Stanford - a.Stanford  year  year
-----------------------  -----------------------  ----  ----
-2                       9                        2002  2003
-13                      31                       2002  2014
-11                      22                       2003  2014

在上面的查询中，我们给第一个 a 表起别名 big_game，给第二个 b 表起别名。然后我们可以使用带别名的点记法来引用 每个表中的列，例如 big_game table. We can then reference columns from each table using dot notation with the aliases, e.g. a.Berkeley, a.Stanford，以及 a.Year 来从第一张表中查询。

SQL 聚合

下面是另一张示例表，这次关于航班：

CREATE TABLE flights (
    departure TEXT, arrival TEXT, price INTEGER);

INSERT INTO flights (departure, arrival, price) VALUES
    ('SFO', 'LAX', 97),
    ('SFO', 'AUH', 848),
    ('LAX', 'SLC', 115),
    ('SFO', 'PDX', 192),
    ('AUH', 'SEA', 932),
    ('SLC', 'PDX', 79),
    ('SFO', 'LAS', 40),
    ('SLC', 'LAX', 117),
    ('SEA', 'PDX', 32),
    ('SLC', 'SEA', 42),
    ('SFO', 'SLC', 97),
    ('LAS', 'SLC', 50),
    ('LAX', 'PDX', 89);

应用一个 聚合函数 例如 MAX(column) 会将多行中的值合并为一行输出。

默认情况下，我们会合并表中所有行的值。例如，如果我们 想统计 flights 表中的行数，可以使用：

sqlite> SELECT COUNT(*) from FLIGHTS;
13

如果我们想把相似行中的值分组，并在这些组内执行 聚合操作，该怎么办？我们使用 GROUP BY 子句。

再看一个例子。对于每个不同的出发地，把所有具有 相同出发机场的行收集到一个组中。然后，选择 price 列，并对该组 应用 MIN 聚合，以得到该组中最便宜出发的价格。最终结果是一张包含出发机场和最便宜 出发航班的表。

sqlite> SELECT departure, MIN(price) FROM flights GROUP BY departure;
departure  MIN(price)
---------  ----------
AUH        932
LAS        50
LAX        89
SEA        32
SFO        40
SLC        42

就像我们可以用 WHERE 过滤掉行一样，我们也可以 用 HAVING 过滤掉组。通常，HAVING 子句应当使用一个聚合 函数。假设我们想查看所有至少有两次出发的机场：

sqlite> SELECT departure FROM flights GROUP BY departure HAVING COUNT(*) >= 2;
departure
---------
LAX
SFO
SLC

注意 COUNT(*) 聚合只是统计每个组中的行数。distinct（去重） 机场。那么，我们可以 使用下面的查询：

sqlite> SELECT COUNT(DISTINCT departure) AS destinations FROM flights;
destinations
------------
6

这枚举了 flights table (in this case: SFO, LAX, AUH, SLC, SEA, and LAS).

表中所有可用的不同出发机场（本例中为：SFO、LAX、AUH、SLC、SEA 和 LAS）。

IMDb

IMDb 1000 数据集包含来自 Internet Movie Database（互联网电影数据库）.

这个数据集中的表相当大，所以经常使用 LIMIT 来 查看其中一张表的少数几行。要查看 titles 表中的几个示例行（该表包含每部电影的信息）：

    % sqlite3

    sqlite> .tables

以 .read 开头的命令会读入 imdb1000.sql 中的 SQL 命令，这些命令 创建带有电影数据集的新表。而 .tables 命令会列出所有 表。

sqlite> .mode column
sqlite> SELECT tconst, title, year, runtime FROM titles LIMIT 3;

tt0013442  Nosferatu: A Symphony of Horror  1922  94

Q1: 最新电影

创建一个名为 newest 的表，其中包含数据集中最新的 10 部电影，它有两列：

  • title：电影的名称
  • year：电影制作的年份

如果你愿意，看看能不能猜出结果中会有哪些电影。

  SELECT ____, ____
  FROM ____
  ORDER BY ____
  LIMIT ____;
  1. 使用 FROM 来指定从哪个表读取数据。
  2. 使用 ORDER BY 按电影的新旧程度排序。
  3. 使用 LIMIT 只选择最新的 10 部电影。
  4. 使用 SELECT 将电影标题和年份放入输出中。
CREATE table newest AS

  SELECT title, year
  FROM titles
  ORDER BY year DESC
  LIMIT 10;
使用 Ok 测试你的代码：

python3 ok -q newest

Q2: 有狗的电影

创建一个 dog_movies 表，其中包含每个包含“dog”一词的电影角色对应的一行， 它有两列：

  • title（文本）：电影的名称
  • character（文本）：狗角色的名称

如果一部电影有多个狗角色，它可能会多次出现。

SELECT _____, _____
FROM _____ JOIN _____ ON _____
WHERE ____ LIKE "%dog%";
  1. 使用 FROM, JOIN，以及 ON 来合并 titles 和 principals 表中的信息。
  2. 使用 WHERE 只选择包含“dog”的角色。
  3. 使用 SELECT 将电影标题和角色放入输出中。
CREATE table dog_movies AS 

  SELECT title, character
  FROM titles JOIN principals
  ON titles.tconst = principals.tconst
  WHERE character LIKE "%dog%";
使用 Ok 测试你的代码：

python3 ok -q dog_movies

Q3: 主演的连锁

创建一个 leads 表，它有两列：

  • name（文本）：演员的姓名
  • lead_roles（整数）：该演员担任主演的影片数量

你可以通过在 principals 表中查找 ordering 等于 1 的行来找到主演角色。超过 10 部电影的演员。

  SELECT ____, ____ AS lead_roles
  FROM ____ JOIN ____ ON ____
  WHERE ____
  GROUP BY names.nconst
  HAVING count(*) > 10;
  1. 使用 FROM 和 ON 来合并 principals 和 names 表中的信息。
  2. 使用 WHERE 只选择主演角色。
  3. 使用 GROUP BY 为每个人创建单独的一行。
  4. 使用 HAVING 只输出担任主演超过 10 次的演员。
  5. 使用 SELECT 将演员姓名及其角色数量放入输出中。
CREATE table leads AS 

  SELECT name, count(*)
  FROM names JOIN principals
  ON names.nconst=principals.nconst
  WHERE ordering=1
  GROUP BY names.nconst
  HAVING count(*) > 10;
使用 Ok 测试你的代码：

python3 ok -q leads

Q4: 长电影

创建一个 long_movies 表，其中包含每个年代中时长超过 3 小时的电影数量。long_movies 有两列：

  • decade（字符串）：年代，例如 1920s
  • count（数字）：该年代中时长超过 3 小时（180 分钟）的电影数量

对于 IMDB 1000 数据集，结果将是：

+--------+-------+
| decade | count |
+--------+-------+
| 1930s  | 1     |
| 1950s  | 2     |
| 1960s  | 2     |
| 1970s  | 3     |
| 1980s  | 2     |
| 1990s  | 7     |
| 2000s  | 4     |
| 2010s  | 3     |
| 2020s  | 4     |
+--------+-------+
当把数字相加并将结果放入字符串时，请将算术部分用括号括起来，例如， 注意字符串连接！ 
sqlite> SELECT (192 * 10) || "s";
1920s
SELECT ____ AS decade, ____ AS count
FROM ____
WHERE ____
GROUP BY ____;
  1. 使用 FROM 和 WHERE 只选择时长大于 180 分钟的电影。
  2. 使用 GROUP BY 将同一个年代的所有电影分组。
  3. 使用 SELECT 为每个年代创建类似 1920s 的字符串，并选择每个年代的电影数量。
CREATE table long_movies AS 

  SELECT ((year / 10) * 10) || "s" AS decade, COUNT(*) AS count
  FROM titles
  WHERE runtime>180
  GROUP BY year / 10;

使用 Ok 测试你的代码：

python3 ok -q long_movies
