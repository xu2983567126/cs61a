必做题目

SQL

一条 SELECT 语句根据输入行描述一个输出表。编写它的方法是：

  1. 使用 FROM 和 WHERE 子句描述 输入行。
  2. 使用 GROUP BY 和 HAVING 子句对行进行 分组，并确定哪些组应该作为输出行出现。
  3. 使用 SELECT 和 ORDER BY 子句格式化并排列 输出行 和列。

SELECT （第 3 步） FROM （第 1 步） WHERE （第 1 步） GROUP BY （第 2 步） HAVING （第 2 步） ORDER BY （第 3 步）；

第 1 步可能涉及连接表（使用逗号），以形成由现有表中两行或更多行组成的输入行。

WHERE、GROUP BY、HAVING 和 ORDER BY 子句都是可选的。

如果你需要复习 SQL，请参考下面的折叠框。如果遇到困难，也可以直接跳到题目，再回来查阅本部分。

SQL 基础

示例表

下面是一个名为 big_game 的表，用于下面的例子，它记录了 每年“大赛”（Big Game）的比分。这个表有三列：berkeley、stanford 和 year。

CREATE TABLE big_game (
    berkeley INTEGER, stanford INTEGER, year INTEGER);

INSERT INTO big_game (berkeley, stanford, year) VALUES
    (30, 7, 2002),
    (28, 16, 2003),
    (17, 38, 2014);

你可以像下面这样在 sqlite 中查看它：

sqlite> .mode column
sqlite> SELECT * FROM big_game;
berkeley  stanford  year
--------  --------  ----
30        7         2002
28        16        2003
17        38        2014
如果你的 sqlite 版本中 .mode column 命令不起作用，也没关系。忽略它即可。

从表中选择

通常，我们会使用 SELECT 语句从现有表创建一个新的表：

SELECT [columns] FROM [tables] WHERE [condition] ORDER BY [columns] LIMIT [limit];

我们来分解一下这条语句：

  • SELECT [columns] 告诉 SQL 我们希望在 输出表中包含给定的列；[columns] 是一个用逗号分隔的列名列表，* 可用于选择所有列。
  • FROM [table] 告诉 SQL 我们要选择的列来自 给定的表。
  • WHERE [condition] 通过只包含那些值满足给定 [condition]（一个布尔表达式）的行来筛选输出表。
  • ORDER BY [columns] 按给定的用逗号分隔的列列表对输出表中的行进行排序；默认情况下，值按升序（ASC）排序，但你也可以使用 DESC 按降序排序。
  • LIMIT [limit] 将输出表中的行数限制为整数 [limit]。

下面是一些例子：

从 big_game 表中选择 Berkeley 的所有得分，但只包含在 2002 年之后的年份中的得分：

sqlite> SELECT berkeley FROM big_game WHERE year > 2002;
28
17

选择 Berkeley 获胜年份中两所学校的比分：

sqlite> SELECT berkeley, stanford FROM big_game WHERE berkeley > stanford;
30|7
28|16

选择 Stanford 得分超过 15 分的年份：

sqlite> SELECT year FROM big_game WHERE stanford > 15;
2003
2014

SQL 运算符

SELECT、WHERE 和 ORDER BY 子句中的表达式可以包含一个或多个以下运算符：

  • 比较运算符：=、>、<、<=、>=、<> 或 !=（“不等于”）
  • 布尔运算符：AND、OR
  • 算术运算符：+、-、*、/
  • 拼接运算符：||

输出每年 Berkeley 得分与 Stanford 得分的比值：

sqlite> select berkeley * 1.0 / stanford from big_game;
0.447368421052632
1.75
4.28571428571429

输出两队的得分之和，条件是两队得分都超过 10 分：

sqlite> select berkeley + stanford from big_game where berkeley > 10 and stanford > 10;
55
44

输出一个只有一列一行、值为 "hello world" 的表：

sqlite> SELECT "hello" || " " || "world";
hello world

连接（Joins）

要从多个表中选择数据，我们可以使用连接（joins）。连接有很多种 类型，但我们只需要关注内连接（inner join）。要对两个或更多表执行 内连接，只需在 SELECT 语句的 FROM 子句中将它们全部列出：

SELECT [columns] FROM [table1], [table2], ... WHERE [condition] ORDER BY [columns] LIMIT [limit];

我们可以从多个不同的表中选择，也可以多次从同一个表中选择。

假设我们有如下表格，记录了 2002 年以来加州大学伯克利分校橄榄球队主教练的姓名：

CREATE TABLE coaches (
    name TEXT,
    start INTEGER,
    end INTEGER
);

INSERT INTO coaches (name, start, end)
VALUES
    ('Jeff Tedford', 2002, 2012),
    ('Sonny Dykes', 2013, 2016),
    ('Justin Wilcox', 2017, 2025);

当我们连接两个或更多表时，默认输出是一个 笛卡尔积（cartesian product）。例如，如果我们将 big_game 与 coaches 连接，我们会得到如下结果：

sqlite> SELECT * FROM big_game JOIN coaches;
berkeley  stanford  year  name           start  end
--------  --------  ----  -------------  -----  ----
30        7         2002  Jeff Tedford   2002   2012
30        7         2002  Sonny Dykes    2013   2016
30        7         2002  Justin Wilcox  2017   2025
28        16        2003  Jeff Tedford   2002   2012
28        16        2003  Sonny Dykes    2013   2016
28        16        2003  Justin Wilcox  2017   2025
17        38        2014  Jeff Tedford   2002   2012
17        38        2014  Sonny Dykes    2013   2016
17        38        2014  Justin Wilcox  2017   2025

如果我们要把每场比赛与其当季的教练对应起来，就必须在 WHERE 子句中比较两个表中的列：

sqlite> SELECT * FROM big_game JOIN coaches ON year >= start AND year <= end
   ...> ;
berkeley  stanford  year  name          start  end
--------  --------  ----  ------------  -----  ----
30        7         2002  Jeff Tedford  2002   2012
28        16        2003  Jeff Tedford  2002   2012
17        38        2014  Sonny Dykes   2013   2016

在上面的查询中，没有任何列名是歧义的。例如，很明显 start 列来自 coaches 表，因为 big_game 表中没有同名的列。然而，如果一个列名存在于多个被连接的表中，或者我们将一个表与自身连接，我们就必须使用点表示法和别名（alias）来消除列名的歧义。

举例来说，我们想找出 big_game 中某场比赛与之前任何一场比赛之间的比分差。由于该表中的每一行代表一场比赛，为了比较两场比赛，我们必须将 big_game 与自身连接：

sqlite> SELECT b.Berkeley - a.Berkeley, b.Stanford - a.Stanford, a.Year, b.Year
   ...>   FROM big_game AS a, big_game AS b WHERE a.Year < b.Year;
b.Berkeley - a.Berkeley  b.Stanford - a.Stanford  year  year
-----------------------  -----------------------  ----  ----
-2                       9                        2002  2003
-13                      31                       2002  2014
-11                      22                       2003  2014

在上面的查询中，我们给第一个 big_game 表取别名 a，给第二个 big_game 表取别名 b。然后我们可以使用带别名的点表示法引用每个表中的列，例如 a.Berkeley、a.Stanford 和 a.Year 来选择第一个表中的列。

SQL 聚合

下面是另一个示例表，这次是关于航班的：

CREATE TABLE flights (
    departure TEXT, arrival TEXT, price INTEGER);

INSERT INTO flights (departure, arrival, price) VALUES
    ('SFO', 'LAX', 97),
    ('SFO', 'AUH', 848),
    ('LAX', 'SLC', 115),
    ('SFO', 'PDX', 192),
    ('AUH', 'SEA', 932),
    ('SLC', 'PDX', 79),
    ('SFO', 'LAS', 40),
    ('SLC', 'LAX', 117),
    ('SEA', 'PDX', 32),
    ('SLC', 'SEA', 42),
    ('SFO', 'SLC', 97),
    ('LAS', 'SLC', 50),
    ('LAX', 'PDX', 89);

应用 聚合函数（aggregate function） （例如 MAX(column)）可将多行中的值合并到一个输出行中。

默认情况下，我们合并表中所有行的值。例如，如果我们 想计算 flights 表中的行数，可以使用：

sqlite> SELECT COUNT(*) from FLIGHTS;
13

如果我们想将相似行中的值分组，并在这些组内执行 聚合操作，该怎么办？我们使用 GROUP BY 子句。

再看一个例子。对于每个不同的出发地，将所有具有相同出发地机场的行收集到一个组中。然后，选择 price 列并 应用 MIN 聚合，以恢复从该组出发地出发最便宜的航班价格。 最终结果是一个出发地机场及其最便宜出发航班的表。

sqlite> SELECT departure, MIN(price) FROM flights GROUP BY departure;
departure  MIN(price)
---------  ----------
AUH        932
LAS        50
LAX        89
SEA        32
SFO        40
SLC        42

就像我们可以用 WHERE 筛选行一样，我们也可以用 HAVING 筛选 组。通常，HAVING 子句应使用聚合函数。假设我们想查看所有至少有两次出发的机场：

sqlite> SELECT departure FROM flights GROUP BY departure HAVING COUNT(*) >= 2;
departure
---------
LAX
SFO
SLC

注意 COUNT(*) 聚合只是计算每个组中的行数。 假设我们想改为计算 不同 机场的数量。那么，我们可以使用以下查询：

sqlite> SELECT COUNT(DISTINCT departure) AS destinations FROM flights;
destinations
------------
6

这列举了 flights 表中所有不同的出发地机场（本例中为：SFO、LAX、AUH、SLC、SEA 和 LAS）。

使用方法

首先，检查是否存在一个名为 sqlite_shell.py 的文件，它与作业文件放在一起。 如果你没看到它，或者在使用它时遇到问题，请向下滚动到“故障排除”一节，了解如何在继续之前下载官方预编译的 SQLite 二进制文件。

你可以在终端或 Git Bash 中使用以下命令启动交互式 SQLite 会话：

python3 sqlite_shell.py

在解释器运行时，你可以输入 .help 查看可以运行的一些命令。

要退出 SQLite 解释器，请输入 .exit 或 .quit，或按 Ctrl-C。请记住，如果你在按回车后看到 ...>，很可能是你忘记写 ; 了。

你也可以通过以下方式运行 .sql 文件中的所有语句：（这里我们使用 lab11.sql 文件作为例子。）

  1. 运行你的代码，然后立即退出 SQLite。

    python3 sqlite_shell.py < lab11.sql

  2. 运行你的代码，然后打开一个交互式 SQLite 会话，这类似于使用交互式的 -i 标志运行 Python 代码。

    python3 sqlite_shell.py --init lab11.sql

IMDb

IMDb 1000 数据集包含评分最高的 1000 部热门电影（得票率前 0.2%），来自 互联网电影数据库（Internet Movie Database）。

该数据集中的表相当大，所以使用 LIMIT 来查看其中一个表里的几行通常很有用。要查看 titles 表中的几行示例（该表包含每部电影的信息）：

    % sqlite3
    sqlite> .read imdb1000.sql
    sqlite> .tables
    crew        names       principals  ratings     titles

以 .read 开头的命令会读入 imdb1000.sql 中的 SQL 命令，这些命令 创建了带有电影数据集的新表。.tables 命令列出了所有 表。

下面是本实验你需要的表和列。 .mode column 命令可以改善格式，但它在 sqlite_shell.py 中不起作用， 而且它是可选的。

sqlite> .mode column
sqlite> SELECT tconst, title, year, runtime FROM titles LIMIT 3;
tconst     title                            year  runtime
---------  -------------------------------  ----  -------
tt0012349  The Kid                          1921  68
tt0013442  Nosferatu: A Symphony of Horror  1922  94
tt0015864  The Gold Rush                    1925  95

sqlite> SELECT tconst, ordering, nconst, character FROM principals LIMIT 3;
tconst     ordering  nconst     character
---------  --------  ---------  ---------
tt0012349  1         nm0000122  A Tramp
tt0012349  2         nm0701012  The Woman
tt0012349  3         nm0001067  The Child

sqlite> SELECT nconst, name, birth, death FROM names LIMIT 3;
nconst     name            birth  death
---------  --------------  -----  -----
nm0000002  Lauren Bacall   1924   2014
nm0000004  John Belushi    1949   1982
nm0000005  Ingmar Bergman  1918   2007

tconst 是每部电影的唯一标识符（t 代表 title），nconst 是每个人的唯一 标识符。这些标识符对于连接来自不同表的行很有用， 例如，要确定某部电影的评分，我们会在 titles 表中找到该电影的 nconst，然后在 ratings 表中查找该 nconst。
