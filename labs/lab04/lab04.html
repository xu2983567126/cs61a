序列

序列是支持元素选取操作、并且具有长度的、有序的值的集合。 我们已经使用过列表，但其他 Python 类型也是序列，包括字符串。

我们来看一些可以对字符串进行的操作的例子。

>>> x = 'Hello there Oski!'
>>> x
'Hello there Oski!'
>>> len(x)
17
>>> x[6:]
'there Oski!'
>>> x[::-1]
'!iksO ereht olleH'

由于字符串是序列，我们可以对字符串做很多与列表相同的操作。我们甚至可以像遍历列表一样遍历字符串：

>>> x = 'I am not Oski.'
>>> vowel_count = 0
>>> for i in range(len(x)):
...     if x[i] in 'aeiou':
...         vowel_count += 1
>>> vowel_count
5

for 语句会对序列中的每个元素执行一次其中的代码，例如列表或 range。每次执行代码时，紧跟在 for 后面的名称会被绑定到序列中的不同元素上。

for <name> in <expression>:
    <suite>

首先，计算 <expression>。它必须计算为一个序列。然后，对序列中的每个元素按序执行：

  1. <name> 被绑定到该元素。
  2. 执行 <suite>。

下面是一个例子：

for x in [-1, 4, 2, 0, 5]:
    print("Current elem:", x)

这将显示如下内容：

Current elem: -1
Current elem: 4
Current elem: 2
Current elem: 0
Current elem: 5

字典包含键值对，并允许通过方括号使用键来查找对应的值。每个键必须是唯一的。

>>> d = {2: 4, 'two': ['four'], (1, 1): 4}
>>> d[2]
4
>>> d['two']
['four']
>>> d[(1, 1)]
4

可以使用 .keys()、.values() 或 .items() 来访问键、值或键值对的序列。

>>> for k in d.keys():
...     print(k)
...
2
two
(1, 1)
>>> for v in d.values():
...     print(v)
...
4
['four']
4
>>> for k, v in d.items():
...     print(k, v)
...
2 4
two ['four']
(1, 1) 4

默认情况下，遍历字典就是遍历它的键。

>>> for x in d:
...     print(x)
...
2
two
(1, 1)

你可以使用 in 来检查字典是否包含某个键：

>>> 'two' in d
True
>>> 4 in d
False

试图访问字典中不存在的键会导致错误。 你可以使用 .get(<key>, <default>)，它会返回字典中 <key> 对应的值，如果该键不存在，则返回 <default>。

>>> d[3]
KeyError: 3
>>> d.get(3, "fun")
"fun"
>>> d.get(2, "fun")
4

可以使用 = 修改字典的内容：

>>> d
{2: 4, 'two': ['four'], (1, 1): 4}
>>> d[(1, 1)] = "61a"
>>> d[(1, 1)]
'61a'

字典推导式是一个计算结果为新字典的表达式。

>>> {3*x: 3*x + 1 for x in range(2, 5)}
{6: 7, 9: 10, 12: 13}

树形递归

树形递归函数是一个递归函数，它对自己进行多次调用，从而形成树状的调用序列。

例如，下面是 Virahanka-Fibonacci（斐波那契）数列： 0, 1, 1, 2, 3, 5, 8, 13, ...。

每一项都是前两项之和。这个树形递归函数计算第 n 个 Virahanka-Fibonacci 数。

def virfib(n):
    if n == 0 or n == 1:
        return n
    return virfib(n - 1) + virfib(n - 2)

调用 virfib(6) 会得到一个类似于倒置的树（其中 f 表示 virfib）的调用结构：

每次递归调用 f(i) 都会调用 f(i-1) 和 f(i-2)。 当我们到达 f(0) 或 f(1) 调用时，可以直接返回 0 或 1， 而无需继续递归调用。这些调用就是我们的基例。

基例会在不依赖其他调用结果的情况下返回一个答案。 一旦到达基例，我们就可以回溯并解答导致该基例的那些递归调用。

正如我们将看到的，树形递归通常对具有分支选择的问题非常有效。 在这类问题中，你为每个分支选择进行一次递归调用。

数据抽象

数据抽象是一组函数的集合，用于组合和分解复合值。其中一个称为构造器的函数将两个部分或更多部分组合成一个整体（例如有理数，也就是分数），而其他称为选择器的函数则返回该整体的各个部分（例如分子或分母）。

def rational(n, d):
    "Return a fraction n / d for integers n and d."

def numer(r):
    "Return the numerator of rational number r."

def denom(r):
    "Return the denominator of rational number r."

关键在于，即使不知道这些函数是如何实现的，也可以使用数据抽象。例如，我们（人类）只要知道 rational、numer 和 denom 的作用，就可以验证 mul_rationals 的实现是否正确，而无需知道它们是如何实现的。

def mul_rationals(r1, r2):
    "Return the rational number r1 * r2."
    return rational(numer(r1) * numer(r2), denom(r1) * denom(r2))

然而，为了让 Python 能够运行程序，数据抽象需要一个实现。使用关于实现的内部知识会越过抽象屏障，它将程序的某个部分（依赖于数据抽象的实现）与其余部分（不依赖）分隔开来。一个编写良好的程序通常会尽量减少依赖实现的代码量，以便在日后更改实现时无需重写大量代码。

当你使用一个已经提供的数据抽象时，请将你的程序编写成：即使该数据抽象的实现发生改变，你的程序仍然能正确运行。

树

tree 是一种表示信息层级结构的数据结构。文件系统就是一个很好的树结构例子。例如，在你的 cs61a 文件夹中，你有用文件夹区分开的 projects（项目）、lab（实验）作业和 homework（作业）。下一级是用文件夹区分的不同作业，如 hw01、lab01、hog 等，而在这些文件夹内部则是文件本身，包括初始文件和 ok。下面是你 cs61a 目录可能呈现的样子（不完整示意图）。

正如你所看到的，与自然界中的树不同，树这种抽象数据类型的画法是将根画在顶部、将叶子画在底部。

对于一棵树 t：

  • 它的根标签可以是任意值，label(t) 返回该值。
  • 它的分支是树，branches(t) 返回一个分支的列表。
  • 可以用 tree(label(t), branches(t)) 构造出一棵完全相同的树。
  • 你可以调用以树为参数的函数，例如 is_leaf(t)。
  • 这就是你操作树的方式。不要使用 t == x、t[0]、x in t 或 list(t) 等。
  • 没有办法修改一棵树（除非违反抽象屏障）。

下面是一个树 t1 的例子，它的分支 branches(t1)[1] 是 t2。

t2 = tree(5, [tree(6), tree(7)])
t1 = tree(3, [tree(4), t2])

路径是一系列树，其中每个树都是下一个树的父节点。

我们的 tree 抽象数据类型由一个根和一份 branches（分支）列表组成。要创建一棵树并访问它的根值和分支，请使用以下构造器和选择器接口：

  • 构造器

    • tree(label, branches=[])：创建一个树对象，其根节点的值为给定的 label，分支列表为 branches。注意这个构造器的第二个参数 branches 是可选的——如果你想创建一棵没有分支的树，留空该参数即可。

  • 选择器

    • label(tree)：返回 tree 根节点中的值。
    • branches(tree)：返回给定 tree 的分支列表（每个分支本身也是一棵树）

  • 辅助函数

    • is_leaf(tree)：如果 tree 的 branches 列表为空，返回 True，否则返回 False。

例如，由以下代码生成的树：

number_tree = tree(1,
         [tree(2),
          tree(3,
               [tree(4),
                tree(5)]),
          tree(6,
               [tree(7)])])

看起来是这样的：

   1
 / | \
2  3  6
  / \  \
 4   5  7

要从这棵树中提取数字 3（它是第二个分支根节点的标签），我们要这样写：

label(branches(number_tree)[1])

print_tree 函数以一种人类可读的形式打印出一棵树。其精确形式遵循上面所示的模式：根节点不缩进，它的每个分支再缩进一级。

def print_tree(t, indent=0):
    """Print a representation of this tree in which each node is
    indented by two spaces times its depth from the root.

    >>> print_tree(tree(1))
    1
    >>> print_tree(tree(1, [tree(2)]))
    1
      2
    >>> numbers = tree(1, [tree(2), tree(3, [tree(4), tree(5)]), tree(6, [tree(7)])])
    >>> print_tree(numbers)
    1
      2
      3
        4
        5
      6
        7
    """
    print('  ' * indent + str(label(t)))
    for b in branches(t):
        print_tree(b, indent + 1)

Q9：树的数量

满二叉树是指每个节点有 2 个分支或 0 个分支，但绝不会只有 1 个分支的树。

请编写一个函数，返回恰好有 n 个叶子的不同满二叉树结构的数量。 查看文档测试，了解具有 1、2、3 个叶子的可能满二叉树结构的可视化示例。

提示：满二叉树可以通过将两棵更小的满二叉树连接到一个根节点上来构造。 如果两棵更小的满二叉树分别有 a 和 b 个叶子，那么新的满二叉树将有 a + b 个叶子。 例如，如下方第一张图所示，一个有 4 个叶子的满二叉树可以通过将一棵有 3 个叶子的满二叉树（黄色）与一棵有 1 个叶子的满二叉树（橙色）连接而成。 一个有 4 个叶子的满二叉树也可以通过将两棵各有 2 个叶子的满二叉树连接而成（第二张图）。
