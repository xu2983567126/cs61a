  • Scheme 表达式的求值包含哪三个步骤？
  • 首先求值运算符（确认它在当前帧中存在），然后求值各个操作数，最后将运算符应用于操作数。
  • 宏的作用是什么？
  • Scheme 中的宏让你能够在代码运行前对其改写，从而创建自己的命令。
  • 为什么尾递归在 Scheme 中是有益的？
  • 尾递归之所以有益，是因为它允许关闭将来不会再使用的帧，从而节省空间。

准引用

如果你需要复习准引用，可以参考下拉菜单。如果卡住了，也可以直接跳到题目，需要时再回来看这里。

普通的 quote ' 和 quasiquote ` 都是引用表达式的有效方式。然而，准引用后的表达式可以被 取消引用 通过 "unquote" ,（以逗号表示）。当准引用表达式中的某一项被 取消引用 时，被取消引用的项会 被求值，而不是作为字面文本处理。 这种机制有点类似于 Python 中的 f-strings，其中 表达式 {} 会被求值并插入到字符串中。

scm> (define a 5)
a
scm> (define b 3)
b
scm> `(* a b)  ; Quasiquoted expression
(* a b)
scm> `(* a ,b)  ; Unquoted b, which evaluates to 3
(* a 3)
scm> `(* ,(+ a b) b)  ; Unquoted (+ a b), which evaluates to 8
(* 8 b)

解释器

对于下面的题目，建议参考 Calculator 下拉菜单。如果你需要复习解释器，可以参考其他下拉菜单。如果卡住了，也可以直接跳到题目，需要时再回来看这里。

解释器是一个让你能够使用某种特定语言与计算机交互的程序。它接收你编写的代码，对其进行解释，然后执行相应的操作，通常是用一种更底层的语言来与计算机硬件通信。

在 Project 4 中，你将使用 Python 为 Scheme 编程语言开发一个解释器。有趣的是，你在本课程中一直使用的 Python 解释器主要是用 C 语言编写的。在最底层，计算机通过解释机器码来运行，机器码是一串 0 和 1，用于指示计算机执行算术运算和读取数据等基本任务。

当我们谈论解释器时，涉及两种不同的语言：

  1. 被解释的语言： 对于 Project 4，这就是 Scheme 语言。
  2. 实现语言： 这是用于创建 解释器本身的语言，对于 Project 4 而言是 Python。

REPL

解释器的一个常见特性是“读取-求值-打印”循环（REPL），它通过三个阶段循环处理用户输入：

  • 读取： 解释器首先读取用户输入的字符串。 这个输入会经过一个解析过程，包含两个关键步骤：

    • 首先是 词法分析 步骤将输入字符串拆分为一个个词元（token）， 这些词元是你所解释语言的基本元素或“单词”。它们表示输入中最小的语义单位。

    • 接下来是 语法分析 步骤，它接收上一步得到的词元，并将其组织成 底层语言能够理解的数据结构。对于我们 的 Scheme 解释器，我们把词元组装成一个 Link 对象（类似于 Link），用来表示原始调用表达式的结构。

      • 该 Link 中的第一项表示调用表达式的运算符，后续元素则是该运算所作用的操作数或参数。注意这些操作数本身也可以是调用表达式（嵌套表达式）。

下面是一个 Scheme 表达式输入的读取过程总结：


  • 求值： 这一步对你用该编程语言编写的表达式进行求值，以得到一个值。它涉及以下两个函数：

    • eval 接收一个表达式并根据语言的规则对其求值。 当表达式是一个调用表达式时，eval 使用 apply 函数来得到结果。 它会按顺序求值运算符及其操作数。例如，在 (add 1 2), eval 会识别 add 为运算符，并识别 1 和 2 为操作数。add 它会求值 1 以确保它是一个有效的函数（function），然后求值 2 和
    • apply 接收已求值的运算符（即函数）并将其应用于 已求值的操作数（即参数）。注意在这个过程中，apply 可能需要求值更多表达式（例如函数体中的表达式）。这正是 apply 可能会回调到 eval 的地方，因此这两个阶段是 相互递归.
  • 打印： 显示对用户输入求值的结果。

Calculator

解释器是一个执行程序的程序。今天，我们将扩展 Calculator 的解释器，Calculator 是一种简单的人造语言，是 Scheme 的一个子集。本实验类似于 Scheme 项目的精简版。

Calculator 语言只包含四种基本算术运算：+, -, *、以及 /。这些运算可以嵌套，也可以接收任意数量的参数，就像在 Scheme 中一样。下面展示了一些 Calculator 表达式及其对应的值。

 calc> (+ 2 2 2)
 6

 calc> (- 5)
 -5

 calc> (* (+ 1 2) (+ 2 3 4))
 27

Calculator 表达式用 Python 对象表示：

  • 数字用 Python 数字表示。
  • 算术运算的符号用 Python 字符串表示（例如 '+').
  • 调用表达式用下面的 Link 类表示。

为了在 Python 中表示 Scheme 列表，我们将使用 Link 类（在本实验和 Scheme 项目中都会用到）。一个 Link 实例有两个属性：first 和 rest. Link 总是接收两个参数。要创建一个列表，可以嵌套调用 Link，并将 nil 作为最后一个 Link 的第二个参数传入。

注意： 在 Python 代码中，nil 绑定到 Link.empty。nil类似地，Scheme 中的

例如，一旦我们的解释器读入 Scheme 表达式 (+ 2 3)，它就被表示为 Link('+', Link(2, Link(3, nil))).

>>> p = Link('+', Link(2, Link(3, nil)))
>>> p.first
'+'
>>> p.rest
Link(2, Link(3, nil))
>>> p.rest.first
2
>>> print(p)
(+ 2 3)

存在一个 map_link 函数，它接收一个单参数 Python 函数 f 和一个链表 s。它返回将 f 应用到 Scheme 列表的每个元素后得到的 Scheme 列表。

>>> map_link(lambda x: 2 * x, p.rest)
Link(4, Link(6, nil))

下面是 Link 类和 map_link 函数（__str__ 和 __repr__ 方法未 显示）。

class Link:
    """Represents the built-in Link data structure in Scheme."""
    empty = ()
    def __init__(self, first, rest):
        self.first = first
        self.rest = rest

nil = Link.empty

def map_link(f, s):
    """Map function f over linked list s.
    >>> square = lambda x: x * x
    >>> map_link(square, Link(1, Link(2, Link(3))))
    Link(1, Link(4, Link(9, nil)))
    """
    if s is Link.empty:
        return s
    return Link(f(s.first), map_link(f, s.rest))

Calculator 求值

对于问题 3（新过程），你需要更新下面的 calc_eval 函数，它用于求值一个 Calculator 表达式。对于问题 3，你需要确定在 Scheme 中，调用表达式的 operator 和 operands 是什么，以及如何在 calc_apply 行中将一个过程应用于参数。

def calc_eval(exp):
    """
    >>> calc_eval(Link("define", Link("a", Link(1, nil))))
    'a'
    >>> calc_eval("a")
    1
    >>> calc_eval(Link("+", Link(1, Link(2, nil))))
    3
    """
    if isinstance(exp, Link):

        operator = exp.first
        operands = exp.rest
        if operator == 'and': # and expressions
            return eval_and(operands)
        elif operator == 'define': # define expressions
            return eval_define(operands)
        else: # Call expressions

            return calc_apply(calc_eval(operator), map_link(calc_eval, operands))
    elif exp in OPERATORS:   # Looking up procedures
        return OPERATORS[exp]
    elif isinstance(exp, int) or isinstance(exp, bool):   # Numbers and booleans
        return exp
    elif exp in bindings:   # Looking up variables
        return bindings[exp]

Q3: 新过程

向 Calculator 添加 // 运算，这是一个整除过程，使得 (// dividend divisor) 返回 dividend 除以 divisor 的结果，忽略余数（Python 中的 dividend // divisor）。按照下面的示例处理多个输入：(// dividend divisor1 divisor2 divisor3) 在 Python 中求值为 (((dividend // divisor1) // divisor2) // divisor3)。假设每次对 // 的调用都至少有两个参数。

提示： 你需要同时修改 calc_eval 和 floor_div 方法！

calc> (// 1 1)
1
calc> (// 5 2)
2
calc> (// 28 (+ 1 1) 1)
14

提示： 确保 Link 中的每个元素（运算符和所有操作数）都会被求值 一次，这样我们才能正确地将相关的 Python 运算符应用于操作数！calc_eval-uated once so that we can correctly apply the relevant Python operator to operands!

def floor_div(args):
    """
    >>> floor_div(Link(100, Link(10, nil)))
    10
    >>> floor_div(Link(5, Link(3, nil)))
    1
    >>> floor_div(Link(1, Link(1, nil)))
    1
    >>> floor_div(Link(5, Link(2, nil)))
    2
    >>> floor_div(Link(23, Link(2, Link(5, nil))))
    2
    >>> calc_eval(Link("//", Link(4, Link(2, nil))))
    2
    >>> calc_eval(Link("//", Link(100, Link(2, Link(2, Link(2, Link(2, Link(2, nil))))))))
    3
    >>> calc_eval(Link("//", Link(100, Link(Link("+", Link(2, Link(3, nil))), nil))))
    20
    """

    result = args.first
    divisors = args.rest
    while divisors != nil:
        divisor = divisors.first
        result //= divisor
        divisors = divisors.rest
    return result

Q4: 新形式

向我们的 Calculator 解释器中添加 and 表达式，并引入 Scheme 布尔值 #t 和 #f，它们分别用 Python 的 True 和 False。 下面的示例假设条件运算符（例如 <, >, = 等）已经实现，但你不需要为这个问题担心。

calc> (and (= 1 1) 3)
3
calc> (and (+ 1 0) (< 1 0) (/ 1 0))
#f
calc> (and #f (+ 1 0))
#f
calc> (and 0 1 (+ 5 1)) ; 0 is a true value in Scheme!
6

在一个调用表达式中，我们首先求值运算符，然后求值操作数，最后将过程应用于其参数（就像你在上一题中为 floor_div 所做的那样）。and 表达式不能像调用表达式那样求值。由于 and 是一个特殊形式，会在第一个为假的操作数处短路，我们需要添加特殊逻辑，以避免总是求值所有子表达式。

重要：要检查某个 val 在 Scheme 中是否为假值，请使用 val is scheme_f 而不是 val == scheme_f，因为在 Python 中 0 == False 为假，但 0 is not False（很疯狂，对吧！）。

scheme_t = True   # Scheme's #t
scheme_f = False  # Scheme's #f

def eval_and(expressions):
    """
    >>> calc_eval(Link("and", Link(1, nil)))
    1
    >>> calc_eval(Link("and", Link(False, Link("1", nil))))
    False
    >>> calc_eval(Link("and", Link(1, Link(Link("//", Link(5, Link(2, nil))), nil))))
    2
    >>> calc_eval(Link("and", Link(Link('+', Link(1, Link(1, nil))), Link(3, nil))))
    3
    >>> calc_eval(Link("and", Link(Link('-', Link(1, Link(0, nil))), Link(Link('/', Link(5, Link(2, nil))), nil))))
    2.5
    >>> calc_eval(Link("and", Link(0, Link(1, nil))))
    1
    >>> calc_eval(Link("and", nil))
    True
    """

    curr, val = expressions, True
    while curr is not nil:
        val = calc_eval(curr.first)
        if val is scheme_f:
            return scheme_f
        curr = curr.rest
    return val

宏

如果你需要复习宏，可以参考下拉菜单。如果卡住了，也可以直接跳到题目，需要时再回来看这里。

宏是一种使用 define-macro 创建、并通过调用表达式应用的代码变换。宏调用的求值过程如下：

  1. 将宏的形式参数绑定到宏调用的 未求值 的操作数表达式。
  2. 对宏的函数体求值，它会返回一个表达式。
  3. 在原始宏调用的帧中对宏返回的表达式求值。
scm> (define-macro (twice expr) (list 'begin expr expr))
twice
scm> (twice (+ 2 2))  ; evaluates (begin (+ 2 2) (+ 2 2))
4
scm> (twice (print (+ 2 2)))  ; evaluates (begin (print (+ 2 2)) (print (+ 2 2)))
4
4

Q5: 重复

定义 repeat，一个接收数字 n 和表达式 expr 的宏。repeat 会在一个局部帧中将 expr 求值 n 次，其值为 最终结果。你会发现辅助函数 repeated-call 很有用，它接收一个数字 n 和一个无参过程 f，并将 f n 调用指定次数。

例如，(repeat (+ 2 3) (print 1)) 等价于：

(repeated-call (+ 2 3) (lambda () (print 1)))

并应将 (print 1) 重复求值 5 次。

下面的表达式应打印 four 四次：

(repeat 2 (repeat 2 (print 'four)))

(define-macro (repeat n expr)

  `(repeated-call ,n (lambda () ,expr)))

; 调用 zero-argument 过程 f n 次并返回最终结果。
(define (repeated-call n f)

  (if (= n 1) (f) (begin (f) (repeated-call (- n 1) f))))

使用 Ok 测试你的代码：

python3 ok -q repeat-lambda

过程接收一个无参过程，因此 repeated-call 必须出现在空白处。lambda 表达式的函数体是 (lambda () ___)，它必须被取消引用。expr, which must be unquoted.

用 f 以无参形式调用 (f)。如果 n 为 1，则直接调用 f。如果 n 大于 1，则先调用 f，然后再调用 (repeated-call (- n 1) f).


尾调用

尾调用复习

如果一个递归调用是函数所做的最后一件事，那么它就是一个尾调用。

尾调用示例：

(define (fact n total)
  (if (= n 0)
      total
      (fact (- n 1) (* total n))))

如上所示，最后发生的是对 fact 的调用。这个帧中已没有其余工作，因此我们可以关闭它并继续下一个。

非尾调用函数示例：

(define (fact n)
  (if (= n 0)
      1
      (* n (fact (- n 1)))))

如上所示，(fact (- n 1)) 调用必须先返回，然后再乘以 n。也就是说，我们必须保持该帧打开，直到调用完成并且我们可以进行乘法运算。

这一点很重要，因为尾递归函数使用 常量空间，而非尾递归函数可能使用线性或更多的空间。

递归调用返回后，是否还有剩余工作要做？

  • 如果有，那么它不是尾调用。
  • 如果没有，那么它就是尾调用。
