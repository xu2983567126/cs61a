反引号引用（Quasiquotation）

如果你需要复习反引号引用，请参考下面的折叠框。如果遇到困难，也可以直接跳到题目，再回来查阅本部分。

普通的 quote ' 和反引号引用 ` 都是引用表达式的有效方式。然而，被反引号引用的表达式可以通过“反引用”（unquote）符号 ,（用一个逗号表示）来“反引用”。当一个位于反引号引用表达式中的项被“反引用”时，该项会被 求值，而不是作为字面文本处理。 这种机制有点类似于 Python 中的 f-string，其中 {} 内的表达式会被求值并插入到字符串中。

scm> (define a 5)
a
scm> (define b 3)
b
scm> `(* a b)  ; 反引号引用的表达式
(* a b)
scm> `(* a ,b)  ; 反引用 b，它求值为 3
(* a 3)
scm> `(* ,(+ a b) b)  ; 反引用 (+ a b)，它求值为 8
(* 8 b)

解释器

对于下面的题目，建议先查阅 Calculator 折叠框。如果你需要复习解释器的内容，请参考其他折叠框。如果遇到困难，也可以直接跳到题目，再回来查阅本部分。

解释器（interpreter）是一个允许你使用某种特定语言与计算机交互的程序。它接收你编写的代码， 对其解释，然后执行相应的操作，通常 使用一种更底层的语言来与计算机硬件通信。

在项目 4 中，你将使用 Python 开发一个 Scheme 编程语言的解释器。有趣的是，你在本课程中一直使用的 Python 解释器主要是用 C 语言编写的。在最低层，计算机 通过解释机器码（machine code）来运行，机器码是一串由 0 和 1 组成的指令，指示计算机执行算术运算和数据检索等基本任务。

当我们谈论一个解释器时，涉及两种语言：

  1. 被解释的语言：对于项目 4，这就是 Scheme 语言。
  2. 实现语言：这是用于创建 解释器本身的语言，对于项目 4，它将是 Python。

REPL

解释器的一个常见特性是“读取-求值-打印循环”（REPL，Read-Eval-Print Loop），它通过三个阶段循环处理用户输入：

  • 读取（Read）：解释器首先读取用户提供的输入字符串。 这个输入会经过一个解析（parsing）过程，该过程包含两个关键步骤：

    • 词法分析（lexical analysis）步骤将输入字符串拆分为一个个词法单元（token）， 也就是你正在解释的这门语言中的基本元素或“单词”。 这些词法单元代表了输入中最小的意义单位。

    • 语法分析（syntactic analysis）步骤将上一步得到的词法单元组织成 底层语言能够理解的数据结构。对于我们的 Scheme 解释器，我们将词法单元组装成一个 Link 对象（类似于一个 Link），以表示原始调用表达式的结构。

      • Link 中的第一项表示调用表达式的运算符，后续元素则是操作数，即运算所作用的对象。注意，这些操作数本身也可以是调用表达式（嵌套表达式）。

下面是 Scheme 表达式输入的读取过程总结：


  • 求值（Eval）：这一步对你用该编程语言编写的表达式求值，以得到一个值。它涉及以下两个函数：

    • eval 接受一个表达式，并根据语言的规则对其求值。 当该表达式是一个调用表达式时，eval 使用 apply 函数来得到结果。 它会按顺序对运算符及其操作数求值。例如，在 (add 1 2) 中， eval 会将 add 识别为运算符，将 1 和 2 识别为操作数。 它会对 add 求值以确保它是一个有效的函数，然后对 1 和 2 求值以确保它们是有效的参数。
    • apply 接受已求值的运算符（即函数）并将其应用于 已求值的操作数（即参数）。注意，在此过程中，apply 可能需要对更多表达式求值（例如函数体中的那些表达式）。这正是 apply 可能回调 eval 的地方，因此这两个阶段是 相互递归的。
  • 打印（Print）：显示用户输入求值的结果。

下面是各部分是如何组合在一起的：

求值

要使用解释器对表达式 (+ (* 3 4) 5) 求值，会按以下顺序对以下表达式调用 scheme_eval：

  1. (+ (* 3 4) 5)
  2. +
  3. (* 3 4)
  4. *
  5. 3
  6. 4
  7. 5

* 被求值，因为它是 (* 3 4) 的运算符子表达式， 而 (* 3 4) 又是 (+ (* 3 4) 5) 的操作数子表达式。

默认情况下，* 求值为一个将其参数相乘的过程。 但 * 随时可能被重新定义，因此每次使用符号 * 时都必须对其求值，以查找其当前值。

scm> (* 2 3)  ; 此时它做乘法
6
scm> (define * +)
*
scm> (* 2 3)  ; 此时它做加法
5

Calculator

解释器是一个执行程序的程序。今天，我们将扩展 Calculator 的解释器，Calculator 是一种简单的虚构语言，是 Scheme 的一个子集。本实验就像是 Scheme 项目的迷你版。

Calculator 语言只包含四种基本的算术运算：+、-、* 和 /。这些运算可以嵌套，并且可以接受数量不定的参数，就像在 Scheme 中一样。下面是一些 Calculator 表达式及其对应值的例子：

 calc> (+ 2 2 2)
 6

 calc> (- 5)
 -5

 calc> (* (+ 1 2) (+ 2 3 4))
 27

Calculator 表达式用 Python 对象表示：

  • 数字用 Python 数字表示。
  • 算术运算的符号用 Python 字符串表示（例如 '+'）。
  • 调用表达式用下面的 Link 类表示。

为了在 Python 中表示 Scheme 列表，我们将使用 Link 类（在本实验和 Scheme 项目中都是如此）。一个 Link 实例有两个属性：first 和 rest。Link 总是接受两个参数来调用。要创建一个列表，请嵌套调用 Link，并将 nil 作为最后一个 Link 的第二个参数传入。

注意： 在 Python 代码中，nil 绑定到 Link.empty。 类似地，Scheme 中的 nil 求值为一个空列表。

例如，一旦我们的解释器读入 Scheme 表达式 (+ 2 3)，它就被表示为 Link('+', Link(2, Link(3, nil)))。

>>> p = Link('+', Link(2, Link(3, nil)))
>>> p.first
'+'
>>> p.rest
Link(2, Link(3, nil))
>>> p.rest.first
2
>>> print(p)
(+ 2 3)

有一个 map_link 函数，它接受一个单参数的 Python 函数 f 和一个链表 s。它返回对 Scheme 列表中每个元素应用 f 后得到的 Scheme 列表。

>>> map_link(lambda x: 2 * x, p.rest)
Link(4, Link(6, nil))

下面是 Link 类和 map_link 函数（未显示 __str__ 和 __repr__ 方法）。

class Link:
    """Represents the built-in Link data structure in Scheme."""
    empty = ()
    def __init__(self, first, rest):
        self.first = first
        self.rest = rest

nil = Link.empty

def map_link(f, s):
    """Map function f over linked list s.
    >>> square = lambda x: x * x
    >>> map_link(square, Link(1, Link(2, Link(3))))
    Link(1, Link(4, Link(9, nil)))
    """
    if s is Link.empty:
        return s
    return Link(f(s.first), map_link(f, s.rest))

宏（Macros）

如果你需要复习宏，请参考下面的折叠框。如果遇到困难，也可以直接跳到题目，再回来查阅本部分。

宏是一种使用 define-macro 创建、并通过调用表达式应用的代码转换。一次宏调用的求值过程如下：

  1. 将宏的形式参数绑定到宏调用中那些 未求值 的操作数表达式。
  2. 对宏的函数体求值，它会返回一个表达式。
  3. 在原宏调用的帧中，对宏返回的表达式求值。
scm> (define-macro (twice expr) (list 'begin expr expr))
twice
scm> (twice (+ 2 2))  ; 求值 (begin (+ 2 2) (+ 2 2))
4
scm> (twice (print (+ 2 2)))  ; 求值 (begin (print (+ 2 2)) (print (+ 2 2)))
4
4

Q5：重复

定义 repeat，它是一个宏，接受一个数字 n 和一个表达式 expr。调用 repeat 会在一个局部帧中对 expr 求值 n 次，其值为 最后的结果。你会发现辅助函数 repeated-call 很有用，它接受一个数字 n 和一个无参过程 f，并将 f 调用 n 次。

例如，(repeat (+ 2 3) (print 1)) 等价于：

(repeated-call (+ 2 3) (lambda () (print 1)))

它应该将 (print 1) 重复求值 5 次。

下面的表达式应该将 four 打印四次：

(repeat 2 (repeat 2 (print 'four)))

(define-macro (repeat n expr)
  `(repeated-call ,n ___))

尾调用

尾调用复习

如果一个递归调用是函数所做的 最后一件事，那么它就是尾调用。

尾调用的例子：

(define (fact n total)
  (if (= n 0)
      total
      (fact (- n 1) (* total n))))

如你所见，最后发生的事情是对 fact 的一次调用。这个帧中没有任何剩余工作要做，因此我们可以关闭它并进入下一个。

不带尾调用的函数例子：

(define (fact n)
  (if (= n 0)
      1
      (* n (fact (- n 1)))))

如你所见，(fact (- n 1)) 调用必须先返回，然后才能与 n 相乘。也就是说，我们必须保持该帧打开，直到调用完成并且我们可以进行乘法运算。

这一点很重要，因为尾递归函数使用 常数空间，而非尾递归函数可能使用线性或更多的空间。

在递归调用返回后，还有任何工作要做吗？

  • 如果有，那么它不是尾调用。
  • 如果没有，那么它就是尾调用。
