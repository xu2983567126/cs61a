Scheme

Scheme 是 1970 年代一种著名的函数式编程语言。它是 Lisp（即 LISt Processing 列表处理）的一种方言。Scheme 的语法非常独特：它使用前缀表示法和许多嵌套的括号（参见 http://xkcd.com/297/）。Scheme 具有一等函数和经过优化的尾递归，这些特性在 Scheme 被引入时还相当新颖。

Scheme 规范与内置过程参考是了解 Scheme 语法的良好参考资料。

原子表达式（也称为 原子）是不包含子表达式的表达式，例如数字、布尔值和符号。

scm> 1234    ; integer
1234
scm> 123.4   ; real number
123.4
scm> #f      ; the Scheme equivalent of False in Python
#f

一个 Scheme 符号 等价于一个 Python 名称。符号会求值为在当前环境中绑定到该符号的值。（它们被称为符号而不是名称，是因为它们包含 + 以及其他算术符号。）

scm> quotient      ; A symbol bound to a built-in procedure
#[quotient]
scm> +             ; A symbol bound to a built-in procedure
#[+]

在 Scheme 中，所有 的值（除了 #f，等价于 Python 中的 False）都是真值 （不像 Python 那样还有其他假值，例如 0）。

scm> #t
#t
scm> #f
#f

Scheme 中所有非基本表达式被称为 组合式， 并具有如下语法：

(<operator> <operand1> <operand2> ...)

组合式是组合多个表达式的表达式。在这里， <operator>、<operand1> 和 <operand2>。都是表达式。操作数的数量取决于运算符。组合式有两种类型：

  1. 一个 调用表达式，其运算符求值为一个过程
  2. 一个 特殊形式表达式，其运算符是一个特殊形式

Scheme 使用波兰前缀表示法，其中运算符表达式位于 操作数表达式之前。例如，要计算 3 * (4 + 2)，我们这样写：

scm> (* 3 (+ 4 2))
18

就像在 Python 中一样，计算一个调用表达式时：

    计算运算符。它应当求值为一个过程。
  1. Evaluate the operator. It should evaluate to a procedure.
    2. 从左到右计算操作数。
  2. Evaluate the operands, left to right.
    3. 将过程应用于已计算的操作数。
  3. Apply the procedure to the evaluated operands.

以下是一些使用内置过程的例子：

scm> (+ 1 2)
3
scm> (- 10 (/ 6 2))
7
scm> (modulo 35 4)
3
scm> (even? (quotient 45 2))
#t

Define： The define 形式用于给符号赋值。它具有如下语法：

(define <symbol> <expression>)
scm> (define pi (+ 3 0.14))
pi
scm> pi
3.14

要计算 define 表达式：

    计算最后一个子表达式（
  1. ，在本例中它求值为 <expression>。3.14。
    2. 将该值绑定到符号（
  2. ，在本例中为 symbol。pi。
    3. 返回该符号。
  3. Return the symbol.

的 define 形式也可以定义新的过程，详见“定义函数”一节。

If 表达式： The if 特殊形式根据一个谓词来计算两个表达式中的一个。

(if <predicate> <if-true> <if-false>)

计算一个 if 特殊形式表达式的规则如下：

  1. 计算 <predicate>。
    2. 如果
  2. 求值为真值（除了 <predicate> 之外的任何值），则计算 并返回 #f 表达式的值。否则，计算并返回 <if-true> 表达式的值。<if-false> expression.

例如，这个表达式不会报错，并且求值为 5，即使子表达式 (/ 1 (- x 3)) 如果单独求值会报错。

scm> (define x 3)
x
scm> (if (> (- x 3) 0) (/ 1 (- x 3)) (+ x 2))
5

的 <if-false> 表达式是可选的。

scm> (if (= x 3) (print x))
3

让我们将一个 Scheme 的 if 表达式与一个 Python 的 if 语句进行比较：

  • 在 Scheme 中：
(if (> x 3) 1 2)
  • 在 Python 中：
if x > 3:
    1
else:
    2

Scheme 的 if 表达式求值为一个数字（1 或 2，取决于 x）。Python 的语句不求值为任何值，因此 1 和 2 无法被使用或访问。

两者之间的另一个区别是，可以将更多行代码 添加到 Python 的 if 语句的语句体中，而一个 Scheme 的 if 表达式在每个 <if-true> 和 <if-false> 位置都只期望单个表达式。

最后一个区别是，在 Scheme 中，你不能编写 elif 子句。

Cond 表达式： The cond 特殊形式可以包含多个谓词（类似于 Python 中的 if/elif）：

(cond
    (<p1> <e1>)
    (<p2> <e2>)
    ...
    (<pn> <en>)
    (else <else-expression>))

每个子句中的第一个表达式是一个谓词。子句中的第二个表达式 是与该谓词对应的返回表达式。else 子句是可选的；它的 <else-expression> 是在所有谓词都不为真时的返回表达式。

求值规则如下：

    按顺序计算谓词
  1. 、<p1>、……、<p2>，直到其中一个 求值为真值（除了 <pn> 之外的任何值）。#f).
    2. 计算并返回对应于第一个为真值的谓词的返回表达式的值。
  2. Evalaute and return the value of the return expression corresponding to the first predicate expression with a true value.
    3. 如果没有任何谓词求值为真值，并且存在
  3. 子句，则计算并返回 else。<else-expression>.

例如，这个 cond 表达式返回距离 x：

scm> (define x 5)
x
scm> (cond ((= (modulo x 3) 0) x)
            ((= (modulo x 3) 1) (- x 1))
            ((= (modulo x 3) 2) (+ x 1)))
6


Lambdas： The lambda 特殊形式会创建一个过程。

(lambda (<param1> <param2> ...) <body>)

这个表达式会创建并返回一个具有给定形式参数和函数体的过程，类似于 Python 中的 lambda 表达式。

scm> (lambda (x y) (+ x y))        ; Returns a lambda procedure, but doesn't assign it to a name
(lambda (x y) (+ x y))
scm> ((lambda (x y) (+ x y)) 3 4)  ; Create and call a lambda procedure in one line
7

以下是在 Python 中等价的表达式：

>>> lambda x, y: x + y
<function <lambda> at ...>
>>> (lambda x, y: x + y)(3, 4)
7

的 <body> 可以包含多个表达式。一个 Scheme 过程会返回 其函数体中最后一个表达式的值。

的 define 形式可以创建一个过程并给它命名：

(define (<symbol> <param1> <param2> ...) <body>)

例如，这是我们定义 double 过程的方式：

scm> (define (double x) (* x 2))
double
scm> (double 3)
6

这是一个带有三个参数的例子：

scm> (define (add-then-mul x y z)
        (* (+ x y) z))
scm> (add-then-mul 3 4 5)
35

当 define 表达式被求值时，会发生以下情况：

  1. 使用给定的参数和 <body>。
    2. 将该过程绑定到
  2. （当前帧中的 <symbol>）。
    3. 返回
  3. 。<symbol>.

下面这两个表达式是等价的：

scm> (define add (lambda (x y) (+ x y)))
add
scm> (define (add x y) (+ x y))
add

在阅读本节时，你可能难以理解 Scheme 容器的各种表示形式之间的区别。我们 建议你使用 我们的在线 Scheme 解释器 来查看你难以想象的配对与列表的盒子-指针图！（使用命令 (autodraw) 来切换图形的自动绘制。）

列表

Scheme 列表与我们之前在 Python 中使用的链表非常相似。就像一个链表是由一系列 Link 对象构成一样，一个 Scheme 列表是由一系列配对构成的，这些配对通过构造函数 cons。

Scheme 列表要求 cdr 要么是另一个列表，要么是 nil（一个空列表）。 列表在解释器中显示为一系列值（类似于 __str__ 对 Link 对象的表示）。例如，

scm> (cons 1 (cons 2 (cons 3 nil)))
(1 2 3)

在这里，我们确保了每个 cons 表达式的第二个参数是 另一个 cons 表达式或 nil。

我们可以使用 car 和 cdr 过程从列表中获取值，它们现在的工作方式类似于 Python 中 Link 的 first 和 rest 属性。 （好奇这些奇怪的名字从何而来？ 查看它们的词源。)

scm> (define a (cons 1 (cons 2 (cons 3 nil))))  ; Assign the list to the name a
a
scm> a
(1 2 3)
scm> (car a)
1
scm> (cdr a)
(2 3)
scm> (car (cdr (cdr a)))
3

如果你没有将一个配对或 nil 作为第二个参数传给 cons，它将会 报错：

scm> (cons 1 2)
Error

list 过程

还有其他几种创建列表的方式。list 过程接受任意数量的参数，并用这些参数的值构造一个列表：

scm> (list 1 2 3)
(1 2 3)
scm> (list 1 (list 2 3) 4)
(1 (2 3) 4)
scm> (list (cons 1 (cons 2 nil)) 3 4)
((1 2) 3 4)

注意，该表达式中的所有操作数在放入结果列表之前都会被求值。

引用形式（Quote）

我们也可以使用 quote 形式来创建一个列表，它会构造所给的精确列表。与 list 过程不同，' 的参数是 不 被求值的。

scm> '(1 2 3)
(1 2 3)
scm> '(cons 1 2)           ; Argument to quote is not evaluated
(cons 1 2)
scm> '(1 (2 3 4))
(1 (2 3 4))

用于列表的内置过程

Scheme 中还有几个其他用于列表的内置过程。 在解释器中试一试吧！

scm> (null? nil)                ; Checks if a value is the empty list
True
scm> (append '(1 2 3) '(4 5 6)) ; Concatenates two lists
(1 2 3 4 5 6)
scm> (length '(1 2 3 4 5))      ; Returns the number of elements in a list
5
scm> (list-ref '(1 2 3 4 5) 2)  ; Returns the element at a given index (0-indexed)
3
scm> (car '(1 2 3))             ; Returns the first element of a list
1
scm> (cdr '(1 2 3))             ; Returns all elements after the first
(2 3)
scm> (reverse '(1 2 3 4 5))     ; Reverses the order of a list
(5 4 3 2 1)

用于列表的高阶过程

map、filter 和 reduce 让你无需编写显式的递归就能变换或处理列表。

scm> (map (lambda (x) (* x x)) '(1 2 3 4)) ; Applies a procedure to every element
(1 4 9 16)
scm> (filter (lambda (x) (> x 2)) '(1 2 3 4)) ; Keeps only elements that satisfy a predicate
(3 4)
scm> (reduce + '(1 2 3 4))      ; Combines all elements using a procedure, left to right
10

一种有助于理解它们之间区别的方式：

    —— 变换每个元素，保持元素数量不变。 就像你沿着列表走，把每一项替换为
  • map。(fn item).
    • —— 保留或丢弃每个元素，但从不修改。 测试一个是非谓词，如果是则保留原样，如果不是则丢弃。
  • filter — Keeps or drops each element, but never changes. Tests a yes/no predicate, if yes it stays as it is and if no it is dropped.
  • reduce —— 将整个列表折叠为单个值（使用一个从左到右的组合过程）

这三种过程通常可以替代原本需要带有基例和递归例的递归函数。 看看其中一个手动写出来可能是什么样子，或许对你有所帮助：

手动编写 map：

scm> (define (my-map fn lst)
       (if (null? lst)
           nil
           (cons (fn (car lst)) (my-map fn (cdr lst)))))
scm> (my-map (lambda (x) (* x x)) '(1 2 3 4))
(1 4 9 16)

由此看来，这三种高阶过程只是 Scheme 为你内置的常见递归模式。 map 举例来说，只是为你完成了 cons、cdr 以及基例的工作！

Q1：大于还是小于

定义一个过程 over-or-under，它接受一个数字 num1 和一个数字 num2 并返回如下结果：

  • -1，如果 num1 小于 num2
  • 0，如果 num1 等于 num2
  • 1，如果 num1 大于 num2

注意： 请记住，Scheme 中的每个括号都会产生一次函数调用。例如，仅仅输入 0 在 Scheme 解释器中就会返回 0。(0) 然而，输入 0 会导致错误，因为

不是一个函数。

挑战：使用 if 和 cond 以两种不同的方式实现它！

(define (over-or-under num1 num2)

  (cond
    ((< num1 num2) -1)
    ((= num1 num2) 0)
    (else 1))

)

使用 ok 测试你的代码：

python3 ok -q over_or_under

Q2：组合

编写过程 composed，它接受过程 f 和 g 并返回一个新过程。这个新过程接受一个数字 x 并返回调用 f 作用于 g 的结果。x。

注意： 记住要使用 Scheme 语法 来调用函数。其形式是 (func arg)，而不是 func(arg)。

(define (composed f g)

  (lambda (x) (f (g x)))
)

使用 ok 测试你的代码：

python3 ok -q composed

Q3：重复

编写过程 repeat，它接受一个过程 f 和一个数字 n，并输出一个新过程。这个新过程接受一个数字 x 并返回调用 f 作用于 x 总共 n 次的结果。例如：

scm> (define (square x) (* x x))
square
scm> ((repeat square 2) 5) ; (square (square 5))
625
scm> ((repeat square 3) 3) ; (square (square (square 3)))
6561
scm> ((repeat square 1) 7) ; (square 7)
49

提示： 你在上一题编写的 composed 函数可能会很有用。

(define (repeat f n)

  ; note: this relies on `composed` being implemented correctly
  (if (< n 1)
    (lambda (x) x)
    (composed f (repeat f (- n 1))))
)

使用 ok 测试你的代码：

python3 ok -q repeat

Q6：去除重复

实现 without-duplicates，它接受一个数字列表 lst 作为输入，并返回一个列表，该列表包含 lst 中各个元素首次出现的顺序，但不包含重复项。例如，(without-duplicates (list 5 4 5 4 2 2)) 求值为 (5 4 2)。

提示：要测试两个数字是否相等，请使用 = 过程。要测试 两个数字是否不相等，请使用 not 过程，并结合 =。filter你可能会发现使用 lambda 过程，并配合一个辅助的

函数作为过滤器会很有帮助。 
(define (without-duplicates lst)

  (if (null? lst) lst
    (cons (car lst)
      (without-duplicates (filter (lambda (x) (not (= (car lst) x))) (cdr lst)))))
)
