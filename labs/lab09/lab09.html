Scheme

Scheme 是 1970 年代著名的函数式编程语言。它是 Lisp（LISt Processing，即列表处理）的一种方言。Scheme 的语法非常独特：它使用前缀表示法以及大量嵌套的括号（参见 http://xkcd.com/297/）。Scheme 具有一等函数（first-class functions）和优化的尾递归，这些特性在 Scheme 被提出时还相当新颖。

Scheme 规范和内置过程参考是查询 Scheme 语法的好帮手。

如果你需要复习 Scheme / Scheme 列表的内容，请参考下面的折叠框。如果遇到困难，也可以直接跳到 题目，再回来查阅本部分。

原子表达式（也称为 原子，atoms）是不含子表达式的表达式，例如数字、布尔值和符号。

scm> 1234    ; integer
1234
scm> 123.4   ; real number
123.4
scm> #f      ; Scheme 中相当于 Python 里的 False
#f

Scheme 的 符号（symbol）相当于 Python 中的名称。符号会在当前环境中求值（evaluate）为该符号所绑定的值。（它们被称为符号而不是名称，是因为它们还包含 + 等算术符号。）

scm> quotient      ; 绑定到内置过程的符号
#[quotient]
scm> +             ; 绑定到内置过程的符号
#[+]

在 Scheme 中，除了 #f（相当于 Python 中的 False）之外的 所有 值都是真值 （与 Python 不同，Python 还有其他为假的值，例如 0）。

scm> #t
#t
scm> #f
#f

Scheme 中所有非基本表达式都被称为 组合式（combinations），并具有以下语法：

(<operator> <operand1> <operand2> ...)

组合式是将多个表达式组合在一起的表达式。这里的 <operator>、<operand1> 和 <operand2> 都是表达式。操作数的数量取决于运算符。组合式有两种类型：

  1. 调用表达式（call expression），其运算符求值后是一个过程
  2. 特殊形式表达式（special form expression），其运算符是一种特殊形式

Scheme 使用波兰前缀表示法（Polish prefix notation），即运算符表达式出现在 操作数表达式之前。例如，要计算 3 * (4 + 2)，我们写成：

scm> (* 3 (+ 4 2))
18

就像在 Python 中一样，调用表达式的求值过程如下：

  1. 对运算符求值。它应当求值后得到一个过程。
  2. 从左到右求值各个操作数。
  3. 将该过程应用于已求值的操作数。

下面是一些使用内置过程的例子：

scm> (+ 1 2)
3
scm> (- 10 (/ 6 2))
7
scm> (modulo 35 4)
3
scm> (even? (quotient 45 2))
#t

Define（定义）： define 形式用于给符号赋值。它的语法如下：

(define <symbol> <expression>)
scm> (define pi (+ 3 0.14))
pi
scm> pi
3.14

对 define 表达式求值的步骤如下：

  1. 对最后一个子表达式（<expression>）求值，在本例中它求值得到 3.14。
  2. 将该值绑定到符号（symbol），在本例中为 pi。
  3. 返回该符号。

define 形式也可以定义新过程，详见“定义函数”一节。

If 表达式： if 特殊形式根据一个谓词（predicate）来求值两个表达式中的一个。

(if <predicate> <if-true> <if-false>)

对 if 特殊形式表达式求值的规则如下：

  1. 对 <predicate> 求值。
  2. 如果 <predicate> 求值得到真值（除 #f 以外的任何值），则求值 并返回 <if-true> 表达式的值。否则，求值并返回 <if-false> 表达式的值。

例如，这个表达式不会报错，并返回 5，即使子表达式 (/ 1 (- x 3)) 如果被求值会报错。

scm> (define x 3)
x
scm> (if (> (- x 3) 0) (/ 1 (- x 3)) (+ x 2))
5

<if-false> 表达式是可选的。

scm> (if (= x 3) (print x))
3

让我们将 Scheme 的 if 表达式与 Python 的 if 语句做个比较：

  • 在 Scheme 中：
(if (> x 3) 1 2)
  • 在 Python 中：
if x > 3:
    1
else:
    2

Scheme 的 if 表达式求值得到一个数字（根据 x 的值，为 1 或 2）。Python 的语句不会求值得到任何东西，因此 1 和 2 无法被使用或访问。

两者另一个不同之处在于，你可以在 Python 的 if 语句的代码块中添加更多行代码，而 Scheme 的 if 表达式在 <if-true> 和 <if-false> 两个位置处都只期望有一个表达式。

最后一个不同之处是，在 Scheme 中你无法编写 elif 子句。

Cond 表达式： cond 特殊形式可以包含多个谓词（类似于 Python 中的 if/elif）：

(cond
    (<p1> <e1>)
    (<p2> <e2>)
    ...
    (<pn> <en>)
    (else <else-expression>))

每个子句中的第一个表达式是谓词。该子句中的第二个表达式是与其谓词相对应的返回表达式。else 子句是可选的；如果没有任何谓词为真，其 <else-expression> 就是返回表达式。

求值的规则如下：

  1. 依次对谓词 <p1>、<p2>、……、<pn> 求值，直到其中一个 求值得到真值（除 #f 以外的任何值）。
  2. 求值并返回第一个求值为真值的谓词所对应的返回表达式的值。
  3. 如果没有任何谓词求值为真值，并且存在 else 子句，则求值并返回 <else-expression>。

例如，下面这个 cond 表达式返回距离 x 最近的 3 的倍数：

scm> (define x 5)
x
scm> (cond ((= (modulo x 3) 0) x)
            ((= (modulo x 3) 1) (- x 1))
            ((= (modulo x 3) 2) (+ x 1)))
6


Lambdas（lambda 表达式）： lambda 特殊形式用于创建一个过程。

(lambda (<param1> <param2> ...) <body>)

这个表达式会创建并返回一个具有给定形式参数和函数体的过程，类似于 Python 中的 lambda 表达式。

scm> (lambda (x y) (+ x y))        ; 返回一个 lambda 过程，但没有将其绑定到某个名字
(lambda (x y) (+ x y))
scm> ((lambda (x y) (+ x y)) 3 4)  ; 在一行内创建并调用一个 lambda 过程
7

下面是 Python 中对应的等价表达式：

>>> lambda x, y: x + y
<function <lambda> at ...>
>>> (lambda x, y: x + y)(3, 4)
7

<body> 可以包含多个表达式。Scheme 过程会返回其函数体中最后一个表达式的值。

define 形式可以创建一个过程并给它命名：

(define (<symbol> <param1> <param2> ...) <body>)

例如，下面是我们定义 double 过程的方式：

scm> (define (double x) (* x 2))
double
scm> (double 3)
6

下面是一个带三个参数的例子：

scm> (define (add-then-mul x y z)
        (* (+ x y) z))
scm> (add-then-mul 3 4 5)
35

当对一个 define 表达式求值时，会发生以下事情：

  1. 创建一个具有给定参数和 <body> 的过程。
  2. 将该过程绑定到当前帧中的 <symbol>。
  3. 返回 <symbol>。

下面两个表达式等价：

scm> (define add (lambda (x y) (+ x y)))
add
scm> (define (add x y) (+ x y))
add

在阅读本节时，你可能很难理解 Scheme 中各种容器表示方式之间的区别。我们 建议你使用 我们的在线 Scheme 解释器 来查看你难以可视化的序对（pair）和列表的盒子-指针图！（使用命令 (autodraw) 来切换是否自动绘制图示。）

列表

Scheme 列表与我们一直在 Python 中使用的链表非常相似。就像一个链表是由一系列 Link 对象构成的一样，Scheme 列表是由一系列序对（pair）构成的，这些序对通过构造函数 cons 创建。

Scheme 列表要求 cdr 要么是另一个列表，要么是 nil（空列表）。 列表在解释器中显示为一系列值（类似于 Link 对象的 __str__ 表示）。 例如，

scm> (cons 1 (cons 2 (cons 3 nil)))
(1 2 3)

这里，我们确保每个 cons 表达式的第二个参数 是另一个 cons 表达式或 nil。

我们可以使用 car 和 cdr 过程从列表中取出值，它们 现在的工作方式类似于 Python 中 Link 的 first 和 rest 属性。 （好奇这些奇怪名字的由来吗？可以查看它们的词源。）

scm> (define a (cons 1 (cons 2 (cons 3 nil))))  ; 将列表赋值给名字 a
a
scm> a
(1 2 3)
scm> (car a)
1
scm> (cdr a)
(2 3)
scm> (car (cdr (cdr a)))
3

如果你在调用 cons 时没有将序对或 nil 作为第二个参数传入，它会 报错：

scm> (cons 1 2)
Error

list 过程

还有其他几种创建列表的方式。list 过程接受任意数量的参数，并用这些 参数的值构造出一个列表：

scm> (list 1 2 3)
(1 2 3)
scm> (list 1 (list 2 3) 4)
(1 (2 3) 4)
scm> (list (cons 1 (cons 2 nil)) 3 4)
((1 2) 3 4)

注意，这个表达式中所有操作数在放入结果列表之前都会被先求值。

Quote 形式

我们也可以使用 quote 形式来创建一个列表，它会构造出所给的确切列表。与 list 过程不同，传给 ' 的参数 不会 被求值。

scm> '(1 2 3)
(1 2 3)
scm> '(cons 1 2)           ; quote 的参数不会被求值
(cons 1 2)
scm> '(1 (2 3 4))
(1 (2 3 4))

列表的内置过程

Scheme 中还有一些用于列表的内置过程。 在解释器中试一试吧！

scm> (null? nil)                ; 检查一个值是否为空列表
True
scm> (append '(1 2 3) '(4 5 6)) ; 拼接两个列表
(1 2 3 4 5 6)
scm> (length '(1 2 3 4 5))      ; 返回列表中元素的数量
5
scm> (list-ref '(1 2 3 4 5) 2)  ; 返回给定索引处（从 0 开始）的元素
3
scm> (car '(1 2 3))             ; 返回列表的第一个元素
1
scm> (cdr '(1 2 3))             ; 返回第一个元素之后的所有元素
(2 3)
scm> (reverse '(1 2 3 4 5))     ; 反转列表的顺序
(5 4 3 2 1)

列表的高阶过程

map、filter 和 reduce 让你无需编写显式的递归就能转换或处理列表。

scm> (map (lambda (x) (* x x)) '(1 2 3 4)) ; 将过程应用于每个元素
(1 4 9 16)
scm> (filter (lambda (x) (> x 2)) '(1 2 3 4)) ; 只保留满足谓词的元素
(3 4)
scm> (reduce + '(1 2 3 4))      ; 使用过程从左到右将所有元素合并
10

区分它们的一个有用方式：

  • map —— 转换每个元素，保持元素数量不变。 就像你遍历列表，把每个元素替换为 (fn item)。
  • filter —— 保留或丢弃每个元素，但从不改变元素本身。 测试一个是非判断，如果是则原样保留，如果否就丢弃。
  • reduce —— 将整个列表折叠（collapse）为单个值（使用一个从左到右的合并过程）

这三个过程通常可以取代原本需要写出带基准情形和递归情形的递归函数。 看看其中一个如果手动写出来会是什么样，也许对你有帮助：

手写 map：

scm> (define (my-map fn lst)
       (if (null? lst)
           nil
           (cons (fn (car lst)) (my-map fn (cdr lst)))))
scm> (my-map (lambda (x) (* x x)) '(1 2 3 4))
(1 4 9 16)

由此可见，这三个高阶过程其实就是 Scheme 为你内置的常见递归模式。 例如 map 就自动帮你做了 cons、cdr 和基准情形的工作！

Q1：大于还是小于

定义一个过程 over-or-under，它接受数字 num1 和 num2，并返回以下内容：

  • 如果 num1 小于 num2，返回 -1
  • 如果 num1 等于 num2，返回 0
  • 如果 num1 大于 num2，返回 1

注意： 记住 Scheme 中的每一个括号都意味着一次函数调用。例如，在 Scheme 解释器中只输入 0 会返回 0。然而，输入 (0) 会导致错误，因为 0 不是函数。

挑战：用 if 和 cond 两种不同的方式来实现它！

(define (over-or-under num1 num2)
  'YOUR-CODE-HERE
)

Q3：重复

编写过程 repeat，它接受一个过程 f 和一个数字 n，并输出一个新的过程。这个新过程接受一个数字 x，并返回对 x 总共调用 f n 次的结果。例如：

scm> (define (square x) (* x x))
square
scm> ((repeat square 2) 5) ; (square (square 5))
625
scm> ((repeat square 3) 3) ; (square (square (square 3)))
6561
scm> ((repeat square 1) 7) ; (square 7)
49

提示： 你在上一题写的 composed 函数可能会很有用。

(define (repeat f n)
  'YOUR-CODE-HERE
)

使用 Ok 测试你的代码：

python3 ok -q repeat
