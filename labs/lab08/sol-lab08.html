链表

如果你需要复习链表，可以查看下拉菜单。直接跳到题目，并在卡住时 回到此处参考也是可以的。

链表是一种用于存储值序列的数据结构。对于某些操作（例如在长列表中间插入一个值），它比普通的内置列表更高效。链表不是内置的，因此我们定义了一个名为 Link 来表示它们。 链表要么是 Link 的实例，要么是 Link.empty （表示一个空链表）。

的一个实例Link 有两个实例属性，first 和 rest。

的 rest 属性属于一个 Link 实例应当始终是一个链表：要么是 另一个 Link 实例，要么是 Link.empty。它绝不应该 是 None。

class Link:
    """A linked list is either a Link object or Link.empty

    >>> s = Link(3, Link(4, Link(5)))
    >>> s.rest
    Link(4, Link(5))
    >>> s.rest.rest.rest is Link.empty
    True
    >>> s.rest.first * 2
    8
    >>> print(s)
    (3 4 5)
    """
    empty = ()

    def __init__(self, first, rest=empty):
        assert rest is Link.empty or isinstance(rest, Link)
        self.first = first
        self.rest = rest

    def __repr__(self):
        if self.rest:
            rest_repr = ', ' + repr(self.rest)
        else:
            rest_repr = ''
        return 'Link(' + repr(self.first) + rest_repr + ')'

    def __str__(self):
        string = '('
        while self.rest is not Link.empty:
            string += str(self.first) + ' '
            self = self.rest
        return string + str(self.first) + ')'

Q2：去掉一个

实现 without，它接受一个链表 s 和一个非负整数 i。它返回一个包含 s 的所有元素， 除了位于索引 i 的那个。 （假设 s.first 是位于索引 0 的元素。）

The original linked list s原始链表

不应被修改。

提示： 使用递归方法可能比迭代方法更容易。

def without(s: Link, i: int) -> Link:
    """Return a new linked list like s but without the element at index i.

    >>> s = Link(3, Link(5, Link(7, Link(9))))
    >>> without(s, 0)
    Link(5, Link(7, Link(9)))
    >>> without(s, 2)
    Link(3, Link(5, Link(9)))
    >>> without(s, 4)  # There is no index 4, so all of s is retained.
    Link(3, Link(5, Link(7, Link(9))))
    """

    if s is Link.empty:
        return s
    if i == 0:
        return s.rest
    else:
        return Link(s.first, without(s.rest, i-1))

Q3：复制链表

编写一个函数 duplicate_link，它接受一个链表 s 和一个值 val。 它 修改 s，使得每个等于 val 的元素后面都跟着一个额外的 val（副本）。 它返回 None。小心不要陷入无限循环，不断复制新生成的副本！

注意：为了将一条链接插入链表中，请重新赋值 rest 的 Link 实例，这些实例的 val 是它们的 first。试着画出一个文档测试来可视化！

def duplicate_link(s: Link, val: int) -> None:
    """Mutates s so that each element equal to val is followed by another val.

    >>> x = Link(5, Link(4, Link(5)))
    >>> duplicate_link(x, 5)
    >>> x
    Link(5, Link(5, Link(4, Link(5, Link(5)))))
    >>> y = Link(2, Link(4, Link(6, Link(8))))
    >>> duplicate_link(y, 10)
    >>> y
    Link(2, Link(4, Link(6, Link(8))))
    >>> z = Link(1, Link(2, Link(2, Link(3))))
    >>> duplicate_link(z, 2) # ensures that back to back links with val are both duplicated
    >>> z
    Link(1, Link(2, Link(2, Link(2, Link(2, Link(3))))))
    """

    if s is Link.empty:
        return
    elif s.first == val:
        remaining = s.rest
        s.rest = Link(val, remaining)
        duplicate_link(remaining, val)
    else:
        duplicate_link(s.rest, val)

python3 ok -q duplicate_link

Q4：切片

实现一个函数 slice_link，它对给定的链表 link进行切片。slice_link 应当对该 link 从 start 开始切片，并在 end 之前的一个元素处结束，就像普通的 Python 列表一样。此外，类似于对普通 Python 列表进行切片，这个函数应当返回一个新列表，而不修改原始列表。

def slice_link(link: Link, start: int, end: int) -> Link:
    """Slices a linked list from start to end (as with a normal Python list) and returns
    a linked list. You do NOT have to support negative indices.

    >>> link = Link(3, Link(1, Link(4, Link(1, Link(5, Link(9))))))
    >>> new = slice_link(link, 1, 4)
    >>> print(new)
    (1 4 1)
    >>> print(slice_link(link, 0, 2))
    (3 1)
    >>> print(slice_link(link, 0, 6))
    (3 1 4 1 5 9)
    >>> print(slice_link(link, 2, 2))
    ()
    >>> print(slice_link(link, 2, 3))
    (4)
    >>> print(slice_link(link, 3, 100))
    (1 5 9)
    >>> print(slice_link(link, 10, 12))
    ()
    """

    if link is Link.empty or end == 0:
        return Link.empty
    elif start == 0:
        return Link(link.first, slice_link(link.rest, 0, end-1))
    else:
        return slice_link(link.rest, start-1, end-1)

Q5：循环

的 Link 类可以表示带循环的列表。也就是说，一个列表可能 将自身作为子列表包含在内。

>>> s = Link(1, Link(2, Link(3)))
>>> s.rest.rest.rest = s
>>> s.rest.rest.rest.rest.rest.first
3

实现 has_cycle，它返回一个参数（一个 Link 实例）是否包含循环。

提示：遍历链表，并尝试记录哪些 Link 对象你已经见过了。

def has_cycle(link: Link) -> bool:
    """Return whether link contains a cycle.

    >>> s = Link(1, Link(2, Link(3)))
    >>> s.rest.rest.rest = s
    >>> has_cycle(s)
    True
    >>> t = Link(1, Link(2, Link(3)))
    >>> has_cycle(t)
    False
    >>> u = Link(2, Link(2, Link(2)))
    >>> has_cycle(u)
    False
    """

    links = []
    while link is not Link.empty:
        if link in links:
            return True
        links.append(link)
        link = link.rest
    return False

python3 ok -q has_cycle

额外挑战（可选）：实现 has_cycle，而不记录所有 Link 对象你已经见过了。 这个解法很短（少于 20 行代码），但需要巧妙的思路。 在四处求助之前，试着自己找出解法。

def has_cycle_constant(link: Link) -> bool:
    """Return whether link contains a cycle.

    >>> s = Link(1, Link(2, Link(3)))
    >>> s.rest.rest.rest = s
    >>> has_cycle_constant(s)
    True
    >>> t = Link(1, Link(2, Link(3)))
    >>> has_cycle_constant(t)
    False
    """

    if link is Link.empty:
        return False
    slow, fast = link, link.rest
    while fast is not Link.empty:
        if fast.rest == Link.empty:
            return False
        elif fast is slow or fast.rest is slow:
            return True
        else:
            slow, fast = slow.rest, fast.rest.rest
    return False

python3 ok -q has_cycle_constant
