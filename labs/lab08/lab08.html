链表

如果你需要复习链表的内容，可以参考下面的折叠框。如果遇到困难，也可以直接跳到题目，再回来查阅本部分。

链表是一种用于存储值序列的数据结构。对于某些操作（例如在一个长列表的中间插入一个值），它比普通的 Python 内置列表更高效。链表不是 Python 内置的，所以我们定义了一个名为 Link 的类来表示它。 一个链表要么是一个 Link 实例，要么是 Link.empty （表示一个空链表）。

Link 的一个实例有两个实例属性：first 和 rest。

Link 实例的 rest 属性始终应该是一个链表：要么是另一个 Link 实例，要么是 Link.empty。它绝不应该是 None。

要判断一个链表是否为空，将其与 Link.empty 比较即可。因为只存在一个空链表，我们可以使用 is 来比较，但 == 也同样有效。

def is_empty(s):
    """Return whether linked list s is empty."""
    return s is Link.empty:

你可以通过两种方式改变一个 Link 对象 s：

  • 使用 s.first = ... 修改第一个元素
  • 使用 s.rest = ... 修改其余元素

你可以通过调用 Link 来创建一个新的 Link 对象：

  • Link(4) 创建一个长度为 1、包含 4 的链表。
  • Link(4, s) 创建一个以 4 开头、后面跟着链表 s 中各个元素的链表。

下面是 Link 类的实现：

class Link:
    """A linked list is either a Link object or Link.empty

    >>> s = Link(3, Link(4, Link(5)))
    >>> s.rest
    Link(4, Link(5))
    >>> s.rest.rest.rest is Link.empty
    True
    >>> s.rest.first * 2
    8
    >>> print(s)
    (3 4 5)
    """
    empty = ()

    def __init__(self, first, rest=empty):
        assert rest is Link.empty or isinstance(rest, Link)
        self.first = first
        self.rest = rest

    def __repr__(self):
        if self.rest:
            rest_repr = ', ' + repr(self.rest)
        else:
            rest_repr = ''
        return 'Link(' + repr(self.first) + rest_repr + ')'

    def __str__(self):
        string = '('
        while self.rest is not Link.empty:
            string += str(self.first) + ' '
            self = self.rest
        return string + str(self.first) + ')'
