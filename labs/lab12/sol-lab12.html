可变树

A Tree 实例有两个实例属性：
  • label 是存储在树根节点的值。
  • branches 是一个由 Tree 实例组成的列表，这些实例保存树其余部分的标签。

该 Tree 类（其 __repr__ 和 __str__ 方法已省略）定义如下：

class Tree:
    """A tree has a label and a list of branches.

    >>> t = Tree(3, [Tree(2, [Tree(5)]), Tree(4)])
    >>> t.label
    3
    >>> t.branches[0].label
    2
    >>> t.branches[1].is_leaf()
    True
    """
    def __init__(self, label, branches=[]):
        self.label = label
        for branch in branches:
            assert isinstance(branch, Tree)
        self.branches = list(branches)

    def is_leaf(self):
        return not self.branches

要构造一个 Tree 实例，给定标签 x（任意值）以及分支列表 bs（由 Tree 实例组成的列表），并将其命名为 t 的叶子节点，请写 t = Tree(x, bs) 个自然数。

对于一棵树 t:

  • 其根标签可以是任意值，并且 t.label 求值为它。
  • 它的分支始终是 Tree 实例，并且 t.branches 求值为 list 它的分支。
  • t.is_leaf() 返回 True：当 t.branches 为空时返回 True，False 否则返回另一方法。
  • 要构造一个标签为 x 的叶子节点，请写 Tree(x) 个自然数。

显示一棵树 t:

  • repr(t) 返回一个求值为等价树的 Python 表达式。
  • str(t) 为每个标签返回一行，缩进比其父节点多一级，子节点位于父节点下方。
>>> t = Tree(3, [Tree(1, [Tree(4), Tree(1)]), Tree(5, [Tree(9)])])

>>> t         # displays the contents of repr(t)
Tree(3, [Tree(1, [Tree(4), Tree(1)]), Tree(5, [Tree(9)])])

>>> print(t)  # displays the contents of str(t)
3
  1
    4
    1
  5
    9

改变（也称为修改）一棵树 t:

  • t.label = y 会将 t 的根标签改为 y（任意值）。
  • t.branches = ns 将 t 的根标签改为 ns（由 Tree 实例组成的列表）。
  • 对 t.branches 的修改会改变 t。例如， t.branches.append(Tree(y)) 会添加一个标签为 y 的叶子节点，作为最右侧的 分支。
  • 对 t 的修改会改变 t。例如， t.branches[0].label = y 会将最左侧分支的根标签改为 y 个自然数。
>>> t.label = 3.0
>>> t.branches[1].label = 5.0
>>> t.branches.append(Tree(2, [Tree(6)]))
>>> print(t)
3.0
  1
    4
    1
  5.0
    9
  2
    6

- 树的构造函数与选择函数 树类
构造一棵树 给定 label 以及 branches 的标签或分支，我们调用 tree(label, branches) 给定 label 以及 branches 的标签或分支，我们调用 Tree(label, branches)（它调用 Tree.__init__ 方法）。
标签与分支 要获取树 t 的标签或分支，我们调用 label(t) 或 branches(t) 分别 要获取树 t 的标签或分支，我们访问实例属性 t.label 或 t.branches 分别。
可变性 函数式树数据抽象是不可变的（不违反其抽象屏障），因为我们无法对调用表达式赋值。 该 label 和 branches 属性可以Tree 实例可以被重新赋值，从而修改树。

Q1：删除

实现 delete，它接受一个 Tree t 并移除所有标签为 x 的非根节点。 每个剩余节点的父节点是它最近的未被移除的祖先节点。 即使根节点的标签为 x 个自然数。

def delete(t, x):
    """Remove all nodes labeled x below the root within Tree t. When a non-leaf
    node is deleted, the deleted node's children become children of its parent.

    The root node will never be removed.

    >>> t = Tree(3, [Tree(2, [Tree(2), Tree(2)]), Tree(2), Tree(2, [Tree(2, [Tree(2), Tree(2)])])])
    >>> delete(t, 2)
    >>> t
    Tree(3)
    >>> t = Tree(1, [Tree(2, [Tree(4, [Tree(2)]), Tree(5)]), Tree(3, [Tree(6), Tree(2)]), Tree(4)])
    >>> delete(t, 2)
    >>> t
    Tree(1, [Tree(4), Tree(5), Tree(3, [Tree(6)]), Tree(4)])
    >>> t = Tree(1, [Tree(2, [Tree(4), Tree(5)]), Tree(3, [Tree(6), Tree(2)]), Tree(2, [Tree(6),  Tree(2), Tree(7), Tree(8)]), Tree(4)])
    >>> delete(t, 2)
    >>> t
    Tree(1, [Tree(4), Tree(5), Tree(3, [Tree(6)]), Tree(6), Tree(7), Tree(8), Tree(4)])
    """
    new_branches = []

    for b in t.branches:
        delete(b, x)
        if b.label == x:

            new_branches.extend(b.branches)
        else:

            new_branches.append(b)
    t.branches = new_branches

Q2：子序列

一个序列 s 的子序列是 s 中元素的一个子集，且保持它们在 s 中出现的原有顺序。考虑列表 [1, 2, 3]。它的几个 子序列是 []、[1, 3]、[2] 与 [1, 2, 3] 个自然数。

编写一个函数，接受一个列表并返回该列表的所有可能子序列。 子序列应以列表的列表形式返回，其中每个嵌套列表都是 原始输入的一个子序列。

为了完成这一点，你可能想先编写一个函数 insert_into_all，它接受一个元素和一个列表的列表，将该元素添加到每个嵌套列表的开头， 并返回结果列表。

def insert_into_all(item, nested_list):
    """Return a new list consisting of all the lists in nested_list,
    but with item added to the front of each. You can assume that
    nested_list is a list of lists.

    >>> nl = [[], [1, 2], [3]]
    >>> insert_into_all(0, nl)
    [[0], [0, 1, 2], [0, 3]]
    """

    return [[item] + lst for lst in nested_list]

def subseqs(s):
    """Return a nested list (a list of lists) of all subsequences of S.
    The subsequences can appear in any order. You can assume S is a list.

    >>> seqs = subseqs([1, 2, 3])
    >>> sorted(seqs)
    [[], [1], [1, 2], [1, 2, 3], [1, 3], [2], [2, 3], [3]]
    >>> subseqs([])
    [[]]
    """

    if not s:
        return [[]]
    else:

        subset = subseqs(s[1:])
        return insert_into_all(s[0], subset) + subset

Q3：非递减子序列

我们想要编写一个函数，它接受一个列表并 返回一个列表的列表，其中每个单独的列表都是 原始输入的一个子序列。

然而，我们有一个条件：我们只想要那些 连续元素 nondecreasing 的子序列。例如，[1, 3, 2] 是 [1, 3, 2, 4] 的一个子序列，但由于 2 < 3，这个子序列将 不会 被包含在我们的结果中。

你可以假设作为 s 传入的列表只包含非负元素。

你可以使用 insert_into_all 辅助函数。

def insert_into_all(item, lsts):
    """Assuming that lsts is a list of lists, return a new list consisting of
    all the lists in lsts, but with item added to the front of each.

    >>> lsts = [[], [1, 2], [3]]
    >>> insert_into_all(0, lsts)
    [[0], [0, 1, 2], [0, 3]]
    """
    return [[item] + lst for lst in lsts]
def non_decrease_subseqs(s):
    """Return a nested list of all subsequences of S (a list of lists) 
    for which the elements of the subsequence are nondecreasing. The 
    subsequences can appear in any order. You can assume S is a list.

    >>> seqs = non_decrease_subseqs([1, 3, 2])
    >>> sorted(seqs)
    [[], [1], [1, 2], [1, 3], [2], [3]]
    >>> non_decrease_subseqs([])
    [[]]
    >>> seqs2 = non_decrease_subseqs([1, 1, 2])
    >>> sorted(seqs2)
    [[], [1], [1], [1, 1], [1, 1, 2], [1, 2], [1, 2], [2]]
    """
    def subseq_helper(s, prev):
        if not s:

            return [[]]
        elif s[0] < prev:

            return subseq_helper(s[1:], prev)
        else:

            a = subseq_helper(s[1:], s[0])
            b = subseq_helper(s[1:], prev)
            return insert_into_all(s[0], a) + b
    return subseq_helper(s, 0)

Q4：共同玩家

实现函数 common_players。该 common_players 函数接受一个 roster 字典，该字典 将玩家映射到他们的队伍，并返回一个新的字典，将队伍映射到该队伍中玩家组成的列表。 列表中玩家名字的顺序无关紧要。

def common_players(roster):
    """Returns a dictionary containing values along with a corresponding
    list of keys that had that value from the original dictionary.
    >>> full_roster = {
    ...     "bob": "Team A",
    ...     "barnum": "Team B",
    ...     "beatrice": "Team C",
    ...     "bernice": "Team B",
    ...     "ben": "Team D",
    ...     "belle": "Team A",
    ...     "bill": "Team B",
    ...     "bernie": "Team B",
    ...     "baxter": "Team A"
    ... }
    >>> player_dict = common_players(full_roster)
    >>> type(player_dict) == dict
    True
    >>> for key, val in sorted(player_dict.items()):
    ...     print(key, list(sorted(val)))
    Team A ['baxter', 'belle', 'bob']
    Team B ['barnum', 'bernice', 'bernie', 'bill']
    Team C ['beatrice']
    Team D ['ben']
    """

    result_dict = {}
    for player in roster:
        team = roster[player]
        if team in result_dict:
            result_dict[team] += [player]
        else:
            result_dict[team] = [player]
    return result_dict

Q5：楼梯走法

想象你想爬上一个有 n 级台阶的楼梯， 其中 n 是一个正整数。你每次可以走 一 或 两步。

编写一个生成器函数 stair_ways，它生成你爬上楼梯的所有不同方式。

爬楼梯的每种“方式”都可以用一个由 1 和 2 组成的列表表示，其中每个数字表示你一次走一步还是两步。

例如，对于一个有 3 级台阶的楼梯，有三种爬法：

  • 你可以每次走一步：[1, 1, 1] 个自然数。
  • 你可以先走两步再走一步：[2, 1] 个自然数。
  • 你可以先走一步再走两步：[1, 2]. 个自然数。

因此，stair_ways(3) 应该生成 [1, 1, 1]、[2, 1] 与 [1, 2]。这些可以以任意顺序生成。

提示： 递归地思考这个问题。如果你在第 n 级台阶，你上一步可能是哪一级台阶？

def stair_ways(n):
    """
    Yield all the ways to climb a set of n stairs taking
    1 or 2 steps at a time.

    >>> list(stair_ways(0))
    [[]]
    >>> s_w = stair_ways(4)
    >>> sorted([next(s_w) for _ in range(5)])
    [[1, 1, 1, 1], [1, 1, 2], [1, 2, 1], [2, 1, 1], [2, 2]]
    >>> list(s_w) # Ensure you're not yielding extra
    []
    """

    if n == 0:
        yield []
    elif n == 1:
        yield [1]
    else:
        for way in stair_ways(n - 1):
            yield [1] + way
        for way in stair_ways(n - 2):
            yield [2] + way

选举

让我们实现一个名为选举的游戏。在这个游戏中，两名玩家竞争以 获得最多的选票。两名玩家都从 0 票和 100 人气开始。

两名玩家轮流行动，由第一名玩家先开始。每一轮， 当前玩家选择一个行动。行动有两种类型：

  • 玩家可以 debate，并可能获得或失去 50 人气。如果玩家 的人气为 p1，而另一名玩家的人气为 p2，那么玩家 获得 50 人气的概率为 max(0.1, p1 / (p1 + p2)). Note that the max 确保概率永远不会低于 0.1。
  • 玩家可以发表一场 speech。如果玩家的人气为 p1，而另一名 玩家的人气为 p2，那么玩家获得 p1 // 10 票和 人气，而另一名玩家失去 p2 // 10 人气。

当一名玩家达到 50 票，或者总共进行了 10 轮 （每名玩家各行动 5 轮）后，游戏结束。游戏结束时 得票较多的一方获胜！

Q6：玩家

首先，让我们实现 Player 类。填写 debate 和 speech 方法，这些方法接受一个 Player other，并实现如上所述的 正确行为。以下是需要牢记的几点：

  • 每名玩家都持有一个随机数生成器（即 random_func 实例属性）， 它是一个不接受参数、被调用时返回 0 到 1 之间随机浮点数的函数。
  • 在 debate 方法中，你应该调用 random_func 函数来获取一个随机数。 如果随机数小于上述概率，玩家应获得 50 人气， 否则失去 50 人气。
  • 任何玩家的人气都不应变为负数。如果发生这种情况， 请将其设为 0。
### Phase 1: The Player Class
class Player:
    """
    >>> random = make_test_random()
    >>> p1 = Player('Hill', random)
    >>> p2 = Player('Don', random)
    >>> p1.popularity
    100
    >>> p1.debate(p2)  # random() should return 0.0
    >>> p1.popularity
    150
    >>> p2.popularity
    100
    >>> p2.votes
    0
    >>> p2.speech(p1)
    >>> p2.votes
    10
    >>> p2.popularity
    110
    >>> p1.popularity
    135
    >>> p1.speech(p2)
    >>> p1.votes
    13
    >>> p1.popularity
    148
    >>> p2.votes
    10
    >>> p2.popularity
    99
    >>> for _ in range(4):  # 0.1, 0.2, 0.3, 0.4
    ...     p1.debate(p2)
    >>> p2.debate(p1)
    >>> p2.popularity
    49
    >>> p2.debate(p1)
    >>> p2.popularity
    0
    """
    def __init__(self, name, random_func):
        self.name = name
        self.votes = 0
        self.popularity = 100
        self.random_func = random_func

    def debate(self, other):

        prob = max(0.1, self.popularity / (self.popularity + other.popularity))
        if self.random_func() < prob:
            self.popularity += 50
        else:
            self.popularity = max(0, self.popularity - 50)

    def speech(self, other):

        self.votes += self.popularity // 10
        self.popularity += self.popularity // 10
        other.popularity = max(0, other.popularity - (other.popularity // 10))

    def choose(self, other):
        return self.speech

Q7：游戏

现在，实现 Game 类。填写 play 方法，它应该 在两名玩家之间交替，从 p1 开始，并让每名玩家 每次行动一轮。choose 类中的 Player 方法返回应该被调用以执行 行动的方法，即 debate 或 speech。

此外，填写 winner 方法，它应该返回 得票较多的玩家，如果平局则返回 None。

### Phase 2: The Game Class
class Game:
    """
    >>> random = make_test_random()
    >>> p1, p2 = Player('Hill',random), Player('Don', random)
    >>> g = Game(p1, p2)
    >>> winner = g.play()
    >>> p1 is winner
    True
    >>> # Additional correctness tests
    >>> winner is g.winner()
    True
    >>> g.turn
    10
    >>> p1.votes = p2.votes
    >>> print(g.winner())
    None
    """
    def __init__(self, player1, player2):
        self.p1 = player1
        self.p2 = player2
        self.turn = 0

    def play(self):
        while not self.game_over():

            if self.turn % 2 == 0:
                curr, other = self.p1, self.p2
            else:
                curr, other = self.p2, self.p1
            curr.choose(other)(other)
            self.turn += 1
        return self.winner()

    def game_over(self):
        return max(self.p1.votes, self.p2.votes) >= 50 or self.turn >= 10

    def winner(self):

        if self.p1.votes > self.p2.votes:
            return self.p1
        elif self.p2.votes > self.p1.votes:
            return self.p2
        else:
            return None

Q9：双列表

实现一个函数 two_list，它接受两个列表并返回一个链表。第一个列表包含 我们想要放入链表中的值，第二个列表包含每个对应值的数量。 假设两个列表大小相同且长度大于等于 1。假设第二个列表中的所有元素 都大于 0。

def two_list(vals, counts):
    """
    Returns a linked list according to the two lists that were passed in. Assume
    vals and counts are the same size. Elements in vals represent the value, and the
    corresponding element in counts represents the number of this value desired in the
    final linked list. Assume all elements in counts are greater than 0. Assume both
    lists have at least one element.
    >>> a = [1, 3]
    >>> b = [1, 1]
    >>> c = two_list(a, b)
    >>> c
    Link(1, Link(3))
    >>> a = [1, 3, 2]
    >>> b = [2, 2, 1]
    >>> c = two_list(a, b)
    >>> c
    Link(1, Link(1, Link(3, Link(3, Link(2)))))
    """

    def helper(count, index):
        if count == 0:
            if index + 1 == len(vals):
                return Link.empty
            return Link(vals[index + 1], helper(counts[index + 1] - 1, index + 1))
        return Link(vals[index], helper(count - 1, index))
    return helper(counts[0], 0)

#迭代解法
def two_list_iterative(vals, counts):
    result = Link(None)
    p = result
    for index in range(len(vals)):
        item = vals[index]
        for _ in range(counts[index]):
            p.rest = Link(item)
            p = p.rest
    return result.rest

Scheme/尾递归

Q10：累加

补全过程 accumulate 的定义，它按照以下参数 连接前 n 个自然数（即 1 到 n，包含 n）：

  1. merger：一个接受两个参数的函数
  2. start：我们开始连接时使用的数字
  3. n：要连接的自然数的个数
  4. term：一个接受单个参数的函数，用于计算 n 序列的 第 n 项

例如，我们可以通过 将乘法运算符作为 merger，并将我们的 乘积起始值设为 1，来求得 1 到 5 所有数的乘积：

scm> (define (identity x) x)
scm> (accumulate * 1 5 identity)  ; 1 * 1 * 2 * 3 * 4 * 5
120

我们也可以将 加法运算符作为 merger 和 square 作为 term:

scm> (define (square x) (* x x))
scm> (accumulate + 0 5 square)  ; 0 + 1^2 + 2^2 + 3^2 + 4^2 + 5^2
55
scm> (accumulate + 5 5 square)  ; 5 + 1^2 + 2^2 + 3^2 + 4^2 + 5^2
60

你可以假设 merger 始终是交换的：即参数的顺序 无关紧要。

(define (accumulate merger start n term)

  (if (= n 0)
    start
    (accumulate merger (merger (term n) start) (- n 1) term))
)

在作业的前面部分，你已经在 scheme 中实现了 accumulate。提醒一下，accumulate 按照参数 n 连接前 merger、start、n 与 term 个自然数。

将你的 accumulate 实现更新为尾递归。它 仍应通过所有针对“普通” accumulate 的测试！

你可以假设输入的 merger 和 term 过程是 正确的尾递归。

如果你在上一题中实现的 accumulate 已经 是尾递归的，你可以直接复制该解法（将 accumulate 替换为 accumulate-tail 即可）。

如果你遇到了递归深度超限错误，并且你正在 使用官方解释器，那很可能你的解法 不是正确的尾递归。

我们通过调用 accumulate-tail 并传入 一个非常大的输入来测试你的解法是否为尾递归。如果你的解法不是尾递归，且没有使用 常数数量的帧，它将无法成功运行。

(define (accumulate-tail merger start n term)

  (define (accum-helper x so-far)
    (if (= x 0)
      so-far
      (accum-helper (- x 1) (merger (term x) so-far))
    ))
  (accum-helper n start))
; 备选解法
(define (accumulate-tail merger start n term)
  (if (= n 0)
    start
    (accumulate-tail merger (merger (term n) start) (- n 1) term))
)

如果我们用 Python 以迭代方式实现它，可能看起来 像这样：

def accumulate(merger, start, n, term):
    total = start
    while n > 0:
        total = merger(total, term(n))
        n -= 1
    return total
