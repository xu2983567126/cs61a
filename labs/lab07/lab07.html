可变树

一个 Tree 实例有两个实例属性：

  • label 是存储在树的根节点的值。
  • branches 是一个 Tree 实例的列表，包含了树其余部分的标签。

Tree 类（省略了 __repr__ 和 __str__ 方法）定义如下：

class Tree:
    """A tree has a label and a list of branches.

    >>> t = Tree(3, [Tree(2, [Tree(5)]), Tree(4)])
    >>> t.label
    3
    >>> t.branches[0].label
    2
    >>> t.branches[1].is_leaf()
    True
    """
    def __init__(self, label, branches=[]):
        self.label = label
        for branch in branches:
            assert isinstance(branch, Tree)
        self.branches = list(branches)

    def is_leaf(self):
        return not self.branches

要从一个标签 x（任意值）和一个分支列表 bs（Tree 实例的列表）构造一个 Tree 实例并命名为 t，可以写成 t = Tree(x, bs)。

对于一棵树 t：

  • 它的根标签可以是任意值，t.label 计算结果为该值。
  • 它的分支始终是 Tree 实例，t.branches 计算结果为它的分支的列表。
  • t.is_leaf() 在 t.branches 为空时返回 True，否则返回 False。
  • 要构造一个标签为 x 的叶子节点，写成 Tree(x)。

显示一棵树 t：

  • repr(t) 返回一个 Python 表达式，计算后能得到一棵等价的树。
  • str(t) 返回多行，每个标签比其父节点多缩进一级，子节点位于父节点下方。
>>> t = Tree(3, [Tree(1, [Tree(4), Tree(1)]), Tree(5, [Tree(9)])])

>>> t         # displays the contents of repr(t)
Tree(3, [Tree(1, [Tree(4), Tree(1)]), Tree(5, [Tree(9)])])

>>> print(t)  # displays the contents of str(t)
3
  1
    4
    1
  5
    9

更改（也称为变更）一棵树 t：

  • t.label = y 将 t 的根标签改为 y（任意值）。
  • t.branches = ns 将 t 的分支改为 ns（Tree 实例的列表）。
  • 对 t.branches 的变更会改变 t。例如， t.branches.append(Tree(y)) 会添加一个标签为 y 的叶子节点作为最右侧的分支。
  • 对 t 中任一分支的变更都会改变 t。例如， t.branches[0].label = y 会将最左侧分支的根标签改为 y。
>>> t.label = 3.0
>>> t.branches[1].label = 5.0
>>> t.branches.append(Tree(2, [Tree(6)]))
>>> print(t)
3.0
  1
    4
    1
  5.0
    9
  2
    6

下面总结了将树作为函数式抽象实现与作为类实现之间的差异：

- 树的构造器与选择器函数 Tree 类
构造一棵树 给定一个 label 和一个 branches 列表来构造一棵树，我们调用 tree(label, branches) 给定一个 label 和一个 branches 列表来构造一个树对象，我们调用 Tree(label, branches)（这会调用 Tree.__init__ 方法）。
标签与分支 要获取一棵树 t 的标签或分支，我们分别调用 label(t) 或 branches(t) 要获取一棵树 t 的标签或分支，我们分别访问实例属性 t.label 或 t.branches。
可变性 函数式树的抽象是不可变的（除非越过其抽象屏障），因为我们无法对调用表达式赋值 Tree 实例的 label 和 branches 属性可以被重新赋值，从而变更这棵树。
判断一棵树是否为叶子 要判断一棵树 t 是否为叶子，我们调用函数 is_leaf(t) 要判断一棵树 t 是否为叶子，我们调用方法 t.is_leaf()。该方法只能对 Tree 对象调用。

class Tree:
    """A tree has a label and a list of branches.

    >>> t = Tree(3, [Tree(2, [Tree(5)]), Tree(4)])
    >>> t.label
    3
    >>> t.branches[0].label
    2

        return not self.branches

    def __repr__(self):
        if self.branches:
            branch_str = ', ' + repr(self.branches)
        else:
            branch_str = ''
        return 'Tree({0}{1})'.format(repr(self.label), branch_str)

    def __str__(self):
        return '\n'.join(self.indented())

    def indented(self):
        lines = []
        for b in self.branches:
            for line in b.indented():
                lines.append('  ' + line)
        return [str(self.label)] + lines

Q5：层级变更（链表）

提醒一下，节点的深度定义为从根到该节点的边数。因此，根节点本身的深度为 0，因为根与自身之间没有边。

给定一棵树 t 和一个由单参数函数组成的链表 funcs，编写一个函数，使用 funcs 中对应深度的函数来变更 t 的标签。例如：

  • 根节点（深度 0）的标签将使用 funcs 中深度 0 的函数（funcs.first）来变更。
  • 树中第一层的标签将使用 funcs 中深度 1 的函数（funcs.rest.first）来变更，依此类推。

funcs 中的每个函数都接受一个标签值并返回一个有效的标签值。

如果一个节点是叶子，而 funcs 中还有剩余的函数，则所有这些剩余的函数都应按顺序应用到该叶子节点的标签上。如果 funcs 为空，树应保持不变。

请参阅文档测试中的示例。
