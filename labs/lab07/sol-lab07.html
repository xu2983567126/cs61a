可变树

一个 Tree 实例有两个实例属性：

  • label 是存储在树根处的值。
  • branches 是一个由 Tree 实例组成的列表，这些实例保存着树其余部分的标签。

该Tree 类（其 __repr__ 和 __str__ 方法省略）定义如下：

class Tree:
    """A tree has a label and a list of branches.

    >>> t = Tree(3, [Tree(2, [Tree(5)]), Tree(4)])
    >>> t.label
    3
    >>> t.branches[0].label
    2
    >>> t.branches[1].is_leaf()
    True
    """
    def __init__(self, label, branches=[]):
        self.label = label
        for branch in branches:
            assert isinstance(branch, Tree)
        self.branches = list(branches)

    def is_leaf(self):
        return not self.branches

要构造一个 Tree 实例，给定一个标签 x（任意值）以及一份分支列表 bs（即由 Tree 实例组成的列表），并将其命名为 t，可以写作 t = Tree(x, bs).

对于一棵树 t：

  • 它的根标签可以是任意值，并且 t.label 求值得到它。
  • 它的分支始终是 Tree 实例，并且 t.branches 求值得到其 列表 分支。
  • t.is_leaf() 返回 True，如果 t.branches 为空，否则返回 False。
  • 要构造一个标签为 x，可以写作 Tree(x).

显示一棵树 t：

  • repr(t) 返回一个求值后等价于该树的 Python 表达式。
  • str(t) 为每个标签返回一行，比其父节点多缩进一次，子节点位于父节点下方。
>>> t = Tree(3, [Tree(1, [Tree(4), Tree(1)]), Tree(5, [Tree(9)])])

>>> t         # displays the contents of repr(t)
Tree(3, [Tree(1, [Tree(4), Tree(1)]), Tree(5, [Tree(9)])])

>>> print(t)  # displays the contents of str(t)
3
  1
    4
    1
  5
    9

修改（也称为变更）一棵树 t：

  • t.label = y 将 t 的根标签更改为 y（任意值）。
  • t.branches = ns 将 t 的根标签更改为 ns（即由 Tree 实例组成的列表）。
  • 对 t.branches 中任意分支的变更会修改 t。例如， t.branches.append(Tree(y)) 会添加一个标签为 y 的叶子作为最右侧的 分支。
  • 对 t 中任意分支的变更会修改 t。例如， t.branches[0].label = y 会将最左侧分支的根标签更改为 y.
>>> t.label = 3.0
>>> t.branches[1].label = 5.0
>>> t.branches.append(Tree(2, [Tree(6)]))
>>> print(t)
3.0
  1
    4
    1
  5.0
    9
  2
    6

下面总结了以函数式抽象实现与以类实现的树数据抽象之间的区别：

- 树的构造函数与选择器函数 树的类
构造一棵树 要构造一棵给定 label 以及 branches 的标签或分支，我们调用 tree(label, branches) 要构造一个给定 label 以及 branches 的标签或分支，我们调用 Tree(label, branches)（它会调用 Tree.__init__ 方法）。
标签与分支 要获取一棵树 t 的标签或分支，我们调用 label(t) 或 branches(t) 分别 要获取一棵树 t 的标签或分支，我们访问其实例属性 t.label 或 t.branches 分别。
可变性 函数式树数据抽象是不可变的（在不违反其抽象屏障的前提下），因为我们无法对调用表达式赋值 该label 和 branches 属性（属于一个 Tree 实例）可以被重新赋值，从而改变这棵树。
判断一棵树是否为叶子 要检查一棵树 t 是否为叶子，我们调用函数 is_leaf(t) 要检查一棵树 t 是否为叶子，我们调用方法 t.is_leaf()。这个方法只能在 Tree 对象上调用。

Q1：最大路径和

编写一个函数，接收一棵树，并返回从树根到任一叶子的任意路径上数值之和的最大值。

def max_path_sum(t):
    """Return the maximum path sum of the tree.

    >>> t = Tree(1, [Tree(5, [Tree(1), Tree(3)]), Tree(10)])
    >>> max_path_sum(t)
    11
    """

    if t.is_leaf():
      return t.label
    else:
      return t.label + max([max_path_sum(b) for b in t.branches])

Q2：添加叶子

实现 add_d_leaves，一个接收 Tree 实例 t 以及一个数字 v.

我们将 t 中某个节点的深度定义为从该节点到根节点的边数。因此根节点的深度为 0。

对于树中的每个节点，你应该添加 d 片叶子，其中 d 是该节点的深度。每片添加的叶子应具有标签 v。如果该深度的节点已有分支，你应将这些叶子添加到该分支列表的末尾。

例如，你应该向深度为 1 的每个节点添加 1 片标签为 v 的叶子，向深度为 2 的每个节点添加 2 片叶子，依此类推。

下面是一个树 t（左侧所示）以及应用 add_d_leaves 且 v 取 5 后的结果。

提示： 使用一个辅助函数来记录深度！

提示： 注意你向树中添加新叶子的时机。 我们只想向树中原始的节点添加叶子，而不是向我们添加的 节点添加。

查看下面的 doctests，并尝试画出第二个 doctest，以可视化该函数如何变更 t3.

def add_d_leaves(t, v):
    """Add d leaves containing v to each node at every depth d.

    >>> t_one_to_four = Tree(1, [Tree(2), Tree(3, [Tree(4)])])
    >>> print(t_one_to_four)
    1
      2
      3
        4
    >>> add_d_leaves(t_one_to_four, 5)
    >>> print(t_one_to_four)
    1
      2
        5
      3
        4
          5
          5
        5

    >>> t0 = Tree(9)
    >>> add_d_leaves(t0, 4)
    >>> t0
    Tree(9)
    >>> t1 = Tree(1, [Tree(3)])
    >>> add_d_leaves(t1, 4)
    >>> t1
    Tree(1, [Tree(3, [Tree(4)])])
    >>> t2 = Tree(2, [Tree(5), Tree(6)])
    >>> t3 = Tree(3, [t1, Tree(0), t2])
    >>> print(t3)
    3
      1
        3
          4
      0
      2
        5
        6
    >>> add_d_leaves(t3, 10)
    >>> print(t3)
    3
      1
        3
          4
            10
            10
            10
          10
          10
        10
      0
        10
      2
        5
          10
          10
        6
          10
          10
        10
    """

    def add_leaves(t, d):
        for b in t.branches:
            add_leaves(b, d + 1)
        t.branches.extend([Tree(v) for _ in range(d)])
    add_leaves(t, 0)

Q3：存在路径

编写一个函数 has_path，它接收一个 Tree t 和一个字符串 target。它 返回 True，如果存在一个从根节点开始的路径，且沿该路径的条目 拼写出 target，否则返回 False。你可以假设 每个节点的 label 恰好是一个字符。

这种数据结构称为前缀树（trie），它有许多很酷的 应用，例如自动补全。

def has_path(t, target):
    """Return whether there is a path in a Tree where the entries along the path
    spell out a particular target.

    >>> greetings = Tree('h', [Tree('i'),
    ...                        Tree('e', [Tree('l', [Tree('l', [Tree('o')])]),
    ...                                   Tree('y')])])
    >>> print(greetings)
    h
      i
      e
        l
          l
            o
        y
    >>> has_path(greetings, 'h')
    True
    >>> has_path(greetings, 'i')
    False
    >>> has_path(greetings, 'hi')
    True
    >>> has_path(greetings, 'hello')
    True
    >>> has_path(greetings, 'hey')
    True
    >>> has_path(greetings, 'bye')
    False
    >>> has_path(greetings, 'hint')
    False
    """
    assert len(target) > 0, 'no path for empty target.'

    if t.label != target[0]:
        return False
    elif len(target) == 1:
        return True
    for b in t.branches:
        if has_path(b, target[1:]):
            return True
    return False

    # 使用 any() 的备选解法
    if t.label != target[0]:
        return False
    if t.label == target:
        return True
    if t.label == target[0]:
        target = target[1:]
    return any([has_path(b, target) for b in t.branches])

Q4：前序遍历

定义函数 preorder，它接收一个 Tree 实例，并 返回树中所有标签的列表，顺序为 打印该树时它们出现的顺序。

下图展示了节点被打印的顺序， 箭头表示函数调用。

树中节点的这种顺序称为前序遍历。

def preorder(t):
    """Return a list of the entries in this tree in the order that they
    would be visited by a preorder traversal (see problem description).

    >>> numbers = Tree(8, [Tree(2), Tree(9, [Tree(4), Tree(5)]), Tree(6, [Tree(7)])])
    >>> print(numbers)
    8
      2
      9
        4
        5
      6
        7
    >>> preorder(numbers)
    [8, 2, 9, 4, 5, 6, 7]
    """

    labels = [t.label]
    for b in t.branches:
        labels.extend(preorder(b))
    return labels

class Tree:
    """A tree has a label and a list of branches.

    >>> t = Tree(3, [Tree(2, [Tree(5)]), Tree(4)])
    >>> t.label
    3
    >>> t.branches[0].label
    2
    >>> t.branches[1].is_leaf()
    True
    """
    def __init__(self, label, branches=[]):
        self.label = label
        for branch in branches:
            assert isinstance(branch, Tree)
        self.branches = list(branches)

    def is_leaf(self):
        return not self.branches

    def __repr__(self):
        if self.branches:
            branch_str = ', ' + repr(self.branches)
        else:
            branch_str = ''
        return 'Tree({0}{1})'.format(repr(self.label), branch_str)

    def __str__(self):
        return '\n'.join(self.indented())

    def indented(self):
        lines = []
        for b in self.branches:
            for line in b.indented():
                lines.append('  ' + line)
        return [str(self.label)] + lines

Q5：层级变更链接

提醒一下，节点的深度定义为从根节点到该节点的边数。因此，根节点本身的深度为 0，因为根节点与自身之间没有边。

给定一个树 t 以及一个由单参数函数组成的链表 funcs，编写一个函数，使用 t 中的函数，在对应的深度上变更 funcs 的标签。例如：

  • 根节点（深度 0）的标签将使用 funcs（funcs.first）进行变更。
  • 树的第一层（深度 1）的标签将使用 funcs（funcs.rest.first）进行变更，依此类推。

中的每个函数 funcs 接收一个标签值并返回一个有效的标签值。

如果一个节点是叶子，并且 funcs 中仍有剩余的函数，所有这些剩余函数应按顺序 应用到叶子节点的标签上。如果 funcs 为空，则树应保持不变不变.

请参考 doctests 中的例子。

def level_mutation_link(t, funcs):
	"""Mutates t using the functions in the linked list funcs.

	>>> t = Tree(1, [Tree(2, [Tree(3)])])
	>>> funcs = Link(lambda x: x + 1, Link(lambda y: y * 5, Link(lambda z: z ** 2)))
	>>> level_mutation_link(t, funcs)
	>>> t    # At level 0, apply x + 1; at level 1, apply y * 5; at level 2 (leaf), apply z ** 2
	Tree(2, [Tree(10, [Tree(9)])])
	>>> t2 = Tree(1, [Tree(2), Tree(3, [Tree(4)])])
	>>> level_mutation_link(t2, funcs)
	>>> t2    # Level 0: 1+1=2; Level 1: 2*5=10 => 10**2 = 100, 3*5=15; Level 2 (leaf): 4**2=16
	Tree(2, [Tree(100), Tree(15, [Tree(16)])])
	>>> t3 = Tree(1, [Tree(2)])
	>>> level_mutation_link(t3, funcs)
	>>> t3    # Level 0: 1+1=2; Level 1: 2*5=10; no further levels, so apply remaining z ** 2: 10**2=100
	Tree(2, [Tree(100)])
	"""

	if funcs is Link.empty:
		return

	t.label = funcs.first(t.label)
	remaining = funcs.rest
	if t.is_leaf():
		while remaining is not Link.empty:
			t.label = remaining.first(t.label)
			remaining = remaining.rest
	for b in t.branches:

		level_mutation_link(b, remaining)
