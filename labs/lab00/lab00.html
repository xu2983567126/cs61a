实验 0：入门指南
  • lab00.zip

截止时间：6月23日（星期二）晚上 11:59。

初始文件

下载 lab00.zip。

本实验为全体学生的必修内容。

出勤

要获得本实验的学分，除了参加实验外，你还需要提交实验题目。

如果你有充分理由（如生病或时间冲突）缺席实验，或因故未被签到，请在一周内发送邮件至 cs61a@berkeley.edu 以获取出勤学分。

简介

本实验介绍如何配置你的电脑以完成作业，并引入 Python 的一些基础知识。如果你需要帮助，请在 Ed 上发帖，或在你被分配的实验课上寻求帮助。

以下是本实验的大纲：

  • 环境配置：安装本课程所需的必要软件。这需要以下几个组件，如下所列。

    • 安装终端：安装一个终端，以便你能操作本课程的文件并运行 OK 命令。
    • 安装 Python 3：在你的电脑上安装 3.8 或更高版本（理想情况是 3.11 或更高版本）的 Python。
    • 安装文本编辑器：安装用于编辑本课程 .py 文件的软件。几乎所有学生都使用 VS Code。
  • 回顾：你的电脑文件系统 本部分概览电脑文件系统的工作原理，包括绝对路径与相对路径的含义。
  • 演练：使用终端：本部分带你逐步了解如何使用终端和 Python 解释器。
  • 演练：整理你的文件：本部分带你逐步了解如何使用终端来整理和浏览本课程的文件。每位同学都应阅读本部分。
  • 必做：完成作业：你必须完成本部分才能获得作业学分。这部分的主要目标是让你练习使用我们的软件。
  • 必做：提交作业：提交你的作业。
  • 附录：有用的 Python 命令行选项：这些命令在调试你的代码时很有用，但不是完成本实验所必需的。我们将其纳入，是因为它们很可能在整个课程中对你有所帮助。

你的第一个作业

做作业时，请确保你的终端工作目录正确（通常就是你解压作业的位置）。

1) Python 会怎么做？（WWPD）

实验作业的一个环节是预测 Python 解释器的行为。我们把这类问题称为"Python 会怎么做？"

在本课程中，我们使用一个名为 ok 的程序来评估你的掌握情况。ok 会包含在每次作业中。下面我们来看看如何用 ok 完成一道 WWPD 题目。

打开你的终端，确保你位于包含本作业解压文件的 lab00 目录下。在该目录中输入 ls 以确认存在以下文件：

  • lab00.py：本实验的初始文件
  • ok：我们的测试程序
  • lab00.ok：ok 的配置文件

如果你没有看到这些文件，请使用 cd 切换到正确的目录。

在没有 ok 的目录中尝试运行 ok 会导致错误。

在终端中输入以下内容，它将运行 ok 并开始本部分：

python3 ok -q python-basics -u

命令 python3 ok -q python-basics -u 告诉 Python 解释器运行当前工作目录中名为 ok 的文件。-q python-basics -u 是提供给 ok 程序的输入，用于指定要运行哪道题。

正如环境配置部分所述，如果 python3 命令无效，请尝试使用 python 或 py。

系统会提示你输入各个语句/表达式的输出。你必须正确输入才能继续，但答错不会扣分。

你第一次运行 Ok 时，会要求输入你的 bCourses 邮箱。请按照这些指引操作。

>>> x = 20
>>> x + 2

______
22

>>> x

______
20

>>> y = 5
>>> y = y + 3
>>> y * 2

______
16

>>> y + x

______
28

2) 实现函数

在 VS Code 中打开整个 lab00 文件夹。你可以将文件夹拖拽到 VS Code 应用上，或者打开 VS Code 并在 File 菜单中使用 Open Folder...。打开 lab00 文件夹后，你会在 VS Code 窗口左侧面板的文件资源管理器中看到 lab00.py 文件。点击它开始编辑 lab00.py，这是你为获得实验学分需要提交的文件。

重要：在 VS Code 的 File 菜单中开启 Auto Save（自动保存）。这样，每当你修改文件时，内容都会自动保存。如果你没有开启 Auto Save，请务必经常手动保存你的工作。

推荐：使用 VS Code 内置的终端（菜单中的 Terminal > New Terminal）。如果你按照上述方法在 VS Code 中打开了作业文件夹，那么 VS Code 终端的工作目录会自动设为该作业文件夹，这意味着你无需切换目录即可检查你的代码。

现在来完成本实验。你应该会看到一个名为 twenty_twenty_six 的函数，其中有一个空的 return 语句。这个空语句是你唯一需要修改的部分。把它替换为一个求值结果为 2026 的表达式。你能想出最有创意的表达式吗？

3) 运行测试

我们还会使用 ok 来测试你的代码。切换到终端。确保你位于包含 ok 和 lab00.py 的 lab00 目录下。

小贴士： 如果你在 VS Code 中打开了 lab00 文件夹，并在 VS Code 的 Terminal 菜单中选择 New Terminal，那么终端会自动处于 lab00 目录中。

现在，用以下命令运行 ok 来测试你的代码：

python3 ok

请记住，如果你使用的是 Windows 且 python3 命令无效，请尝试仅使用 python 或 py。

如果你的代码正确，并且已解锁所有测试，你应该会看到测试通过的提示：

=====================================================================
Assignment: Lab 0
=====================================================================

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Running tests

---------------------------------------------------------------------
Test summary
    2 test cases passed! No cases failed.

如果你没有通过测试，ok 会显示类似如下的内容：

---------------------------------------------------------------------
Doctests for twenty_twenty_six

>>> from lab00 import *
>>> twenty_twenty_six()
0

# Error: expected
#     2026
# but got
#     0

---------------------------------------------------------------------
Test summary
    0 test cases passed before encountering first failed test case

在文本编辑器中修改你的代码，直到测试通过。

每次运行 ok 时，ok 都会尝试备份你的作业。如果它提示"连接超时"或你尚未注册该课程，不必担心。你仍然可以提交本作业并获得学分。

4) 学期前问卷

作为本作业的一部分，请填写学期前问卷。

填写完问卷后，你会获得一个口令（passphrase）。请将这个口令作为字符串填入本作业 Python 文件中写着 passphrase = 'REPLACE_THIS_WITH_PASSPHRASE' 的那一行。例如，如果口令是 abc，那么该行应为 passphrase = 'abc'。

使用 Ok 测试你的代码：

python3 ok -q presem_survey

本地查看你的得分

你可以通过运行以下命令，在本地查看本作业每道题的得分：

python3 ok --score

这并不会提交作业！ 当你对得分满意后，请将作业提交到 Gradescope 以获得学分。

提交作业

既然你已经完成了第一个作业，是时候提交它了。你可以按照接下来的步骤提交作业并获得分数。

重要： 你只需提交到 Gradescope，无需提交到 Ok。

通过 Gradescope 提交

  1. 使用你的 CalNet ID，通过 学校账号 登录 Gradescope。登录后你将立即进入你的 仪表盘。

  2. 在你的 仪表盘 中，选择本课程。（你应该已经被加入 Gradescope。如果不是这样，请发一条私密的 Ed 帖子。）这将带你进入本课程中可以提交的作业列表。在该列表上，你会看到作业的状态、发布日期和截止日期。
  3. 点击作业 Lab 0 打开它。

  4. 当对话框出现时，点击写着 Drag & Drop（拖放）的灰色区域。这将打开你的文件管理器，你应当选择为本作业编辑过的代码文件 lab00.py。


  5. 选择文件后，点击 Upload（上传）按钮。上传成功后，你会在屏幕上看到确认信息，并且会收到一封邮件。

  6. 接下来，等待几分钟让自动评分器为你的代码文件评分。你的最终得分会显示在右侧，你的输出应当与你本地测试时的一致。你可以在右上方一个标有 Code（代码）的标签页中查看你提交的代码。如果还有错误，你可以修改你的 lab00.py 代码，并点击屏幕底部的 Resubmit（重新提交）来重新提交你的代码文件。在截止日期之前，作业可以重新提交任意多次。

你对 WWPD 题目的回答无需提交到 Gradescope，也没有必要提交。实验学分基于代码编写题目。

恭喜，你刚刚提交了你的第一个作业！

附录：有用的 Python 命令行选项

  • ls：list 列出当前目录下的所有文件
  • cd <目录路径>：change 切换到指定directory（目录）
  • mkdir <目录名>：make 创建一个指定名称的新directory（目录）

以下是在文件上运行 Python 最常见的方式。

  1. 不使用任何命令行选项，会运行你提供的文件中的代码，并将你返回到命令行。如果你的文件只包含函数定义，那么除非存在语法错误，否则你看不到任何输出。

    python3 lab00.py

  2. -i：-i 选项会运行你提供的文件中的代码，然后打开一个交互式会话（带有 >>> 提示符）。此后你可以求值表达式，例如调用你定义的函数。要退出，请输入 exit()。你也可以使用键盘快捷键：在 Linux/Mac 机器上为 Ctrl-D，在 Windows 上为 Ctrl-Z Enter。

    如果你在交互式运行期间编辑了 Python 文件，则需要退出并重新启动解释器，这些改动才能生效。

    以下是我们以交互方式运行 lab00.py 的方法：

    python3 -i lab00.py

  3. -m doctest：运行文件中的 doctest，即函数文档字符串中的示例。

    文件中的每个测试由 >>> 后跟一些 Python 代码及其预期输出组成。

    以下是我们运行 lab00.py 中 doctest 的方法：

     python3 -m doctest lab00.py

    当我们的代码通过所有 doctest 时，不会显示任何输出。否则，会显示有关失败测试的信息。
