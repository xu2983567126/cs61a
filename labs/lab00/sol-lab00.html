本实验是所有学生都必须完成的。

出勤

除了出勤，你还需要提交实验题目才能获得实验学分。

If you miss lab for a good reason (such as sickness or a scheduling conflict) or you don't get checked in for some reason, email cs61a@berkeley.edu 在一周内完成以获得出勤学分。

引言

本实验介绍如何配置你的电脑以完成作业，并介绍 Python 的一些基础知识。如果你需要任何帮助，请在 Ed 上发帖，或在你分配到的实验小节中寻求帮助。

以下是本实验的概要：

  • 环境配置：配置课程所需的必要软件。这需要以下几个组件，列在下面。

    • 安装终端：安装一个终端，以便你可以与文件交互并完成本课程中的任务以及运行 OK 命令。
    • 安装 Python 3：在你的电脑上安装 Python 3.8 或更高版本（最好是 Python 3.11 或更高版本）。
    • 安装文本编辑器: Install software to edit .py 文件。几乎所有学生都使用 VS Code。
  • 复习：你的计算机系统 这是对你的计算机系统如何工作的概述，包括绝对文件路径和相对文件路径的含义。
  • 操作演示：使用终端：本节引导你如何使用终端和 Python 解释器。
  • 操作演示：整理你的文件：本节引导你如何使用终端来整理和浏览本课程的文件。 每个人都应当阅读本节。
  • 必做：完成作业：你必须完成本节才能获得本次作业的学分。这部分的主要目标是让你练习使用我们的软件。
  • 必做：提交作业：提交你的工作。
  • 附录：有用的 Python 命令行选项：这些是命令， 在调试你的工作时很有用，但不是完成实验所必需的。我们包含它们是因为它们很可能在本课程中一直对你有帮助。

你的第一个作业

在做作业时，确保你的终端工作目录是正确的（很可能就是你解压作业的地方）。

1) Python 会怎么做？（WWPD）

实验作业的一个组成部分是预测 Python 解释器的行为。我们称这类问题为“Python 会怎么做？”

In this class, we use a program called ok 来评估你的知识。 ok will be included with every assignment. Let's go through how to do a WWPD question with ok.

Open your terminal, and make sure you are in the lab00 directory that contains the unzipped lab files for this assignment. In that directory, type ls 来验证存在以下文件：

  • lab00.py：本实验的起始文件
  • ok：我们的测试程序
  • lab00.ok: a configuration file for ok

If you don't see these files, use cd 以导航到正确的目录。

Attempting to run ok in a directory that does not have ok 会产生一个错误。

Enter the following in your terminal, which will run ok and begin this section:

python3 ok -q python-basics -u

The command python3 ok -q python-basics -u tells the Python interpreter to run the file with the name ok 在当前工作目录中。 -q python-basics -u are inputs provided to the ok 程序，它识别要运行哪个问题。

As stated in the setup section, if the python3 command does not work, please try using python or py.

You will be prompted to enter the output of various statements/expressions. You must enter them correctly to move on, but there is no penalty for incorrect answers.

The first time you run Ok, you will be prompted for your bCourses email. Please follow 这些说明.

>>> x = 20
>>> x + 2
22
>>> x
20
>>> y = 5
>>> y = y + 3
>>> y * 2
16
>>> y + x
28

2) 实现函数

Open the entire lab00 folder in VS Code. You can drag the folder onto the VS Code application or open VS Code and use Open Folder... in the File menu. Once you open the lab00 folder, you'll see the lab00.py 文件，在 VS Code 窗口左侧面板的文件资源管理器中。点击它开始编辑 lab00.py，它是你将提交以获得实验学分的文件。

重要: Turn on Auto Save in the File menu of VS Code. Then, whenever you change a file, the contents will be saved. If you don't enable Auto Save，请确保经常保存你的工作。

推荐：使用 VS Code 内的终端（Terminal > New Terminal 在菜单中）。如果你按照上面的说明在 VS Code 中打开了作业文件夹，那么 VS Code 终端的工作目录会自动设置为作业文件夹，这意味着你不需要切换目录就能检查你的工作。

Now complete the lab. You should see a function called twenty_twenty_six that has a blank return statement. That blank is the only part you should change. Replace it with an expression that evaluates to 2026. What's the most creative expression you can come up with?

3) 运行测试

We'll also use ok to test your code. Switch to the terminal. Make sure you are in the lab00 包含 ok and lab00.py.

专业建议： If you opened the lab00 folder in VS Code and select New Terminal in the Terminal menu of VS Code, then the terminal will automatically be in the lab00 目录。

Now, run ok 使用此命令来测试你的代码：

python3 ok

Remember, if you are using Windows and the python3 命令不起作用，请尝试仅使用 python or py.

如果你正确编写了代码并完成了测试解锁，你应该会看到一个成功的测试：

=====================================================================
Assignment: Lab 0
=====================================================================

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Running tests

---------------------------------------------------------------------
Test summary
    2 test cases passed! No cases failed.

If you didn't pass the tests, ok 而是会向你显示类似这样的内容：

---------------------------------------------------------------------
Doctests for twenty_twenty_six

>>> from lab00 import *
>>> twenty_twenty_six()
0

# Error: expected
#     2026
# but got
#     0

---------------------------------------------------------------------
Test summary
    0 test cases passed before encountering first failed test case

在文本编辑器中修改你的代码，直到测试通过。

Every time you run ok, ok 会尝试备份你的工作。如果它说“连接超时”或者你没有被加入本课程，不要担心。你仍然可以提交本次作业并获得学分。

4) 学期前问卷

作为本次作业的一部分，请填写 学期前问卷 形式。

完成问卷后，你会看到一个口令。将这个口令作为字符串，填在写有 passphrase = 'REPLACE_THIS_WITH_PASSPHRASE' in the Python file for this assignment. E.g. if the passphrase is abc, then the line should be passphrase = 'abc'.

你可以运行以下命令在本地查看本次作业每道题的得分

python3 ok --score

这并不会提交作业！ 当你对得分满意时，将作业提交到 Gradescope 以获得学分。

提交作业

既然你已经完成了第一个作业，是时候提交了。你可以按照以下步骤提交作业并获得分数。

重要： You only need to submit to Gradescope; you do not need to submit to Ok.

通过 Gradescope 提交

  1. Log in with 学校账号 using your CalNet ID to Gradescope. You’ll be taken to your 仪表盘 as soon as you log in.

  2. On your 仪表盘，选择本课程。（你应该已经被加入到 Gradescope 中了。如果不是这样，请发一个私密的 Ed 帖子。）这将带你进入你可以提交的课程作业列表。在这个列表中，你会看到作业的状态、发布日期和截止日期。
  3. 点击作业 Lab 0 将其打开。

  4. When the dialog box appears, click on the gray area that says 拖放. This will open your file finder and you should select your code file lab00.py 你为本次作业修改过的。


  5. Once you have chosen your file select the 上传 button. When your upload is successful, you’ll see a confirmation message on your screen and you will receive an email.

  6. Next, wait a few minutes for the autograder to grade your code file. Your final score will appear at the right and your output should be the same as the one you tested locally. You can check the code that you submitted at the top right where there is a tab labeled 代码. If there are any errors, you can edit your lab00.py code and click 重新提交 at the bottom of your screen to resubmit your code file. Assignments can be resubmitted as many times as you would like before the deadline.

你对 WWPD 问题的回答不会提交到 Gradescope，也没有必要提交。实验学分基于代码编写题目。

恭喜，你刚刚提交了你的第一个作业！

附录：有用的 Python 命令行选项

  • ls: lists all files in the current directory
  • cd <path to directory>: change into the specified directory
  • mkdir <directory name>: makes a new directory with the given name

以下是在文件上运行 Python 最常见的方式。

  1. Using no command-line options will run the code in the file you provide and return you to the command line. If your file just contains function definitions, you'll see no output unless there is a syntax error.

    python3 lab00.py

  2. -i: The -i option runs the code in the file you provide, then opens an interactive session (with a >>> 提示符）。然后你可以求值诸如调用你定义的函数之类的表达式。要退出，输入 exit(). You can also use the keyboard shortcut Ctrl-D on Linux/Mac machines or Ctrl-Z Enter 在 Windows 上。

    如果你在交互式运行时编辑了 Python 文件，你需要退出并重新启动解释器，才能使这些更改生效。

    Here's how we can run lab00.py 交互式地：

    python3 -i lab00.py

  3. -m doctest：运行文件中的 doctest，即函数文档字符串中的示例。

    Each test in the file consists of >>> 后面跟着一些 Python 代码和预期输出。

    Here's how we can run the doctests in lab00.py:

     python3 -m doctest lab00.py

    当我们的代码通过了所有 doctest 时，不会显示任何输出。否则， 会显示有关失败测试的信息。
