短路求值

你认为如果我们把下面这段内容输入 Python 会发生什么？

1 / 0

在 Python 中试一试吧！你应该会看到一个 ZeroDivisionError。但下面这个表达式呢？

True or 1 / 0

它会求值为 True，因为 Python 的 and 和 or 运算符会短路。也就是说，它们不一定会求值每一个操作数。

运算符 检查条件： 从左向右求值直到： 示例
AND 所有值都为真 第一个为假的值 False and 1 / 0 求值为 False
OR 至少有一个值为真 第一个为真的值 True or 1 / 0 求值为 True

当运算符遇到一个足以让它对表达式得出结论的操作数时，就会发生短路。例如，and 一旦遇到第一个为假的值就会短路，因为它此时已经知道并非所有值都为真。

如果 and 和 or 没有发生短路，它们就只是返回最后一个值；换一种记忆方式：无论是否短路，and 和 or 总是返回它们最后求值的那个东西。请注意，当使用 True 和 False 之外的值时，and 和 or 并不总是返回布尔值。

高阶函数

变量是绑定到值的名称，这些值可以是像 3 或 'Hello World' 这样的基本对象，但也可以是函数。由于函数可以接受任意值作为参数，因此其他函数也可以作为参数传入。这就是高阶函数的基础。

高阶函数是指那些通过接受函数作为参数、返回一个函数，或两者兼具的方式来操作其他函数的函数。我们将在本实验中介绍高阶函数的基础知识，并在下一次实验中探索高阶函数的许多应用。

作为参数的函数

在 Python 中，函数对象是可以被传递的值。我们知道，创建函数的一种方式是使用 def 语句：

def square(x):
    return x * x

上面的语句创建了一个内在名称为 square 的函数对象，并将其绑定到当前环境中的名称 square。现在让我们试着把它作为参数传入。

首先，我们来写一个接受另一个函数作为参数的函数：

def scale(f, x, k):
    """ Returns the result of f(x) scaled by k. """
    return k * f(x)

现在我们可以用 scale 作用于 square 和其他一些参数：

>>> scale(square, 3, 2) # Double square(3)
18
>>> scale(square, 2, 5) # 5 times 2 squared
20

注意，在调用 scale 的函数体中，内在名称为 square 的函数对象被绑定到了参数 f 上。然后，我们在 scale 的函数体中通过调用 f(x) 来调用 square。

正如我们在上面关于 lambda 表达式的小节中所看到的，我们也可以把 lambda 表达式作为调用表达式的实参传入！

>>> scale(lambda x: x + 10, 5, 2)
30

在这个调用表达式的帧中，名称 f 被绑定到由 lambda 表达式 lambda x: x + 10 所创建的函数上。

返回函数的函数

由于函数是值，因此它们作为返回值也是合法的！下面是一个例子：

def multiply_by(m):
    def multiply(n):
        return n * m
    return multiply

在这个特定情况下，我们在 multiply_by 的函数体内部定义了函数 multiply，然后将其返回。让我们看看它的实际效果：

>>> multiply_by(3)
<function multiply_by.<locals>.multiply at ...>
>>> multiply(4)
Traceback (most recent call last):
File "<stdin>", line 1, in <module>
NameError: name 'multiply' is not defined

对 multiply_by 的调用会如预期那样返回一个函数。然而，调用 multiply 却会报错，尽管那是我们给内部函数起的名字。这是因为名称 multiply 只存在于我们求值 multiply_by 函数体时所处帧的范围内。

那么我们到底该如何使用这个内部函数呢？这里有两种方式：

>>> times_three = multiply_by(3) # Assign the result of the call expression to a name
>>> times_three(5) # Call the inner function with its new name
15
>>> multiply_by(3)(10) # Chain together two call expressions
30

重点在于，由于 multiply_by 返回的是一个函数，因此你可以像使用任何其他函数一样使用它的返回值。

lambda 表达式

lambda 表达式是通过指定两样东西——参数和一个返回表达式——来求值得到函数的表达式。

lambda <parameters>: <return expression>

虽然 lambda 表达式和 def 语句都会创建函数对象，但它们之间有一些值得注意的区别。lambda 表达式和其他表达式一样工作；就像一个数学表达式只是求值得到一个数字、而不会改变当前环境一样，lambda 表达式求值得到一个函数，而不会改变当前环境。让我们仔细看一看。

lambda def
类型 表达式，求值为一个值。 语句，会改变环境。
执行结果 创建一个没有内在名称的匿名 lambda 函数。 创建一个具有内在名称的函数，并将其绑定到当前环境中的该名称。
对环境的影响 求值 lambda 表达式不会创建或修改任何变量。 执行 def 语句既会创建一个新的函数对象，也会将其绑定到当前环境中的一个名称。
用法 lambda 表达式可以用在任何需要表达式的地方，例如在赋值语句中，或作为调用表达式的运算符或操作数。 执行 def 语句后，所创建的函数会被绑定到一个名称。你应当在任何需要表达式的地方使用该名称来引用这个函数。
示例 
# A lambda expression by itself does not alter
# 环境
lambda x: x * x

# 我们可以把 lambda 函数赋给一个名字
# 使用赋值语句
square = lambda x: x * x
square(3)

# lambda 表达式可以用作运算符
# 或操作数
negate = lambda f, x: -f(x)
negate(lambda x: x * x, 3)
 
def square(x):
    return x * x

# 由 def 语句创建的函数
# 可以通过其固有名称来引用
square(3)

Q5：计数条件

考虑下面 count_fives 和 count_primes 的实现，它们使用了下面定义的 sum_digits 和 is_prime 函数：

def count_fives(n):
    """Return the number of values i from 1 to n (including n)
    where sum_digits(n * i) is 5.

    >>> count_fives(10)  # Among 10, 20, 30, ..., 100, only 50 (10 * 5) has digit sum 5
    1
    >>> count_fives(50)  # 50 (50 * 1), 500 (50 * 10), 1400 (50 * 28), 2300 (50 * 46)
    4
    """
    i = 1
    count = 0
    while i <= n:
        if sum_digits(n * i) == 5:
            count += 1
        i += 1
    return count

def count_primes(n):
    """Return the number of prime numbers up to and including n.

    >>> count_primes(6)   # 2, 3, 5
    3
    >>> count_primes(13)  # 2, 3, 5, 7, 11, 13
    6
    """
    i = 1
    count = 0
    while i <= n:
        if is_prime(i):
            count += 1
        i += 1
    return count

这两个实现看起来非常相似！通过编写一个函数 count_cond 来推广这一逻辑，它接受一个双参数的谓词函数 condition(n, i)。count_cond 返回一个单参数函数，该函数接受 n，并统计从 1 到 n 中所有在调用时满足 condition 的数字个数。

注意： 当我们说 condition 是一个谓词函数时，我们的意思是它是一个会返回 True 或 False 的函数。

def sum_digits(y):
    """Return the sum of the digits of non-negative integer y."""
    total = 0
    while y > 0:
        total, y = total + y % 10, y // 10
    return total

def is_prime(n):
    """Return whether positive integer n is prime."""
    if n == 1:
        return False
    k = 2
    while k < n:
        if n % k == 0:
            return False
        k += 1
    return True

def count_cond(condition):
    """Returns a function with one parameter N that counts all the numbers from
    1 to n that satisfy the two-argument predicate function Condition, where
    the first argument for condition is n and the second argument is the
    number from 1 to n.

    >>> count_fives = count_cond(lambda n, i: sum_digits(n * i) == 5)
    >>> count_fives(10)   # 50 (10 * 5)
    1
    >>> count_fives(50)   # 50 (50 * 1), 500 (50 * 10), 1400 (50 * 28), 2300 (50 * 46)
    4

    >>> is_i_prime = lambda n, i: is_prime(i) # need to pass 2-argument function into count_cond
    >>> count_primes = count_cond(is_i_prime)
    >>> count_primes(2)    # 2
    1
    >>> count_primes(3)    # 2, 3
    2
    >>> count_primes(4)    # 2, 3
    2
    >>> count_primes(5)    # 2, 3, 5
    3
    >>> count_primes(20)   # 2, 3, 5, 7, 11, 13, 17, 19
