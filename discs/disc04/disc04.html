列表

你们中有些人已经知道我们还没讲过的列表操作，比如 append。今天不要使用这些。你只需要用到列表字面量（例如 [1, 2, 3]）、元素选取（例如 s[0]）、列表相加（例如 [1] + [2, 3]）、len（例如 len(s)）以及切片（例如 s[1:]）。用这些就够了！本周晚些时候我们会介绍其他列表操作，到时候会有充足的时间练习。

关于列表，最重要的一点是：一个非空列表 s 可以拆分为它的第一个元素 s[0] 和列表的其余部分 s[1:]。

>>> s = [2, 3, 6, 4]
>>> s[0]
2
>>> s[1:]
[3, 6, 4]
列表推导式描述了列表中的元素，并求值得到包含这些元素的一个新列表。

有两种形式：

[<expression> for <element> in <sequence>]
[<expression> for <element> in <sequence> if <conditional>]

下面是一个例子：从 [1, 2, 3, 4] 开始，使用 if i % 2 == 0 挑出偶数元素 2 和 4，然后用 i*i 对每个元素求平方。for i 的作用是为 [1, 2, 3, 4] 中的每个元素起一个名字。

>>> [i*i for i in [1, 2, 3, 4] if i % 2 == 0]
[4, 16]

这个列表推导式求值得到一个包含以下内容的列表：

  • 表达式 i*i 的值
  • 对于序列 [1, 2, 3, 4] 中的每个元素 i
  • 满足 i % 2 == 0 的那些元素

换句话说，这个列表推导式会创建一个新列表，其中包含原列表 [1, 2, 3, 4] 中每个偶数元素的平方。

我们也可以把列表推导式改写成等价的 for 语句，例如上面的例子：

>>> result = []
>>> for i in [1, 2, 3, 4]:
...     if i % 2 == 0:
...         result = result + [i*i]
>>> result
[4, 16]

Q1：偶数加权

编写一个函数，接收一个列表 s，返回一个新的列表，只保留 s 中下标为偶数的元素，并将它们乘以各自对应的下标。首先用普通的 for 循环（不使用列表推导式）来解决这个问题。

既然你已经用 for 循环做出来了，现在试试用列表推导式来实现！

字典

字典（dictionary）是 Python 中一种将 键 映射到 值 的数据结构。对于一个字典 d：

  • 每个键恰好映射到一个值，你可以用 d[<key>] 来访问它。
  • 如果你尝试 d[<key>]，但 <key> 不是 d 中有效的键，就会报错。
  • 你可以用 <key> in d 来测试某个键是否在 d 中（返回 True 或 False）。
  • d.get(<key>, <default>) 会返回 <key> 在 d 中映射的值；如果 <key> 不是 d 中的键，则返回 <default>。
  • 可以分别用 d.keys()、d.values() 或 d.items() 来访问键、值或键值对的序列。
  • 键可以是任意不可变类型（如字符串、数字和元组），但不能是可变类型（如列表）。
  • 你可以在 for 循环中使用字典 d（例如 for k in d）。这样做会遍历 d 中的键。

Q2：快乐赠礼者

在某个讨论小组中，一些人在节日期间互赠礼物。如果两个人互相送礼物，我们称他们为 快乐赠礼者。请实现函数 happy_givers，它接收一个 gifts 字典，将小组中的每个人映射到他们送礼的对象。happy_givers 返回一个列表，包含小组中所有的快乐赠礼者。列表的顺序无关紧要。

注意，如果有人只收到礼物但没有送出礼物，他们不会作为键出现在 gifts 字典中（只会作为值出现）。你可以假设没有人给自己送礼物。

找到解法后，作为挑战，试着用一行列表推导式来实现。

选做：设想另一种情况，字典中每个人都是键，其值是一个列表，包含他们送礼给的所有人。尝试实现一种解法，在这种配置下找出所有快乐赠礼者的列表。

树

对于一棵树 t：

  • 它的根标签可以是任意值，label(t) 会返回它。
  • 它的分支是树，branches(t) 返回分支组成的列表。
  • 可以用 tree(label(t), branches(t)) 构造出一棵相同的树。
  • 你可以调用以树为参数的函数，例如 is_leaf(t)。
  • 这就是操作树的方式。不要使用 t == x、t[0]、x in t 或 list(t) 等。
  • 无法修改一棵树（且不能违背抽象屏障）。

下面是一个树 t1 的例子，它的分支 branches(t1)[1] 是 t2。

t2 = tree(5, [tree(6), tree(7)])
t1 = tree(3, [tree(4), t2])

一条路径（path）是一系列树的序列，其中每个树都是下一个树的父节点。

def tree(label, branches=[]):
    for branch in branches:
        assert is_tree(branch), 'branches must be trees'
    return [label] + list(branches)

def label(tree):
    return tree[0]

def branches(tree):
    return tree[1:]

def is_leaf(tree):
    return not branches(tree)

def is_tree(tree):
    if type(tree) != list or len(tree) < 1:
        return False
    for branch in branches(tree):
        if not is_tree(branch):
            return False
    return True

Q3：热身

result 被绑定为什么值？

result = label(min(branches(max([t1, t2], key=label)), key=label))

真绕啊！

下面是一个关于 key 函数如何与 max 和 min 配合使用的快速回顾，

max(s, key=f) 会返回 s 中使得 f(x) 最大的那个元素 x。

>>> s = [-3, -5, -4, -1, -2]
>>> max(s)
-1
>>> max(s, key=abs)
-5
>>> max([abs(x) for x in s])
5

因此，max([t1, t2], key=label) 会返回标签最大的树，在本例中就是 t2。

如果你感到疑惑，这个表达式并没有违背抽象屏障。[t1, t2] 和 branches(t) 都是列表（不是树），所以在它们上面调用 min 和 max 是没问题的。

Q4：存在路径

实现 has_path，它接收一棵树 t 和一个列表 p。它返回一个布尔值，表示是否存在一条从 t 的根出发、标签依次为 p 的路径。例如，t1 存在一条从根出发、标签为 [3, 5, 6] 的路径，但不存在 [3, 4, 6] 或 [5, 6] 的路径。

重要：在尝试实现这个函数之前，先讨论一下课堂上关于树处理函数的递归调用提出的这些问题：

  • 我能做的一个小的初始选择是什么（比如探索哪个分支）？
  • 对每个选项，我应该做怎样的递归调用？

  • 我该如何组合这些递归调用的结果？

    • 它们返回的是什么类型的值？
    • 这些返回值代表什么意思？

Q5：寻找路径

实现 find_path，它接收一棵标签唯一的树 t 和一个值 x。它返回一个列表，包含从 t 的根到标签为 x 的节点这条路径上所有节点的标签。

如果 x 不是 t 中的标签，则返回 None。假设 t 的标签是唯一的。

Q6：修剪叶子

实现 prune_leaves，它接收一棵树 t 和一个值元组 vals。它返回一个 t 的修改版本，其中所有标签属于 vals 的叶子都被移除。不要移除非叶子节点，也不要移除标签不在 vals 中的叶子。如果修剪后树中没有任何节点剩下，则返回 None。
