列表

你们当中有些人可能已经了解了我们尚未讲到的列表操作， 例如 append。今天请不要使用那些操作。你只需要用到列表字面量（例如 [1, 2, 3]）、元素选取（例如 s[0]）、列表相加（例如 [1] + [2, 3]), len（例如 len(s)）以及切片（例如 s[1:]）。用这些就够了！本周晚些时候讲到其他列表操作时， 你会有充足的时间练习它们。

关于列表，最要记住的一点是：一个非空列表 s 可以拆分为它的第一个元素 s[0] 以及列表的其余部分 s[1:].

>>> s = [2, 3, 6, 4]
>>> s[0]
2
>>> s[1:]
[3, 6, 4]
列表推导式描述了列表中的元素，并求值为一个包含这些元素的 新列表。

有两种形式：

[<expression> for <element> in <sequence>]
[<expression> for <element> in <sequence> if <conditional>]

下面是一个以 [1, 2, 3, 4] 开头的例子，它挑选出其中的偶数元素 2 和 4 使用 if i % 2 == 0，然后对其中的每一个使用 i*i。 其 目的是 for i 是为了给 [1, 2, 3, 4].

>>> [i*i for i in [1, 2, 3, 4] if i % 2 == 0]
[4, 16]

这个列表推导式求值为如下列表：

  • 的值为 i*i
  • 对于每一个元素 i 在序列 [1, 2, 3, 4]
  • 对于满足 i % 2 == 0

换句话说，这个列表推导式会创建一个新列表，其中包含 原列表 [1, 2, 3, 4].

我们也可以把一个列表推导式改写成等价的 for 语句， 例如上面这个例子：

>>> result = []
>>> for i in [1, 2, 3, 4]:
...     if i % 2 == 0:
...         result = result + [i*i]
>>> result
[4, 16]

Q1：偶数加权

写一个函数，它接收一个列表 s 并返回一个新列表，其中只保留 列表 s 中索引为偶数的元素，并将它们乘以 各自对应的索引。首先请用普通的 for 循环（不使用列表推导式）来解决这个问题。

你的答案
解答 
def even_weighted_loop(s):
    """
    >>> x = [1, 2, 3, 4, 5, 6]
    >>> even_weighted_loop(x)
    [0, 6, 20]
    """
    result = []
    for i in range(len(s)):
        if i % 2 == 0:
            result = result + [i * s[i]]
    return result

既然你已经用 for 循环做了一遍，现在试着用列表推导式来做！

你的答案
解答 
def even_weighted_comprehension(s):
    """
    >>> x = [1, 2, 3, 4, 5, 6]
    >>> even_weighted_comprehension(x)
    [0, 6, 20]
    """
    return [i * s[i] for i in range(len(s)) if i % 2 == 0]

需要注意的关键点是：我们不能遍历列表中的每个元素， 而必须遍历列表的索引。否则，我们 无法判断某个元素是否应该保留。

字典

字典是一种 Python 数据结构，它将 键 到 值。对于一个字典 d:

  • 每个键都映射到唯一的一个值，你可以用 d[<key>].
  • 如果你尝试 d[<key>] 但 <key> 中的有效键，d 中的有效键，就会报错。
  • 你可以使用 <key> in d 来测试（True 或 False）某个键是否存在于 d.
  • d.get(<key>, <default>) 会返回 <key> 在 d，或者 <default> 如果 <key> 不是 d.
  • 键、值或键值对的序列可以分别通过 d.keys() 或 d.values() 或 d.items() 来访问。
  • 键可以是任意不可变类型（如字符串、数字和元组），但不能是可变类型（如列表）。
  • 你可以使用一个 d 在一个 for 循环（例如 for k in d）。这样会遍历 d.

Q2：互赠礼物的人

注意，如果某人只收到礼物但没有送出礼物，他就不会作为键出现在 gifts 字典中（只能作为值出现）。 你可以假设没有人会送给自己礼物。

树

对于一棵树 t:

  • 它的根标签可以是任意值，并且 label(t) 会返回它。
  • 它的分支也是树，并且 branches(t) 会返回分支的列表。
  • 一棵相同的树可以用 tree(label(t), branches(t)).
  • 你可以调用以树作为参数的函数，例如 is_leaf(t).
  • 这就是你操作树的方式。不需要 t == x 或 t[0] 或 x in t 或 list(t)，等等。
  • 没有任何办法去修改一棵树（那会违反抽象屏障）。

下面是一个树的例子 t1，它的分支 branches(t1)[1] 是 t2.

t2 = tree(5, [tree(6), tree(7)])
t1 = tree(3, [tree(4), t2])

一条路径是一系列树，其中每一棵都是下一棵的父节点。

def tree(label, branches=[]):
    for branch in branches:
        assert is_tree(branch), 'branches must be trees'
    return [label] + list(branches)

def label(tree):
    return tree[0]

def branches(tree):
    return tree[1:]

def is_leaf(tree):
    return not branches(tree)

def is_tree(tree):
    if type(tree) != list or len(tree) < 1:
        return False
    for branch in branches(tree):
        if not is_tree(branch):
            return False
    return True

Q3：热身

什么值被绑定到了 result?

result = label(min(branches(max([t1, t2], key=label)), key=label))

解答

6: max([t1, t2], key=label) 求值为 t2 树，因为它的标签 5 大于 t1 的标签 3。在 t2 的分支（都是叶子）中，左边那个 标签为 6 的分支标签更小。

真绕！

快速复习一下 key 函数如何与 max 和 min,

max(s, key=f) 返回 x 在 s 满足 f(x) 最大的那个元素。

>>> s = [-3, -5, -4, -1, -2]
>>> max(s)
-1
>>> max(s, key=abs)
-5
>>> max([abs(x) for x in s])
5

因此， max([t1, t2], key=label) 返回标签最大的树， 在本例中为 t2.

以防你疑惑，这个表达式并没有违反抽象 屏障。[t1, t2] 和 branches(t) 都是列表（不是树），因此可以 直接调用 min 和 max 对它们操作。

Q4：存在路径

实现 has_path，它接收一棵树 t 和一个列表 p。它返回 从 t 出发、标签依次为 p。例如，t1 是否存在一条 从根出发、标签为 [3, 5, 6] 但不存在 [3, 4, 6] 或 [5, 6].

重要：在尝试实现这个函数之前，请先讨论一下 课堂上关于处理树的函数的递归调用提出的这些问题：

  • 我能做出什么小的初始选择（例如探索哪个分支）？
  • 对于每个分支，我应该做怎样的递归调用？

  • 我该如何把这些递归调用的结果组合起来？

    • 它们返回什么类型的值？
    • 那些返回值意味着什么？
你的答案
解答 
def has_path(t, p):
    """Return whether tree t has a path from the root with labels p.

    >>> t2 = tree(5, [tree(6), tree(7)])
    >>> t1 = tree(3, [tree(4), t2])
    >>> has_path(t1, [5, 6])        # This path is not from the root of t1
    False
    >>> has_path(t2, [5, 6])        # This path is from the root of t2
    True
    >>> has_path(t1, [3, 5])        # This path does not go to a leaf, but that's ok
    True
    >>> has_path(t1, [3, 5, 6])     # This path goes to a leaf
    True
    >>> has_path(t1, [3, 4, 5, 6])  # There is no path with these labels
    False
    """
    if p == [label(t)]:
        return True
    elif label(t) != p[0]:
        return False
    else:
        return any([has_path(b, p[1:]) for b in branches(t)])

        for b in branches(t):
            if has_path(b, p[1:]):
                return True
        return False

Q5：查找路径

实现 find_path，它接收一棵树 t，该树的标签唯一，并接收一个值 x。它返回一个列表，包含从 t 的根到某个标签为 x.

如果 x 不是 t，则返回 None。假设 t 的标签是唯一的。

你的答案
解答 
def find_path(t, x):
    """
    >>> t2 = tree(5, [tree(6), tree(7)])
    >>> t1 = tree(3, [tree(4), t2])
    >>> find_path(t1, 5)
    [3, 5]
    >>> find_path(t1, 4)
    [3, 4]
    >>> find_path(t1, 6)
    [3, 5, 6]
    >>> find_path(t2, 6)
    [5, 6]
    >>> print(find_path(t1, 2))
    None
    """
    if label(t) == x:
        return [label(t)]
    for b in branches(t):
        path = find_path(b, x)
        if path:
            return [label(t)] + path
    return None
基准情形的返回值 [label(t)] 创建了一个单元素列表，包含从 t 的根开始、也在那里结束的路径上的标签，因为根节点的标签是 x.

赋值语句 path = find_path(b, x) 让这次递归调用的返回值可以被使用两次：一次用于检查它是否为 None（这是一个假值），另一次用于构建更长的列表。

表达式 [label(t)] + path 对于一棵树 t 和列表 path 会创建一个更长的列表，它以 t 的标签开头，并接着包含 path.

Q6：剪除叶子

实现 prune_leaves，它接收一棵树 t 和一个值的元组 vals。 它返回一个 t 的版本，其中所有 叶子 的标签属于 vals 的叶子都已被移除。不要删除非叶子节点，也不要删除标签不在 vals。返回 None 中的叶子。如果剪枝后树中 没有任何节点剩下，则返回

你的答案
解答 def prune_leaves(t, vals): 
"""Return a version of t (a new tree) with all leaves that have a label
that appears in vals removed. Return None if the entire tree is
pruned away.

>>> t = tree(2)
>>> print(prune_leaves(t, (1, 2)))
None
>>> numbers = tree(1, [tree(2), tree(3, [tree(4), tree(5)]), tree(6, [tree(7)])])
>>> print_tree(numbers)
1
  2
  3
    4
    5
  6
    7
>>> print_tree(prune_leaves(numbers, (3, 4, 6, 7)))
1
  2
  3
    5
  6
"""
if is_leaf(t) and (label(t) in vals):
  return None
new_branches = []
for b in branches(t):
  new_branch = prune_leaves(b, vals)
  if new_branch:
    new_branches.append(new_branch)
return tree(label(t), new_branches)
