解释器

解释器是一个让你能用某种语言与计算机交互的程序。它理解你用该语言输入的表达式，并以某种方式执行相应的操作，通常借助一种底层语言。

当我们谈论一个解释器时，涉及两种语言：

  1. 被解释/被实现的语言。
  2. 底层的实现语言。

许多解释器使用“读取-求值-打印循环”（REPL）。这个循环等待用户输入，然后分三步处理它：

  • 读取（Read）： 解释器接收用户输入（字符串），将输入字符串拆分成小块（记号），再将这些记号组织成数据结构。
  • 求值（Eval）： eval 与 apply 之间的相互递归对表达式求值以获得一个值。

表示列表

Scheme 的调用表达式是一个 Scheme 列表，在 Python 中用 Link 实例表示。

例如，调用表达式 (+ (* 3 4) 5) 表示为：

Link('+', Link(Link('*', Link(3, Link(4, nil))), Link(5, nil)))

那些 nil 是可选的，因为 nil 就是 Link.empty，它是 Link 类的 __init__ 方法的默认第二个参数。

Link('+', Link(Link('*', Link(3, Link(4))), Link(5)))

Link 类和 nil 对象定义在 link.py 中（属于 Scheme 项目）。

class Link:
    "A Scheme list is a Link in which rest is a Link or nil."
    empty = ()
    def __init__(self, first, rest=empty):
        self.first = first
        self.rest = rest

    ... # There are also __str__, __repr__, and map methods, omitted here.

nil = Link.empty

求值

Q1: 求值

当在 x 绑定为 -2 的环境中，对 (if (< x 0) (- x) (if (= x -2) 100 y)) 调用 scheme_eval 时，以下哪些会被求值？请选择所有适用的项。（假设 <、- 和 = 取它们的默认值。）

  • if
  • <
  • =
  • x
  • y
  • 0
  • -2
  • 100
  • -
  • (
  • )
被求值的选项是：<、x、0 和 -。表达式 (if (= x -2) 100 y) 中的任何部分都不会被求值，因为原始条件求值为 #t，所以它会求值结果分支中的表达式，即 (- x)。此外，if 不会被求值，因为它是一个特殊形式，而不是某个调用表达式的运算符。

要使用第 4 个项目（Project 4）的解释器对表达式 (+ (* 3 4) 5) 求值，会按以下顺序对这些表达式调用 scheme_eval：

  1. (+ (* 3 4) 5)
  2. +
  3. (* 3 4)
  4. *
  5. 3
  6. 4
  7. 5

* 会被求值，因为它是 (* 3 4) 的运算符子表达式，而 (* 3 4) 又是 (+ (* 3 4) 5) 的一个操作数子表达式。

if 表达式同样是一个用 Link 实例表示的 Scheme 列表。

例如，(if (< x 0) (- x) x) 表示为：

Link('if', Link(Link('<', Link('x', Link(0, nil))), Link(Link('-', Link('x', nil)), Link('x', nil))))

要在 x 绑定为 2（且 < 和 - 取默认值）的环境中对该表达式求值，会按以下顺序调用 scheme_eval：

  1. (if (< x 0) (- x) x)
  2. (< x 0)
  3. <
  4. x
  5. 0
  6. x

Q2: 打印被求值的表达式

定义 print_evals，它接受一个只包含数字、+、* 和括号的 Scheme 表达式 expr。它打印在 expr 求值过程中所有被求值的表达式。它们按照传递给 scheme_eval 的顺序被打印出来。

注意： 在 Link 实例上调用 print 会打印它所对应的 Scheme 表达式。

>>> print(Link('+', Link(Link('*', Link(3, Link(4, nil))), Link(5, nil))))
(+ (* 3 4) 5)

宏！

宏是一种使用 define-macro 创建、并通过调用表达式来应用的代码转换。对宏调用的求值过程如下：

  1. 将宏的形式参数绑定到宏调用中未被求值的操作数表达式上。
  2. 对宏的主体求值，它返回一个表达式。
  3. 在原始宏调用的环境中，对宏返回的表达式求值。
scm> (define-macro (twice expr) (list 'begin expr expr))
twice
scm> (twice (+ 2 2))  ; evaluates (begin (+ 2 2) (+ 2 2))
4
scm> (twice (print (+ 2 2)))  ; evaluates (begin (print (+ 2 2)) (print (+ 2 2)))
4
4

Q3: 神秘宏

弄清楚这个 mystery-macro 做了什么。试着通过阅读代码并作为一个小组讨论示例，来描述它的作用。

(define-macro (mystery-macro expr old new)
    (mystery-helper expr old new))

(define (mystery-helper e o n)
  (if (and (list? e) (not (null? e)))
      (cons (mystery-helper (car e) o n) (mystery-helper (cdr e) o n))
      (if (eq? e o) n e)))
下面是一些 mystery-macro 的示例用法，可以帮助你理解它的作用以及可能的用法。 
scm> (define five 5)
five
scm> (mystery-macro (* x x) x five)
25
scm> (mystery-macro (* x x) x (+ five 1))
36
scm> (mystery-macro '(* x x) x y)
(* y y)
scm> (mystery-macro (> (x) (> (y) (+ x y))) > lambda)
(lambda (x) (lambda (y) (+ x y)))
scm> (mystery-macro (begin e e e) e (print five))
5
5
5
