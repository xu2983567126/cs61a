解释器

解释器是一个程序，它允许你用某种语言与计算机进行交互。它能够理解你通过该语言键入的表达式，并以某种方式执行相应的操作，通常借助一种底层语言。

当我们讨论解释器时，涉及两种语言在起作用：

  1. 被解释/被实现的语言。
  2. 底层的实现语言。

许多解释器使用读取-求值-打印循环（REPL）。该循环等待用户输入，然后分三步处理：

  • 读取： 解释器接收用户输入（一个字符串），将输入字符串拆分成小块（词法单元 / tokens），然后将这些词法单元组织成数据结构。
  • 求值： eval 与 apply 之间的相互递归对表达式求值，从而得到一个值。

表示列表

一个 Scheme 调用表达式是一个 Scheme 列表，它使用 Link 的 Python 实例来表示。

例如，调用表达式 (+ (* 3 4) 5) 表示为：

Link('+', Link(Link('*', Link(3, Link(4, nil))), Link(5, nil)))

那些 nil 是可选的，因为 nil 是 Link.empty，它是 __init__ 方法的默认第二个参数，该方法是 Link 类的。

Link('+', Link(Link('*', Link(3, Link(4))), Link(5)))

该 Link 类与 nil 对象都定义在 link.py 中，属于 Scheme 项目。

class Link:
    "A Scheme list is a Link in which rest is a Link or nil."
    empty = ()
    def __init__(self, first, rest=empty):
        self.first = first
        self.rest = rest

    ... # There are also __str__, __repr__, and map methods, omitted here.

nil = Link.empty

问题 1：求值

当对 scheme_eval 在以下环境中调用时，以下哪些会被求值： (if (< x 0) (- x) (if (= x -2) 100 y)) 在该环境中，x 被绑定为 -2。请选择所有适用的选项。 （假设 <、- 以及 = 都取默认值。）

  • if
  • <
  • =
  • x
  • y
  • 0
  • -2
  • 100
  • -
  • (
  • )
被求值的选项有：<、x、0 以及 -。表达式 (if (= x -2) 100 y) 中的内容都不会被求值，因为原始条件求值为 #t，因此它对结果分支中的表达式求值，即 (- x)。此外，if 不会被求值，因为它是特殊形式，而不是调用表达式的运算符。

要对表达式 (+ (* 3 4) 5) 使用项目 4 的解释器进行求值， scheme_eval 会按以下顺序对这些表达式调用：

  1. (+ (* 3 4) 5)
  2. +
  3. (* 3 4)
  4. *
  5. 3
  6. 4
  7. 5

该 * 会被求值，因为它是 (* 3 4) 的运算符子表达式，而 (+ (* 3 4) 5)。

一个 if 同样是一个使用 Link 实例表示的 Scheme 列表。

例如，(if (< x 0) (- x) x) 表示为：

Link('if', Link(Link('<', Link('x', Link(0, nil))), Link(Link('-', Link('x', nil)), Link('x', nil))))

要在以下环境中对该表达式求值：x 被绑定为 2（且 < 和 - 都取默认值），会对 scheme_eval 按以下顺序调用这些表达式：

  1. (if (< x 0) (- x) x)
  2. (< x 0)
  3. <
  4. x
  5. 0
  6. x

符号 if 不会被求值，因为它是特殊形式的开始，而不是 调用表达式的一部分。引入特殊形式的符号（and、 if、lambda 等）永远不会被求值。

符号 - 不会被求值，整个子表达式 (- x) 也不会被求值，因为 (< x 0) 求值为 #f。如果你仍然不确定 为什么某些部分会被求值而某些不会，请询问课程助教。

问题 2：打印被求值的表达式

定义 print_evals，它接收一个 Scheme 表达式 expr，该表达式只包含 数字、+、* 以及括号。它会打印在 expr 的求值过程中所有被求值的表达式。它们按照 被传给 scheme_eval。

注意： 调用 print 作用于一个 Link 实例时，会打印它所表示的 Scheme 表达式。

>>> print(Link('+', Link(Link('*', Link(3, Link(4, nil))), Link(5, nil))))
(+ (* 3 4) 5)
你的答案
解答 
def print_evals(expr):
    """Print the expressions that are evaluated while evaluating expr.
    expr: a Scheme expression containing only (, ), +, *, and numbers.
    >>> nested_expr = Link('+', Link(Link('*', Link(3, Link(4, nil))), Link(5, nil)))
    >>> print_evals(nested_expr)
    (+ (* 3 4) 5)
    +
    (* 3 4)
    *
    3
    4
    5
    >>> print_evals(Link('*', Link(6, Link(7, Link(nested_expr, Link(8, nil))))))
    (* 6 7 (+ (* 3 4) 5) 8)
    *
    6
    7
    (+ (* 3 4) 5)
    +
    (* 3 4)
    *
    3
    4
    5
    8
    """
    if not isinstance(expr, Link):
        print(expr)

    else:
        print(expr)
        while expr is not nil:
            print_evals(expr.first)
            expr = expr.rest

宏！

宏是一种代码变换，使用 define-macro 创建，并通过调用表达式来应用。一个宏调用的求值过程如下：

  1. 将宏的形参绑定到宏调用中未求值的操作数表达式。
  2. 对宏的主体求值，它会返回一个表达式。
  3. 在原始宏调用的环境中，对宏返回的表达式求值。
scm> (define-macro (twice expr) (list 'begin expr expr))
twice
scm> (twice (+ 2 2))  ; evaluates (begin (+ 2 2) (+ 2 2))
4
scm> (twice (print (+ 2 2)))  ; evaluates (begin (print (+ 2 2)) (print (+ 2 2)))
4
4

问题 3：神秘宏

弄清楚这个 mystery-macro 的作用。试着通过阅读代码并一起讨论示例，来描述它的 功能。

(define-macro (mystery-macro expr old new)
    (mystery-helper expr old new))

(define (mystery-helper e o n)
  (if (and (list? e) (not (null? e)))
      (cons (mystery-helper (car e) o n) (mystery-helper (cdr e) o n))
      (if (eq? e o) n e)))
这里有一些 mystery-macro 的示例用法，可以帮助你理解它的作用以及可能的用途。 
scm> (define five 5)
five
scm> (mystery-macro (* x x) x five)
25
scm> (mystery-macro (* x x) x (+ five 1))
36
scm> (mystery-macro '(* x x) x y)
(* y y)
scm> (mystery-macro (> (x) (> (y) (+ x y))) > lambda)
(lambda (x) (lambda (y) (+ x y)))
scm> (mystery-macro (begin e e e) e (print five))
5
5
5
该 mystery-macro 会替换所有出现的 old 符号，将其替换为 new 表达式，然后再对表达式求值。expr。

问题 4：参数重复器

首先，编写过程 repeater，它接收一个表达式 expr 以及一个非负整数 k，并输出一个新列表，其中 expr 重复了 k 次。

然后编写宏 arg-repeater，它接收一个函数 fn、一个表达式 expr 以及一个非负整数 k，该数字对应于 fn 接收的参数个数。arg-repeater 会将 k 的 expr 份副本传给对 fn。

注意： 的调用。骨架代码只是建议；如果你愿意，可以使用自己的结构。

你的答案
解答 
(define (repeater expr k)
  ; 返回一个包含 expr 的 k 个副本的列表
  (if (= 0 k)
      nil
      (cons expr (repeater expr (- k 1)))))

(expect (repeater 2 0) ())
(expect (repeater 2 5) (2 2 2 2 2))

(define-macro (arg-repeater fn expr k)
  ; 用 expr 的 k 个副本填充 fn
  (cons fn (repeater expr k)))

(define (add-four a b c d) (+ a b c d))
(define (mult-one x) x)
(define (mult-seven a1 a2 a3 a4 a5 a6 a7)
  (* a1 a2 a3 a4 a5 a6 a7))

(expect (arg-repeater add-four 10 4) 40)
(expect (arg-repeater mult-one -2 1) -2)
; 2 自乘 7 次 = 2^7 = 128
(expect (arg-repeater mult-seven 2 7) 128)

问题 5：反转

编写一个尾递归函数 reverse，它接收一个 Scheme 列表并返回其反转后的副本。 

scm> (reverse '(1 2 3))
(3 2 1)
scm> (reverse '(0 9 1 2))
(2 1 9 0)
你的答案
解答 
(define (reverse lst)
  (define (reverse-tail sofar rest)
    (if (null? rest)
          sofar
          (reverse-tail (cons (car rest) sofar) (cdr rest))))
  (reverse-tail nil lst)
)

(expect (reverse '(1 2 3)) (3 2 1))
(expect (reverse '(0 9 1 2)) (2 1 9 0))

问题 6：切片！

实现 get-slicer 过程，它接收整数 a 和 b 并返回一个 a-b 切片函数。一个 a-b 切片函数接收一个列表作为输入，并输出一个新列表，包含原列表中从索引 a（包含）到索引 b（不包含）的值。

你的实现应当表现得像 Python 的切片，但要假设步长为 1，且不使用负的切片索引。索引从 0 开始。

注意： 骨架代码只是建议。如果你愿意，可以使用自己的结构。

你的答案
解答 
(define (get-slicer a b)
  (define (slicer lst)
    (define (slicer-helper c i j)
      (cond 
        ((or (null? c) (<= j i)) nil)
        ((= i 0) (cons (car c) (slicer-helper (cdr c) i (- j 1))))
        (else (slicer-helper (cdr c) (- i 1) (- j 1)))))
    (slicer-helper lst a b))
  slicer)

; DOCTESTS（无需修改）
(define a '(0 1 2 3 4 5 6))
(define one-two-three (get-slicer 1 4))
(define one-end (get-slicer 1 10))
(define zero (get-slicer 0 1))
(define empty (get-slicer 4 4))

(expect (one-two-three a) (1 2 3))
(expect (one-end a) (1 2 3 4 5 6))
(expect (zero a) (0))
(expect (empty a) ())
