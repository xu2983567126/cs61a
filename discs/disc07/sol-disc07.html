可变树

一个 Tree 实例有两个实例属性：

  • label 是存储在树根节点处的值。
  • branches 是一个由 Tree 实例组成，它们保存着树其余部分的标签。

这个 Tree 类（其中它的 __repr__ 和 __str__ 方法被省略）定义如下：

class Tree:
    """A tree has a label and a list of branches.

    >>> t = Tree(3, [Tree(2, [Tree(5)]), Tree(4)])
    >>> t.label
    3
    >>> t.branches[0].label
    2
    >>> t.branches[1].is_leaf()
    True
    """
    def __init__(self, label, branches=[]):
        self.label = label
        for branch in branches:
            assert isinstance(branch, Tree)
        self.branches = list(branches)

    def is_leaf(self):
        return not self.branches

要构造一个 Tree 实例，给定标签 x（任意值）以及分支列表 bs（一个由 Tree 实例组成的列表），并将其命名为 t，可以写作 t = Tree(x, bs).

对于一个树 t:

  • 它的根标签可以是任意值，而 t.label 会求出它的值。
  • 它的分支始终是 Tree 实例，而 t.branches 会求出列表，该列表由其分支组成。
  • t.is_leaf() 返回 True，若 t.branches 为空，而 False 否则。
  • 要构造一个标签为 x，可以写作 Tree(x).

显示一个树 t:

  • repr(t) 会返回一个等价于该树的 Python 表达式。
  • str(t) 会为每一个标签返回一行，该行比其父节点多缩进一次，子节点位于父节点之下。
>>> t = Tree(3, [Tree(1, [Tree(4), Tree(1)]), Tree(5, [Tree(9)])])

>>> t         # displays the contents of repr(t)
Tree(3, [Tree(1, [Tree(4), Tree(1)]), Tree(5, [Tree(9)])])

>>> print(t)  # displays the contents of str(t)
3
  1
    4
    1
  5
    9

改变（也称为修改）一个树 t:

  • t.label = y 会改变 t 的根标签为 y（任意值）。
  • t.branches = ns 会改变 t 的根标签为 ns（一个由 Tree 实例）。
  • 对 t.branches 的修改会改变 t.例如， t.branches.append(Tree(y)) 会添加一个标签为 y 的叶子作为最右侧的 分支。
  • 对 t 的修改会改变 t.例如， t.branches[0].label = y 中任意分支的修改会改变最左侧分支的根标签 为 y.
>>> t.label = 3.0
>>> t.branches[1].label = 5.0
>>> t.branches.append(Tree(2, [Tree(6)]))
>>> print(t)
3.0
  1
    4
    1
  5.0
    9
  2
    6

下面总结了将树数据抽象实现为函数式抽象与实现为类之间的区别：

- 树的构造器与选择器函数 树类
构造一棵树 给定 label 以及一个由 branches 列表，我们调用 tree(label, branches) 给定 label 以及一个由 branches 列表，我们调用 Tree(label, branches) 来构造一个树对象（它会调用 Tree.__init__ 方法）。
标签与分支 要获取一个树的t 列表，我们调用 label(t) 或 branches(t) 分别。 要获取一个树的t，我们访问实例属性 t.label 或 t.branches 分别。
可变性 函数式树数据抽象是不可变的（在不违背其抽象屏障的前提下），因为我们无法对调用表达式赋值 这个 label 和 branches 的属性Tree 实例可以被重新赋值，从而修改这棵树。
判断一棵树是否为叶子 要检查一个树 t 是否为叶子，我们调用函数 is_leaf(t) 要检查一个树 t 是否为叶子，我们调用方法 t.is_leaf()。这个方法只能在 Tree 对象上调用。

Working with the Tree class

问题 2：最宽层级

编写一个接受 Tree 对象并返回元素最多的深度处的元素。如果有两个深度元素数量相同（平局），则选择较低的深度。

在这个问题中，你可能会发现使用 sum 会很有帮助，它提供了一个起始值。待求和序列中的所有项都会被连接到起始值上。默认情况下，start 为 0，这使你可以对一串数字求和。我们提供了一个以列表作为起始值的 sum 示例，让你能够连接列表中的各项。

你的答案
解答 
def widest_level(t):
    """
    >>> sum([[1], [2]], [])
    [1, 2]
    >>> t = Tree(3, [Tree(1, [Tree(1), Tree(5)]),
    ...              Tree(4, [Tree(9, [Tree(2)])])])
    >>> widest_level(t)
    [1, 5, 9]
    """
    labels = []
    curr_level = [t]
    while curr_level:
        labels.append([t.label for t in curr_level])
        curr_level = sum([t.branches for t in curr_level], [])
    return max(labels, key=len)

问题 3：长路径

实现 long_paths，它返回一个包含所有 路径 的列表，这些路径位于一棵树中且长度至少为 n。树中的一条路径是一个节点标签列表，从根开始，到叶子结束。每个后续元素必须来自前一个节点某个分支的标签。该路径的长度 是指路径中边的数量（即节点数减一）。输出列表中的路径按树中从左到右的顺序排列。可参考文档测试中的一些示例。

你的答案
解答 
def long_paths(t, n):
    """Return a list of all paths in t with length at least n.

    >>> long_paths(Tree(1), 0)
    [[1]]
    >>> long_paths(Tree(1), 1)
    []
    >>> t = Tree(1, [Tree(2, [Tree(3), Tree(4)]), Tree(5), Tree(6, [Tree(7, [Tree(8)])])])
    >>> print(t)
    1
      2
        3
        4
      5
      6
        7
          8
    >>> for path in long_paths(t, 2):
    ...     print(path)
    ...
    [1, 2, 3]
    [1, 2, 4]
    [1, 6, 7, 8]
    >>> long_paths(t, 3)
    [[1, 6, 7, 8]]
    """
    if n <= 0 and t.is_leaf():
      return [[t.label]]
    paths = []
    for b in t.branches:
      for path in long_paths(b, n - 1):
          paths.append([t.label] + path)
    return paths

修改树

问题 4：层级修改

提醒一下，一个节点的深度是指该节点距离根节点有多远。我们将其定义为根节点到该节点之间的边数。由于根节点与其自身之间没有边，根节点的深度为 0。

给定一个树 t 以及一个单参数函数列表 funcs，编写一个函数，用于修改 t 的标签，在对应深度处使用来自 funcs 的函数。例如，根节点（深度为 0）处的标签将使用索引 0 处的函数进行修改，即 funcs[0]。假设 funcs 中的所有函数都能接受一个标签值并返回一个有效的标签值。

如果 t 是一个叶子，并且 funcs 中有超过 1 个函数，则其余所有函数应按顺序应用于 t 的标签上。（可参考文档测试中的示例。）如果 funcs 为空，则树应保持不变。

你的答案
解答 
def level_mutation(t, funcs):
    """Mutates t using the functions in the list funcs.

    >>> t = Tree(1, [Tree(2, [Tree(3)])])
    >>> funcs = [lambda x: x + 1, lambda y: y * 5, lambda z: z ** 2]
    >>> level_mutation(t, funcs)
    >>> t                               # funcs[0] was applied to the label 1, funcs[1] to the label 2, etc.
    Tree(2, [Tree(10, [Tree(9)])])
    >>> t2 = Tree(1, [Tree(2), Tree(3, [Tree(4)])])
    >>> level_mutation(t2, funcs)
    >>> t2                              # (2 * 5) ** 2 = 100
    Tree(2, [Tree(100), Tree(15, [Tree(16)])])
    >>> t3 = Tree(1, [Tree(2)])
    >>> level_mutation(t3, funcs)
    >>> t3
    Tree(2, [Tree(100)])
    """
    if not funcs:
        return
    t.label = funcs[0](t.label)
    remaining = funcs[1:]
    if t.is_leaf() and remaining:
        for f in remaining:
            t.label = f(t.label)
    for b in t.branches:
        level_mutation(b, remaining)

问题 5：删除

实现 delete，它接受一个 Tree t 并删除所有标签为 x 的非根节点。 每个剩余节点的父节点是它最近的、未被删除的祖先节点。 换句话说，当一个非叶子节点被删除时，该被删除节点的子节点会成为其父节点的子节点。 即使根节点的标签为 x.

你的答案
解答 
def delete(t, x):
    """Remove all nodes labeled x below the root within Tree t. When a non-leaf
    node is deleted, the deleted node's children become children of its parent.

    The root node will never be removed.

    >>> t = Tree(3, [Tree(2, [Tree(2), Tree(2)]), Tree(2), Tree(2, [Tree(2, [Tree(2), Tree(2)])])])
    >>> delete(t, 2)
    >>> t
    Tree(3)
    >>> t = Tree(1, [Tree(2, [Tree(4, [Tree(2)]), Tree(5)]), Tree(3, [Tree(6), Tree(2)]), Tree(4)])
    >>> delete(t, 2)
    >>> t
    Tree(1, [Tree(4), Tree(5), Tree(3, [Tree(6)]), Tree(4)])
    >>> t = Tree(1, [Tree(2, [Tree(4), Tree(5)]), Tree(3, [Tree(6), Tree(2)]), Tree(2, [Tree(6),  Tree(2), Tree(7), Tree(8)]), Tree(4)])
    >>> delete(t, 2)
    >>> t
    Tree(1, [Tree(4), Tree(5), Tree(3, [Tree(6)]), Tree(6), Tree(7), Tree(8), Tree(4)])
    """
    new_branches = []
    for b in t.branches:
        delete(b, x)
        if b.label == x:
            new_branches.extend(b.branches)
        else:
            new_branches.append(b)
    t.branches = new_branches
