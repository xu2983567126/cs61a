可变树

一个 Tree 实例有两个实例属性：

  • label 是存储在树根节点的值。
  • branches 是一个由 Tree 实例组成的列表，保存了树其余部分的标签。

Tree 类（省略其 __repr__ 和 __str__ 方法）的定义如下：

class Tree:
    """A tree has a label and a list of branches.

    >>> t = Tree(3, [Tree(2, [Tree(5)]), Tree(4)])
    >>> t.label
    3
    >>> t.branches[0].label
    2
    >>> t.branches[1].is_leaf()
    True
    """
    def __init__(self, label, branches=[]):
        self.label = label
        for branch in branches:
            assert isinstance(branch, Tree)
        self.branches = list(branches)

    def is_leaf(self):
        return not self.branches

要从一个标签 x（任意值）和一个分支列表 bs（由 Tree 实例组成的列表）构造一个 Tree 实例，并将其命名为 t，可以写 t = Tree(x, bs)。

对于一棵树 t：

  • 它的根标签可以是任意值，t.label 求值为该值。
  • 它的分支始终为 Tree 实例，t.branches 求值为其分支组成的列表。
  • 如果 t.branches 为空，t.is_leaf() 返回 True，否则返回 False。
  • 要构造一个标签为 x 的叶子节点，可以写 Tree(x)。

显示一棵树 t：

  • repr(t) 返回一个求值后能得到等价树的 Python 表达式。
  • str(t) 为每标签返回一行，每个标签比其父节点多缩进一次，子节点位于父节点下方。
>>> t = Tree(3, [Tree(1, [Tree(4), Tree(1)]), Tree(5, [Tree(9)])])

>>> t         # displays the contents of repr(t)
Tree(3, [Tree(1, [Tree(4), Tree(1)]), Tree(5, [Tree(9)])])

>>> print(t)  # displays the contents of str(t)
3
  1
    4
    1
  5
    9

修改（也就是改变，mutating）一棵树 t：

  • t.label = y 将 t 的根标签改为 y（任意值）。
  • t.branches = ns 将 t 的分支改为 ns（由 Tree 实例组成的列表）。
  • 对 t.branches 的修改会改变 t。例如，t.branches.append(Tree(y)) 会添加一个标签为 y 的叶子节点作为最右侧的分支。
  • 对 t 中任意分支的修改都会改变 t。例如，t.branches[0].label = y 会把最左侧分支的根标签改为 y。
>>> t.label = 3.0
>>> t.branches[1].label = 5.0
>>> t.branches.append(Tree(2, [Tree(6)]))
>>> print(t)
3.0
  1
    4
    1
  5.0
    9
  2
    6

下面总结了以函数式抽象实现的树数据抽象，与以类实现的树数据抽象之间的区别：

- 树的构造器与选择器函数 Tree 类
构造一棵树 给定一个 label 和一个 branches 列表，我们调用 tree(label, branches) 来构造一棵树 给定一个 label 和一个 branches 列表，我们调用 Tree(label, branches)（它会调用 Tree.__init__ 方法）来构造一个树对象。
标签与分支 要获取树 t 的标签或分支，我们分别调用 label(t) 或 branches(t) 要获取树 t 的标签或分支，我们分别访问其实例属性 t.label 或 t.branches。
可变性 函数式树数据抽象是不可变的（且不能违背其抽象屏障），因为我们无法对调用表达式赋值 Tree 实例的 label 和 branches 属性可以被重新赋值，从而修改这棵树。
判断树是否为叶子节点 要判断树 t 是否为叶子节点，我们调用函数 is_leaf(t) 要判断树 t 是否为叶子节点，我们调用方法 t.is_leaf()。该方法只能在 Tree 对象上调用。

Q2：最宽层级

编写一个函数，接收一个 Tree 对象，返回元素最多的那个深度上的所有元素。如果两个深度的元素数量相同（并列），则选择较浅（更小）的那个深度。

在这道题中，你可能会发现使用 sum 的第二个可选参数（起始值）很有帮助。待求和序列中的所有元素都会被拼接到起始值上。默认情况下，start 默认为 0，这样你就能对一串数字求和。我们给出了一个以列表作为起始值的 sum 示例，它允许你拼接列表中的元素。

Q3：长路径

实现 long_paths，它返回一个列表，包含树中所有长度至少为 n 的路径。树中的一条路径是一个节点标签的列表，从根节点开始，到某个叶子节点结束。其中每个后续元素必须来自前一个节点某个分支的标签。路径的长度是指路径中边的数量（即节点数减一）。输出列表中的路径按树中从左到右的顺序排列。可以查看 doctest 中的示例。

修改树

Q4：层级变异

提醒一下，一个节点的深度是指该节点距离根节点有多远。我们将其定义为从根节点到该节点的边数。由于根节点到自身之间没有边，所以根节点的深度为 0。

给定一个树 t 和一个单参数函数列表 funcs，请编写一个函数，使用与节点深度相对应的 funcs 中的函数来修改 t 的标签。例如，根节点（深度为 0）的标签将使用索引为 0 的函数（即 funcs[0]）来修改。假设 funcs 中的所有函数都能接收一个标签值并返回合法的标签值。

如果 t 是一个叶子节点，而 funcs 中还有超过 1 个函数，则应将所有剩余的函数依次应用到 t 的标签上。（可参考 doctest 中的示例。）如果 funcs 为空，则树应保持不变。

Q5：删除

实现 delete，它接收一个树 t，并移除所有标签为 x 的非根节点。每个剩余节点的父节点是它未被移除的最近祖先。换句话说，当一个非叶子节点被删除时，该被删节点的子节点会成为其原来父节点的子节点。根节点永远不会被移除，即使它的标签是 x。
