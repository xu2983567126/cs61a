作业中用到的大多数表已经可以直接使用，所以让我们尝试执行一条 SELECT 语句：

除了显示输出表的直观表示外，「逐步」按钮还能让我们逐步执行 SQL，并可视化其中发生的每一步变换。以我们的例子为例，点击下一个箭头会生成以下可视化效果，准确展示了 SQL 如何对行进行分组以形成最终输出！

SQL 基础

示例表

这里有一个名为 big_game 的表，在下面的示例中使用，它记录了 每年「大赛」的比分。该表有三列：berkeley、 stanford 以及 year。

CREATE TABLE big_game (
    berkeley INTEGER, stanford INTEGER, year INTEGER);

INSERT INTO big_game (berkeley, stanford, year) VALUES
    (30, 7, 2002),
    (28, 16, 2003),
    (17, 38, 2014);

你可以在 sqlite 中像这样查看它：

sqlite> .mode column
sqlite> SELECT * FROM big_game;
berkeley  stanford  year
--------  --------  ----
30        7         2002
28        16        2003
17        38        2014
如果 .mode column 命令在你的 sqlite 版本中不起作用，也没关系。直接忽略它即可。

从表中查询

通常，我们会使用 SELECT 语句：

SELECT [columns] FROM [tables] WHERE [condition] ORDER BY [columns] LIMIT [limit];

从现有表中创建新表。让我们拆解这个语句：

  • SELECT [columns] 告诉 SQL 我们想在 输出表中包含指定的列；[columns] 是一个以逗号分隔的列名列表，而 * 可以用来选择所有列
  • FROM [table] 告诉 SQL 我们想要选择的列来自 给定的表
  • WHERE [condition] 通过对行进行筛选来过滤输出表，只保留那些 值满足给定 [condition]（一个布尔表达式）的行
  • ORDER BY [columns] 按照给定的 逗号分隔的列列表对输出表中的行排序；默认情况下，值按升序（ASC）排列，但你也可以使用 DESC 按降序排列
  • LIMIT [limit] 按照整数 限制输出表中的行数[limit]

以下是一些示例：

从 big_game 表中选出所有 Berkeley 的比分，但只包括 2002 年之后的比分：

sqlite> SELECT berkeley FROM big_game WHERE year > 2002;
28
17

选出 Berkeley 获胜年份中两所学校的比分：

sqlite> SELECT berkeley, stanford FROM big_game WHERE berkeley > stanford;
30|7
28|16

选出 Stanford 得分超过 15 分的年份：

sqlite> SELECT year FROM big_game WHERE stanford > 15;
2003
2014

SQL 运算符

在 SELECT、WHERE 以及 ORDER BY 子句中的表达式可以包含 以下一个或多个运算符：

  • 比较运算符：=、>、<、<=、>=、<> 或 !=（“不等于”）
  • 布尔运算符：AND、OR
  • 算术运算符：+、-、*、/
  • 连接运算符：||

输出每年 Berkeley 与 Stanford 比分的比率：

sqlite> select berkeley * 1.0 / stanford from big_game;
0.447368421052632
1.75
4.28571428571429

输出两支队得分都超过 10 分的年份的比分总和：

sqlite> select berkeley + stanford from big_game where berkeley > 10 and stanford > 10;
55
44

产出一个只有一列一行、包含值 “hello world” 的表：

sqlite> SELECT "hello" || " " || "world";
hello world

披萨时间

该 pizzas 表包含 Berkeley 优秀披萨店的名字、 营业时间和打烊时间。meals 表包含（大学生）典型的 就餐时间。如果就餐时间正好落在或处于某披萨店营业时间范围内，则该披萨店在该餐次营业。open 和 close 次。

CREATE TABLE pizzas (name TEXT, open INTEGER, close INTEGER);

INSERT INTO pizzas VALUES
  ("Artichoke", 12, 15),
  ("La Val's", 11, 22),
  ("Sliver", 11, 20),
  ("Cheeseboard", 16, 23),
  ("Emilia's", 13, 18);

CREATE TABLE meals (meal TEXT, time INTEGER);

INSERT INTO meals VALUES
  ("breakfast", 11),
  ("lunch", 13),
  ("dinner", 19),
  ("snack", 22);

问题 1：早开门

你想在 13 点（下午 1 点）之前吃披萨。创建一个 opening 表，包含 所有 open 在 13 点之前开门的披萨店的名字，按字母 逆序排列。要测试你的查询输出什么表，请点击 61A Code 中的绿色播放按钮！

opening 表：

name
Sliver
La Val's
Artichoke
你的答案
解答 
-- Pizza places that open before 1pm in alphabetical order
CREATE TABLE opening AS
  SELECT name FROM pizzas WHERE open < 13 ORDER BY name DESC;

问题 2：学习时段

你计划从某披萨店开门一直学习到 14 点 （下午 2 点）。创建一个表 study，包含两列：name 每间披萨店的 以及 duration 你在那里学习时 （开门时间与 14 点之间的差值）的学习时长。对于在下午 2 点前 不开门的披萨店，duration 应为零。按 时长递减的顺序排列各行。

提示： 使用形如 MAX(_, 0) 的表达式，以确保结果不小于 0。

study 表：

name duration
La Val's 3
Sliver 3
Artichoke 2
Emilia's 1
Cheeseboard 0
你的答案
解答 
-- Pizza places and the duration of a study break that ends at 14 o'clock
CREATE TABLE study AS
  SELECT name, MAX(14 - open, 0) AS duration FROM pizzas ORDER BY duration DESC;

问题 3：深夜零食

深夜 snack 还有什么店开着？创建一个 late 表，包含一列，命名为 status，其中有一句话描述每个 在 snack 或更晚打烊的披萨店的打烊时间。重要： 不要在你的 SQL 查询中使用任何 数字！相反，使用连接（join）来将每家餐厅的 打烊时间与零食时间进行比较。各行出现的顺序可以任意。

late 表：

status
Cheeseboard 在 23 点打烊
La Val’s 在 22 点打烊

该 || SQL 中的运算符会将两个字符串拼接在一起，就像 +。

你的答案
解答 
-- Pizza places that are open for late-night-snack time and when they close
CREATE TABLE late AS
  SELECT name || " closes at " || close AS status
  FROM pizzas JOIN meals
  ON time <= close
  WHERE meal="snack";
要比较披萨店的 close 时间与零食时间：
  • 将 pizzas 和 meals 表使用 FROM pizzas, meals
  • 进行连接，只保留那些 meal 是一个 "snack"
  • 的行，比较 time 零食的与 close 披萨店的。
使用 name || " closes at " || close 来在结果表中创建句子。|| 运算符将值拼接成字符串。

问题 4：双份披萨

如果两餐之间相隔超过 6 小时，那么两餐都去同一家披萨店也没什么不妥，对吧？创建一个 double 表，包含三列。first 列是较早的一餐，second 列是 较晚的一餐，而 name 列是披萨店的名字。只包括 描述两餐 相隔超过 6 小时 且某披萨店在两餐时段都营业的行。各行顺序可以任意。

double 表：

first second name
breakfast dinner La Val's
breakfast dinner Sliver
breakfast snack La Val's
lunch snack La Val's
你的答案
解答 
-- Two meals at the same place
CREATE TABLE double AS
  SELECT a.meal AS first, b.meal AS second, name
         FROM meals AS a
         JOIN meals AS b ON b.time > a.time + 6
         JOIN pizzas ON open <= a.time AND a.time <= close AND open <= b.time AND b.time <= close;

SQL 聚合

这里有另一个示例表，这次是关于航班的：

CREATE TABLE flights (
    departure TEXT, arrival TEXT, price INTEGER);

INSERT INTO flights (departure, arrival, price) VALUES
    ('SFO', 'LAX', 97),
    ('SFO', 'AUH', 848),
    ('LAX', 'SLC', 115),
    ('SFO', 'PDX', 192),
    ('AUH', 'SEA', 932),
    ('SLC', 'PDX', 79),
    ('SFO', 'LAS', 40),
    ('SLC', 'LAX', 117),
    ('SEA', 'PDX', 32),
    ('SLC', 'SEA', 42),
    ('SFO', 'SLC', 97),
    ('LAS', 'SLC', 50),
    ('LAX', 'PDX', 89);

应用一个 聚合函数 例如 MAX(column) 会将多行中的值合并为一行输出。

默认情况下，我们会合并表中所有行的值。例如，如果我们 想统计 flights 表中的行数，可以使用：

sqlite> SELECT COUNT(*) from FLIGHTS;
13

如果我们想将相似行中的值分组，并在这些组内执行 聚合操作，该怎么办？我们使用 GROUP BY 子句。

再看一个例子。对于每个不同的出发地，将所有 具有相同出发机场的行收集到一个组中。然后，选择 price 列并 应用 MIN 聚合，以恢复该组中价格最低的出发航班的价格。最终得到的表包含出发机场以及最便宜的 出发航班。

sqlite> SELECT departure, MIN(price) FROM flights GROUP BY departure;
departure  MIN(price)
---------  ----------
AUH        932
LAS        50
LAX        89
SEA        32
SFO        40
SLC        42

就像我们可以用 WHERE，我们也可以用 HAVING 过滤掉 组。通常，HAVING 子句应当使用聚合 函数。假设我们想查看所有至少有两次出发的机场：

sqlite> SELECT departure FROM flights GROUP BY departure HAVING COUNT(*) >= 2;
departure
---------
LAX
SFO
SLC

注意，COUNT(*) 聚合只是统计每个组中的行数。 假设我们想统计 不同的 机场的数量。那么，我们可以 使用以下查询：

sqlite> SELECT COUNT(DISTINCT departure) AS destinations FROM flights;
destinations
------------
6

这会列举出 flights 表中所有不同的出发机场 （本例中为：SFO、LAX、AUH、SLC、SEA 和 LAS）。

教室

选自 2023 年春季期末考试。

该 finals 表包含列 hall（字符串）以及 course（字符串），其 行对应某门课程举行期末考试的礼堂。

该 sizes 表包含列 room（字符串）以及 seats（数字），其包含 校园中每个唯一房间的一行，记录该房间的座位数。所有 礼堂都是房间。

问题 5：总座位数

创建一个包含两列的表，course（字符串）以及 total（数字），其 每行对应 每门使用至少两个房间的课程 的期末考试。每 行包含课程名称以及该课程期末考试教室的 总座位数。

你的查询应当能正确处理 finals 以及 sizes 表中可能出现的任何数据，但对于上面的示例数据，结果应为：

61A|2400
61B|1700
61C|1200
你的答案
解答 
CREATE TABLE finals AS
  SELECT "RSF" AS hall, "61A" as course UNION
  SELECT "Wheeler"    , "61A"           UNION
  SELECT "Pimentel"   , "61A"           UNION
  SELECT "Li Ka Shing", "61A"           UNION
  SELECT "RSF"        , "61B"           UNION
  SELECT "Wheeler"    , "61B"           UNION
  SELECT "Morgan"     , "61B"           UNION
  SELECT "Wheeler"    , "61C"           UNION
  SELECT "Pimentel"   , "61C"           UNION
  SELECT "Soda 306"   , "10"            UNION
  SELECT "RSF"        , "70";

CREATE TABLE sizes AS
  SELECT "RSF" AS room, 900 as seats    UNION
  SELECT "Wheeler"    , 700             UNION
  SELECT "Pimentel"   , 500             UNION
  SELECT "Li Ka Shing", 300             UNION
  SELECT "Morgan"     , 100             UNION
  SELECT "Soda 306"   , 80              UNION
  SELECT "Soda 310"   , 40              UNION
  SELECT "Soda 320"   , 30;

SELECT course, SUM(seats) AS total
  FROM finals JOIN sizes ON hall=room
  GROUP BY course HAVING COUNT(*) > 1;

将 finals 和 sizes 表进行连接，但要确保每一行连接后的结果 是连贯的，方法是限制为那些 hall（来自 finals）与 room （来自 sizes）具有相同值的行。

由于输出中每门课程只有一行，但同一门课程会出现在 finals 表的多个 行中，因此按 course。

COUNT(*) 分组。

表达式 SUM(seats) 求值为组中 seats 值（来自 sizes 表）的总和。如果你按课程分组，那么这就是 该课程所有用于考试的礼堂座位数之和。

问题 6：教室共享

编写一条 select 语句，创建一个包含两列的表，course （字符串）以及 shared（数字），其 每行对应 每门至少使用 一个也被其他课程使用的房间的课程。每行包含 课程名称，以及该课程中同时也被 其他课程使用的房间总数。

COUNT(DISTINCT x) 求值为出现在列 x 中不同值的数量 （针对一个组）。例如，SELECT COUNT(DISTINCT seats) from sizes; 会输出 8，因为 sizes 中有 9 行，但其中有两行座位数为 300， 所以只有 8 个不同的值。

你的查询应当能正确处理 finals 以及 sizes 表，但对于下面的示例，结果应为：

61A|3
61B|2
61C|2
70|1

讨论时间： 讨论为什么输出表包含它所包含的内容。61B 共用的两个礼堂是哪两个？

你的答案
解答 
CREATE TABLE finals AS
  SELECT "RSF" AS hall, "61A" as course UNION
  SELECT "Wheeler"    , "61A"           UNION
  SELECT "Pimentel"   , "61A"           UNION
  SELECT "Li Ka Shing", "61A"           UNION
  SELECT "RSF"        , "61B"           UNION
  SELECT "Wheeler"    , "61B"           UNION
  SELECT "Morgan"     , "61B"           UNION
  SELECT "Wheeler"    , "61C"           UNION
  SELECT "Pimentel"   , "61C"           UNION
  SELECT "Soda 306"   , "10"            UNION
  SELECT "RSF"        , "70";

CREATE TABLE sizes AS
  SELECT "RSF" AS room, 900 as seats    UNION
  SELECT "Wheeler"    , 700             UNION
  SELECT "Pimentel"   , 500             UNION
  SELECT "Li Ka Shing", 300             UNION
  SELECT "Morgan"     , 100             UNION
  SELECT "Soda 306"   , 80              UNION
  SELECT "Soda 310"   , 40              UNION
  SELECT "Soda 320"   , 30;

SELECT a.course, COUNT(DISTINCT a.hall) AS shared
  FROM finals AS a JOIN finals AS b
  ON a.hall = b.hall AND a.course != b.course
  GROUP BY a.course;

将 finals 与 finals 进行连接，但要确保连接后的行对应 使用同一礼堂的不同课程。

按第一个 course 列分组，使得每门课程形成一个组（即一行输出）。HAVING 子句并非必需，如果 WHERE 子句已经 将输入行限制为使用同一礼堂的两个不同课程。

统计 hall 的不同值数量（针对一门课程）：COUNT(DISTINCT ___)。 DISTINCT 限制是必要的，这样被超过两门课程使用的礼堂不会被重复计数。
