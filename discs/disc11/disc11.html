作业中用到的大多数表已经可以直接使用，所以让我们试着执行一条 SELECT 语句：

除了显示输出表的可视化表示外，“逐步执行”按钮还能让我们逐步查看 SQL 的执行过程，并可视化其中发生的每一次转换。以我们的示例为例，点击下一个箭头会显示如下可视化效果，确切地展示了 SQL 如何将我们的行分组以形成最终输出！

SQL 基础

示例表

下面是一个名为 big_game 的表，在以下示例中用到，它记录了每年“大赛”（Big Game）的比分。这个表有三列：berkeley、stanford 和 year。

CREATE TABLE big_game (
    berkeley INTEGER, stanford INTEGER, year INTEGER);

INSERT INTO big_game (berkeley, stanford, year) VALUES
    (30, 7, 2002),
    (28, 16, 2003),
    (17, 38, 2014);

你可以像这样在 sqlite 中查看它：

sqlite> .mode column
sqlite> SELECT * FROM big_game;
berkeley  stanford  year
--------  --------  ----
30        7         2002
28        16        2003
17        38        2014
If the .mode column command doesn't work in your version of sqlite, that's ok. Just ignore it.

从表中选择

通常，我们会使用 SELECT 语句从已有的表中创建新表：

SELECT [columns] FROM [tables] WHERE [condition] ORDER BY [columns] LIMIT [limit];

让我们分解一下这条语句：

  • SELECT [columns] 告诉 SQL 我们想在输出表中包含给定的列；[columns] 是列名的逗号分隔列表，* 可用于选择所有列
  • FROM [table] 告诉 SQL 我们想选择的列来自给定的表
  • WHERE [condition] 通过只保留那些值满足给定 [condition]（布尔表达式）的行来筛选输出表
  • ORDER BY [columns] 按给定的逗号分隔列列表对输出表中的行排序；默认按升序（ASC）排序，但你也可以用 DESC 按降序排序
  • LIMIT [limit] 用整数 [limit] 限制输出表中的行数

下面是一些示例：

从 big_game 表中选择 Berkeley 的所有分数，但只包含 2002 年之后的年份：

sqlite> SELECT berkeley FROM big_game WHERE year > 2002;
28
17

选择在 Berkeley 获胜的年份里两所学校的分数：

sqlite> SELECT berkeley, stanford FROM big_game WHERE berkeley > stanford;
30|7
28|16

选择 Stanford 得分超过 15 分的年份：

sqlite> SELECT year FROM big_game WHERE stanford > 15;
2003
2014

SQL 运算符

SELECT、WHERE 和 ORDER BY 子句中的表达式可以包含一个或多个以下运算符：

  • 比较运算符：=、>、<、<=、>=、<> 或 !=（“不等于”）
  • 布尔运算符：AND、OR
  • 算术运算符：+、-、*、/
  • 连接运算符：||

输出每年 Berkeley 得分与 Stanford 得分的比值：

sqlite> select berkeley * 1.0 / stanford from big_game;
0.447368421052632
1.75
4.28571428571429

输出两支队伍都得分超过 10 分的年份的得分之和：

sqlite> select berkeley + stanford from big_game where berkeley > 10 and stanford > 10;
55
44

输出一个只有单列单行、包含值 “hello world” 的表：

sqlite> SELECT "hello" || " " || "world";
hello world

披萨时间

pizzas 表包含 Berkeley 一些优质披萨店的名称、开门和关门时间。meals 表包含典型的用餐时间（针对大学生）。如果用餐时间落在某披萨店的开门和关门时间之内（含边界），则该店在该餐时段营业。

CREATE TABLE pizzas (name TEXT, open INTEGER, close INTEGER);

INSERT INTO pizzas VALUES
  ("Artichoke", 12, 15),
  ("La Val's", 11, 22),
  ("Sliver", 11, 20),
  ("Cheeseboard", 16, 23),
  ("Emilia's", 13, 18);

CREATE TABLE meals (meal TEXT, time INTEGER);

INSERT INTO meals VALUES
  ("breakfast", 11),
  ("lunch", 13),
  ("dinner", 19),
  ("snack", 22);

Q3: 深夜零食

有什么店在深夜零食时间还开着？创建一个 late 表，包含一个名为 status 的列，其中有一句话描述每家在零食时间或之后关门的披萨店的关门时间。重要： 不要在你的 SQL 查询中使用任何数字！相反，使用连接（join）将每家餐厅的关门时间与零食时间进行比较。各行可以按任意顺序排列。

late 表：

status
Cheeseboard closes at 23
La Val's closes at 22

SQL 中的 || 运算符将两个字符串拼接在一起，就像 Python 中的 + 一样。

要将披萨店的 close 时间与零食时间进行比较：
  • 使用 FROM pizzas, meals 将 pizzas 和 meals 表连接起来
  • 只保留 meal 为 "snack" 的行
  • 将零食的 time 与披萨店的 close 进行比较。
使用 name || " closes at " || close 来生成结果表中的句子。|| 运算符将值拼接成字符串。

SQL 聚合

下面是另一个示例表，这次是关于航班的：

CREATE TABLE flights (
    departure TEXT, arrival TEXT, price INTEGER);

INSERT INTO flights (departure, arrival, price) VALUES
    ('SFO', 'LAX', 97),
    ('SFO', 'AUH', 848),
    ('LAX', 'SLC', 115),
    ('SFO', 'PDX', 192),
    ('AUH', 'SEA', 932),
    ('SLC', 'PDX', 79),
    ('SFO', 'LAS', 40),
    ('SLC', 'LAX', 117),
    ('SEA', 'PDX', 32),
    ('SLC', 'SEA', 42),
    ('SFO', 'SLC', 97),
    ('LAS', 'SLC', 50),
    ('LAX', 'PDX', 89);

应用像 MAX(column) 这样的聚合函数会将多行的值合并成一行输出。

默认情况下，我们会合并表中所有行的值。例如，如果我们想统计 flights 表中的行数，可以使用：

sqlite> SELECT COUNT(*) from FLIGHTS;
13

如果我们想将相似行中的值分组，并在这些组内执行聚合操作呢？我们使用 GROUP BY 子句。

再看一个例子。对每个不同的出发地，将所有具有相同出发机场的行收集到一个组中。然后选择 price 列并应用 MIN 聚合，以找回该组中最便宜出发地的价格。最终结果是一个包含出发机场和最便宜出发航班的表。

sqlite> SELECT departure, MIN(price) FROM flights GROUP BY departure;
departure  MIN(price)
---------  ----------
AUH        932
LAS        50
LAX        89
SEA        32
SFO        40
SLC        42

就像我们可以用 WHERE 筛选行一样，我们也可以用 HAVING 筛选组。通常，HAVING 子句应当使用聚合函数。假设我们想查看所有至少有两次出发的机场：

sqlite> SELECT departure FROM flights GROUP BY departure HAVING COUNT(*) >= 2;
departure
---------
LAX
SFO
SLC

注意，聚合函数 COUNT(*) 只是统计每个组中的行数。假设我们想统计不同机场的数量。那么，可以使用以下查询：

sqlite> SELECT COUNT(DISTINCT departure) AS destinations FROM flights;
destinations
------------
6

这列举了 flights 表中所有不同的出发机场（本例中为：SFO、LAX、AUH、SLC、SEA 和 LAS）。

教室

改编自 2023 年春季期末考试。

finals 表包含列 hall（字符串）和 course（字符串），其中的行表示某门课程举行期末考试的报告厅。

sizes 表包含列 room（字符串）和 seats（数字），校园中每个独特的房间占一行，包含该房间的座位数。所有报告厅都是房间。

Q5: 总座位数

创建一个包含两列的表：course（字符串）和 total（数字），为每门期末考试使用至少两个房间的课程占一行。每行包含课程名称以及该课程期末考试所有房间的座位总数。

你的查询应当能正确处理 finals 和 sizes 表中可能出现的任何数据，但对于上面的示例数据，结果应该是：

61A|2400
61B|1700
61C|1200

将 finals 和 sizes 表连接起来，但要通过限制为 hall（来自 finals）与 room（来自 sizes）取值相同的行，来确保每个连接后的行是“一致”的。

由于输出中每门课程占一行，但同一门课程在 finals 表中出现在多行，因此按 course 分组。

COUNT(*) 求的是一个组中输入行的数量，在此例中即为某门课程使用的房间数。

表达式 SUM(seats) 求的是一个组（来自 sizes 表）中 seats 值的和。如果每门课程对应一个组，那么这就是该课程所有报告厅座位数的总和。

Q6: 教室共享

编写一条 select 语句，创建一个包含两列的表：course（字符串）和 shared（数字），为每门至少使用了一个也被其他课程使用的房间的课程占一行。每行包含课程名称，以及该课程中被其他课程使用的房间总数。

COUNT(DISTINCT x) 求出在一个组中出现在列 x 中的不同值的数量。例如，SELECT COUNT(DISTINCT seats) from sizes; 会输出 8，因为 sizes 中有 9 行，但有 2 行的座位数为 300，所以只有 8 个不同值。

你的查询应当能正确处理 finals 和 sizes 表中可能出现的任何数据，但对于下面的示例，结果应该是：

61A|3
61B|2
61C|2
70|1

讨论时间： 讨论为什么输出表包含这些内容。61B 中被共享的两个报告厅是哪两个？

将 finals 与 finals 自身连接，但要确保连接后的行是针对使用同一报告厅的不同课程。

按第一个 course 列分组，使每门课程对应一个组（以及一行输出）。如果 WHERE 子句已经将输入行限制为使用同一报告厅的两个不同课程，就不需要 HAVING 子句。

统计某门课程中 hall 值的不同数量：COUNT(DISTINCT ___)。需要 DISTINCT 限制，是为了避免一个被超过两门课程使用的报告厅被重复计数。
