可变性

我们可以用很多内置方法来修改列表。下面是最常用的一些：
  • append(el)：将 el 追加到列表末尾，并返回 None。
  • extend(lst)：将列表与 lst 拼接以扩展列表，并返回 None。
  • remove(el)：从列表中移除第一个出现的 el，并返回 None。
  • insert(i, el)：在索引 i 处插入 el，并返回 None。

  • pop(i)：移除并返回索引 i 处的元素。如果不指定索引，则移除并返回列表中的最后一个元素。

让我们看看这些方法的实际效果：

>>> l = [3, 5, 6]
>>> l.append(10)    # Append 10 to the end of the list
>>> l
[3, 5, 6, 10]
>>> l.extend([30, 40])
>>> l
[3, 5, 6, 10, 30, 40]
>>> l.remove(5)     # Remove the first occurrence of 5
>>> l
[3, 6, 10, 30, 40]
>>> l.insert(2, -2) # Insert -2 at index 2
>>> l
[3, 6, -2, 10, 30, 40]
>>> l.pop()         # Remove and return the last element
40
>>> l
[3, 6, -2, 10, 30]
>>> l.pop(2)        # Remove and return the element at index 2
-2
>>> l
[3, 6, 10, 30]

请注意以下两点：

  • 在整个过程中，名字 l 始终指向同一个列表对象；它从未被重新赋值。每次调用方法后输出看起来不同，是因为 l 所指向的列表被修改了。
  • 这里唯一有返回值的方法是 pop！其他方法都返回 None。

迭代器

可迭代对象（iterable）是指任何可以被逐个遍历、一次处理一个元素的值。我们用来遍历可迭代对象的一种结构是 for 语句： 
for elem in iterable:
    # do something

一般而言，可迭代对象是这样一种对象：对其调用内置函数 iter 会返回一个迭代器。迭代器（iterator）则是这样一种对象：对其调用内置函数 next 会返回下一个值。

例如，列表就是一个可迭代值。

>>> s = [1, 2, 3, 4]
>>> next(s)       # s is iterable, but not an iterator
TypeError: 'list' object is not an iterator
>>> t = iter(s)   # Creates an iterator
>>> t
<list_iterator object ...>
>>> next(t)       # Calling next on an iterator
1
>>> next(t)       # Calling next on the same iterator
2
>>> next(iter(t)) # Calling iter on an iterator returns itself
3
>>> t2 = iter(s)
>>> next(t2)      # Second iterator starts at the beginning of s
1
>>> next(t)       # First iterator is unaffected by second iterator
4
>>> next(t)       # No elements left!
StopIteration
>>> s             # Original iterable is unaffected
[1, 2, 3, 4]

你也可以在 for 语句中使用迭代器，因为所有迭代器都是可迭代的。但请注意，由于迭代器会保留自身状态，它们只能用来遍历可迭代对象一次：

>>> t = iter([4, 3, 2, 1])
>>> for e in t:
...     print(e)
4
3
2
1
>>> for e in t:
...     print(e)

有一些内置函数会返回迭代器。这些 Python 内置的序列操作被称为“惰性计算”结果。

>>> m = map(lambda x: x * x, [3, 4, 5])
>>> next(m)
9
>>> next(m)
16
>>> f = filter(lambda x: x > 3, [3, 4, 5])
>>> next(f)
4
>>> next(f)
5
>>> z = zip([30, 40, 50], [3, 4, 5])
>>> next(z)
(30, 3)
>>> next(z)
(40, 4)

生成器

生成器（generator）是一个迭代器，由调用生成器函数得到；生成器函数是指包含 yield 语句（而不是 return 语句）的函数。使用迭代器的方式是对它调用 next，或者把它当作可迭代对象来使用（例如在 for 语句中）。

Q3：大斐波那契

这个生成器函数会依次产生所有的 斐波那契 数。

def gen_fib():
    n, add = 0, 1
    while True:
        yield n
        n, add = n + add, n

请互相讲解下面这个表达式，让每个人都理解它的工作原理。（它会创建一个包含前 10 个斐波那契数的列表。）

(lambda t: [next(t) for _ in range(10)])(gen_fib())

然后，在下面的空格中只填入名称和括号，使整个表达式求值得到大于 2026 的最小斐波那契数。

和同伴讨论一下哪些内置函数可能有用，例如 map、filter、list、any、all 等。

Q4：与众不同

实现 differences，一个生成器函数，接收 t（一个遍历数字的非空迭代器）。它依次产生 t 中每对相邻数值之间的差值。如果 t 遍历了 n 个正整数值，那么 differences 应当产生 n-1 次。

Q5：整数划分

树递归的生成器函数与普通树递归函数结构相似。它们适用于遍历所有可能性。与其构造一个结果列表再返回，不如直接对每个结果使用 yield。

你需要确定一种递归分解：如何用更简单的递归调用来表达答案。先问问自己，一次递归调用会产生什么，然后再思考如何使用这些结果。

定义。 对于正整数 n 和 m，使用不超过 m 的各部分对 n 的划分，是指一组不超过 m 的正整数按非递减顺序排列、其和为 n 的加法表达式。

实现 partition_gen，一个接收正整数 n 和 m 的生成器函数。它依次产生将 n 使用不超过 m 的各部分进行划分的结果（以字符串形式）。

提示： 对于我们在课堂上学习的 partitions 函数（视频），其递归分解是先枚举所有至少使用一个 m 来划分 n 的方式，再枚举完全不使用 m（只用 m-1 及更小值）的方式。

Q6：平方数

实现生成器函数 squares，它接收正整数 total 和 k。它依次产生所有由不小于 k*k 的完全平方数组成、且和为 total 的列表。每个列表按非递增顺序排列（从大到小）。

Q7：邱奇生成器

实现 church_generator，一个以函数 f 为参数的生成器函数。church_generator 依次产生一些函数，每个函数对其参数应用 f 的次数比上一个生成的函数多一次。（这些被产生的函数被称为 邱奇数。）
