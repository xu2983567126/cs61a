链表

链表是一个 Link 对象或 Link.empty.

你可以修改一个 Link 对象 s，有两种方式：

  • 使用 s.first = ...
  • 使用 s.rest = ...

你可以通过调用 Link 来创建一个新的 Link:

  • Link(4) makes a linked list of length 1 containing 4.
  • Link(4, s) makes a linked list that starts with 4 followed by the elements of linked list s.
class Link:
    """A linked list is either a Link object or Link.empty

    >>> s = Link(3, Link(4, Link(5)))
    >>> s.rest
    Link(4, Link(5))
    >>> s.rest.rest.rest is Link.empty
    True
    >>> s.rest.first * 2
    8
    >>> print(s)
    (3 4 5)
    """
    empty = ()

    def __init__(self, first, rest=empty):
        assert rest is Link.empty or isinstance(rest, Link)
        self.first = first
        self.rest = rest

    def __repr__(self):
        if self.rest:
            rest_repr = ', ' + repr(self.rest)
        else:
            rest_repr = ''
        return 'Link(' + repr(self.first) + rest_repr + ')'

    def __str__(self):
        string = '('
        while self.rest is not Link.empty:
            string += str(self.first) + ' '
            self = self.rest
        return string + str(self.first) + ')'

问题 1：奇怪的循环

这里有一个 Link 对象，它带有一个循环，表示一个无限重复的 1 的列表。 它可作为参考用的文档测试，帮助你解决此问题。

>>> ones = Link(1)
>>> ones.rest = ones
>>> [ones.first, ones.rest.first, ones.rest.rest.first, ones.rest.rest.rest.first]
[1, 1, 1, 1]
>>> ones.rest is ones
True

实现 strange_loop，它不接受任何参数，并返回一个 Link object s，使得 s.rest.first.rest 为 s.

。请先画出你想创建的链表的图示，然后编写代码来创建它。 你的答案

解答 
def strange_loop() -> Link:
    """Return a Link s for which s.rest.first.rest is s.

    >>> s = strange_loop()
    >>> s.rest.first.rest is s
    True
    """
    s = Link(1, Link(Link(2)))
    s.rest.first.rest = s
    return s

问题 2：两种方式的求和

同时实现 sum_rec 和 sum_iter。每一个都接受一个数字链表 s 以及一个非负整数 k，并返回前 k 个 元素之和，这些元素来自 s。如果 k 中的元素少于 s，则它们全部被求和。如果 k 为 0 或 s 为空，则和为 0。

使用递归来实现 sum_rec。不要使用递归来实现 sum_iter；而是使用一个 while 循环。

要开始递归实现，请考虑示例 a = Link(1, Link(6, Link(8)))，以及调用 sum_rec(a, 2)。请写下对 sum_rec 的递归调用，它有助于计算 sum_rec(a, 2)。然后，写下该递归调用应当返回什么。讨论这个返回值对于计算 sum_rec(a, 2).

你的答案
解答 
def sum_rec(s: Link, k: int) -> int:
    """Return the sum of the first k elements in s.

    >>> a = Link(1, Link(6, Link(8)))
    >>> sum_rec(a, 2)
    7
    >>> sum_rec(a, 5)
    15
    >>> sum_rec(Link.empty, 1)
    0
    """
    # 使用对 sum_rec 的递归调用；don't 调用 sum_iter
    if k == 0 or s is Link.empty:
        return 0
    return s.first + sum_rec(s.rest, k - 1)

def sum_iter(s: Link, k: int) -> int:
    """Return the sum of the first k elements in s.

    >>> a = Link(1, Link(6, Link(8)))
    >>> sum_iter(a, 2)
    7
    >>> sum_iter(a, 5)
    15
    >>> sum_iter(Link.empty, 1)
    0
    """
    # Don't 调用 sum_rec 或 sum_iter
    total = 0
    while k > 0 and s is not Link.empty:
        total, s, k = total + s.first, s.rest, k - 1
    return total

问题 3：重叠

实现 overlap，它接受两个数字链表（分别称为 s 和 t），这两个链表均按递增顺序排列，且各自内部没有重复元素。 它返回同时出现在两个链表中的数字个数。

这可以在 线性 时间内完成，时间复杂度关于 s 和 t 的总长度：始终在首元素较小的那个链表中向前推进， 直到两个链表的首元素相等（计数加一并同时推进两者），或者其中一个链表为空（此时返回）。

你的答案
解答 
def overlap(s: Link, t: Link) -> int:
    """For increasing s and t, count the numbers that appear in both.

    >>> a = Link(3, Link(4, Link(6, Link(7, Link(9, Link(10))))))
    >>> b = Link(1, Link(3, Link(5, Link(7, Link(8)))))
    >>> overlap(a, b)  # 3 and 7
    2
    >>> overlap(a.rest, b)  # just 7
    1
    >>> overlap(Link(0, a), Link(0, b))
    3
    """
    if s is Link.empty or t is Link.empty:
        return 0
    if s.first == t.first:
        return 1 + overlap(s.rest, t.rest)
    elif s.first < t.first:
        return overlap(s.rest, t)
    elif s.first > t.first:
        return overlap(s, t.rest)

def overlap_iterative(s, t):
    """For increasing s and t, count the numbers that appear in both.

    >>> a = Link(3, Link(4, Link(6, Link(7, Link(9, Link(10))))))
    >>> b = Link(1, Link(3, Link(5, Link(7, Link(8)))))
    >>> overlap(a, b)  # 3 and 7
    2
    >>> overlap(a.rest, b)  # just 7
    1
    >>> overlap(Link(0, a), Link(0, b))
    3
    """
    res = 0
    while s is not Link.empty and t is not Link.empty:
        if s.first == t.first:
            res += 1
            s = s.rest
            t = t.rest
        elif s.first < t.first:
            s = s.rest
        else:
            t = t.rest
    return res

问题 4：按序迭代

实现 iterate_in_order，它接受两个数字链表（分别称为 s 和 t，这两个链表均按递增顺序排列，且各自内部没有重复元素。 它返回一个生成器，按顺序迭代 s 和 t 中的所有元素（非递减顺序）。

你的答案
解答 
def iterate_in_order(s: Link, t: Link):
    """For increasing s and t, yields the elements in s and t, in non-decreasing order.

    >>> a = Link(3, Link(4, Link(6, Link(7, Link(9, Link(10))))))
    >>> b = Link(1, Link(3, Link(5, Link(7, Link(8)))))
    >>> t = iterate_in_order(a, b)
    >>> for item in t:
    ...     print(item)
    1
    3
    3
    4
    5
    6
    7
    7
    8
    9
    10
    >>> t = iterate_in_order(Link.empty, b)
    >>> for item in t:
    ...      print(item)
    1
    3
    5
    7
    8
    """
    while s is not Link.empty or t is not Link.empty:
        if s is Link.empty:
            yield t.first
            t = t.rest
        elif t is Link.empty or s.first <= t.first:
            yield s.first
            s = s.rest
        else:
            yield t.first
            t = t.rest

效率

寻找函数运行时间增长阶的技巧：

  • 如果函数是递归的，请确定递归调用的次数以及每次递归调用的运行时间。
  • 如果函数是迭代的，请确定内层循环的次数以及每个循环的运行时间。
  • 忽略系数。一个执行 n 次操作的函数，与一个执行 100 * n 次操作的函数，两者都是线性的。
  • 选择最大的增长阶。如果一个函数的第一部分具有线性运行时间，而第二部分具有二次运行时间，则整个函数具有二次运行时间。

def mod_7(n):

问题 6：效率练习

选择填入下面所定义函数空白处的术语： <function> 的运行时间为 ____，时间复杂度关于其输入的长度。

  • 常数
  • 对数
  • 线性
  • 二次
  • 指数
  • 以上都不是

假设 len 的运行时间为常数时间， 而 all 的运行时间关于其输入长度为线性。 通过索引选择列表中的元素需要常数时间。 构造一个 range 需要常数时间。

def count_partitions(n, m):
    """Counts the number of partitions of a positive integer n, 
    using parts up to size m."""
    if n == 0:
        return 1
    elif n < 0:
        return 0
    elif m == 0:
        return 0
    else:
        with_m = count_partitions(n-m, m)
        without_m = count_partitions(n, m-1)
        return with_m + without_m

def is_palindrome(s):
    """Return whether a list of numbers s is a palindrome."""
    return all([s[i] == s[len(s) - i - 1] for i in range(len(s))])

def binary_search(lst, n):
    """Takes in a sorted list lst and returns the index where integer n
    is contained in lst. Returns -1 if n does not exist in lst."""
    low = 0
    high = len(lst)
    while low <= high:
        middle = (low + high) // 2
        if lst[middle] == n:
            return middle
        elif n < lst[middle]:
            high = middle - 1
        else:
            low = middle + 1
    return -1

这个 is_palindrome 问题改编自 2019 年秋季第 6(d) 题 期末.

count_partitions：指数。

count_partitions 接受两个输入 n 和 m，因此运行时间取决于这两个输入。然而，当确定增长阶时，我们主要关心的是当 n 和 m.

的取值更大时运行时间的变化。条件语句（例如 if n == 0）是逻辑比较，需要常数时间。因此，对我们运行时间影响最大的是对 count_partitions 的递归调用次数。对于每一次对 count_partitions 的函数调用，我们会再进行两次递归调用：一次使用 m 作为划分，另一次不使用。

将该函数的递归调用树可视化后，我们会发现每一层的函数调用数量都会翻倍。因此，count_partitions 的运行时间是指数的。

is_palindrome：线性。

我们感兴趣的是该函数如何相对于其输入的长度运行，其输入长度为 len(s).

在 is_palindrome 中，计算 len(s)需要常数时间， 然后构造一个从 0 到 len(s) 的 range（不包含上限）。

对于该范围内的每个元素，我们会从 s 中选择两个元素 （s[i] 和 s[len(s)-i-1]）并对它们进行比较，每个元素需要某些 常数时间。 当我们对所有元素完成这一操作后， 我们就将输入列表构建成了 all，所用时间相对于 is_palindrome 的输入长度为线性。

我们假设 all 的运行时间相对于 其 输入， 也就是我们刚刚构建的列表的长度，且与 is_palindrome 的输入长度为线性。

的长度相同。总体而言，is_palindrome 因此将花费相对于其输入长度的线性时间。

binary_search：对数。

这个 binary_search 算法的运行时间取决于 lst 的长度，因为我们正在其中搜索某个整数 n.

同样，假设 len(lst) 以及逻辑比较的计算需要常数时间，我们来观察在完成任务调用之前，while 循环可能会经历多少次迭代。首先，我们检查已排序列表中间的元素。如果 lst[middle] 不等于 n，该函数会判断 lst[middle] 是小于还是大于 n，并将搜索范围缩小到 lst 的较低一半或较高一半（分别）。

对于 while 循环的每一次迭代，binary_search 会将输入 lst 中我们正在搜索的元素数量减半。因此，在返回索引或 -1 之前，while 循环的最大迭代次数为以 2 为底的 log(len(lst))。binary_search 相对于其输入长度来说花费对数时间lst.
