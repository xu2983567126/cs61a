链表

链表是一个 Link 对象或 Link.empty。

你可以通过两种方式修改 Link 对象 s：

  • 用 s.first = ... 修改第一个元素
  • 用 s.rest = ... 修改其余元素

你可以通过调用 Link 来创建一个新的 Link 对象：

  • Link(4) 创建一个长度为 1、包含 4 的链表。
  • Link(4, s) 创建一个以 4 开头、后接链表 s 中元素的链表。
class Link:
    """A linked list is either a Link object or Link.empty

    >>> s = Link(3, Link(4, Link(5)))
    >>> s.rest
    Link(4, Link(5))
    >>> s.rest.rest.rest is Link.empty
    True
    >>> s.rest.first * 2
    8
    >>> print(s)
    (3 4 5)
    """
    empty = ()

    def __init__(self, first, rest=empty):
        assert rest is Link.empty or isinstance(rest, Link)
        self.first = first
        self.rest = rest

    def __repr__(self):
        if self.rest:
            rest_repr = ', ' + repr(self.rest)
        else:
            rest_repr = ''
        return 'Link(' + repr(self.first) + rest_repr + ')'

    def __str__(self):
        string = '('
        while self.rest is not Link.empty:
            string += str(self.first) + ' '
            self = self.rest
        return string + str(self.first) + ')'

>>> ones = Link(1)
>>> ones.rest = ones
>>> [ones.first, ones.rest.first, ones.rest.rest.first, ones.rest.rest.rest.first]

Q2: 两种求和方式

实现 sum_rec 和 sum_iter。两者都接受一个数字链表 s 和一个非负整数 k，并返回 s 中前 k 个元素的和。如果 s 中不足 k 个元素，则将它们全部求和。如果 k 为 0 或 s 为空，和为 0。

使用递归来实现 sum_rec。实现 sum_iter 时不要使用递归，而是使用 while 循环。

要开始递归实现，考虑示例 a = Link(1, Link(6, Link(8))) 以及对 sum_rec(a, 2) 的调用。写下能帮助计算 sum_rec(a, 2) 的 sum_rec 递归调用。然后写出该递归调用应返回的值。讨论这个返回值对计算 sum_rec(a, 2) 的返回值有什么帮助。

Q3: 重叠

实现 overlap，它接受两个名为 s 和 t 的数字链表，它们按递增顺序排列且各自列表内没有重复元素。它返回同时出现在两个链表中的数字个数。

这可以在 s 和 t 总长度上的线性时间内完成：始终在第一个元素较小的那个链表中向前推进，直到两个第一个元素相等（计数加一并同时推进两者）或其中一个链表为空（此时返回）。

Q4: 按顺序迭代

实现 iterate_in_order，它接受两个名为 s 和 t 的数字链表，它们按递增顺序排列且各自列表内没有重复元素。它返回一个生成器，按非递减顺序遍历 s 和 t 中的所有元素。

效率

寻找函数运行时间增长阶数的技巧：

  • 如果函数使用递归，确定递归调用的次数以及每次递归调用的运行时间。
  • 如果函数使用迭代，确定内层循环的次数以及每次循环的运行时间。
  • 忽略系数。执行 n 次操作的函数和执行 100 * n 次操作的函数都是线性的。
  • 选择最大的增长阶数。如果函数第一部分的运行时间为线性、第二部分的运行时间为二次，则整个函数的运行时间为二次。

Q6: 效率练习

选择填入下列函数空白处的术语：<function> 的运行时间是其输入长度的 ____。

  • 常数
  • 对数
  • 线性
  • 二次
  • 指数
  • 以上都不是

假设 len 的运行时间为常数，all 在其输入长度上的运行时间为线性。通过索引选取列表元素需要常数时间。构造 range 需要常数时间。

def count_partitions(n, m):
    """Counts the number of partitions of a positive integer n, 
    using parts up to size m."""
    if n == 0:
        return 1
    elif n < 0:
        return 0
    elif m == 0:
        return 0
    else:
        with_m = count_partitions(n-m, m)
        without_m = count_partitions(n, m-1)
        return with_m + without_m

def is_palindrome(s):
    """Return whether a list of numbers s is a palindrome."""
    return all([s[i] == s[len(s) - i - 1] for i in range(len(s))])

def binary_search(lst, n):
    """Takes in a sorted list lst and returns the index where integer n
    is contained in lst. Returns -1 if n does not exist in lst."""
    low = 0
    high = len(lst)
    while low <= high:
        middle = (low + high) // 2
        if lst[middle] == n:
            return middle
        elif n < lst[middle]:
            high = middle - 1
        else:
            low = middle + 1
    return -1
