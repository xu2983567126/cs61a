Scheme

你可以使用 scheme.cs61a.org 来尝试运行。

一个 if 表达式有 3 个子表达式：

  • 第一个称为 谓词, is always evaluated to choose between the next two.
  • 第二个称为 结果分支, is evaluated if the 谓词's value is true.
  • 第三个称为 替代分支, is evaluated if the 谓词's value is false.

第二个或第三个表达式（被求值的那个）的值即为整个 if 表达式的值。

只有 #f 是一个 假值 在 Scheme 中是假值。所有其他值都是真值，包括 #t。

逻辑特殊形式 and 和 or 可以有任意数量的子表达式。使用 and 来检查其所有子表达式是否都为真值。使用 or 来检查其中是否有任意一个为真值。

一个示例：

scm> (define y (+ 1 2))  ; y is now 3
y
scm> (define z (or (> y 4) (> y 5) (< y 5)))  ; z is true because y < 5
z
scm> (+ 7 (if (and (> y 1) z) y 1))  ; the if expression evaluates to 3
10

该 expect 形式内置于 scheme.cs61a.org 并会检查它的第一个子表达式的求值结果是否等于其第二个子表达式。它用于测试。

问题 1：完全契合

定义：一个完全平方数是 k*k（其中 为某个整数）k。

实现 fit，它接收非负整数 total 和 n。它返回 是否存在 n 个不同的 正完全平方数，它们的和为 total。

使用 (or _ _) 特殊形式来组合两个递归调用：其中一个 使用 k*k 参与求和，另一个不参与。
你的答案
解答 
;;; Return whether there are n perfect squares with no repeats that sum to total
;;;
;;; scm> (fit 10 2)
;;; #t
;;; scm> (fit 9 2)
;;; #f
(define (fit total n)
    (define (f total n k)
        (if (and (= n 0) (= total 0))
            #t
        (if (< total (* k k))
            #f
            (or (f total n (+ k 1)) (f (- total (* k k)) (- n 1) (+ k 1)))
        )))
    (f total n 1))

(expect (fit 10 2) #t)  ; 1*1 + 3*3
(expect (fit 9 1)  #t)  ; 3*3
(expect (fit 9 2)  #f)  ;
(expect (fit 9 3)  #f)  ; 1*1 + 2*2 + 2*2 doesn't count because of repeated 2*2
(expect (fit 25 1)  #t) ; 5*5
(expect (fit 25 2)  #t) ; 3*3 + 4*4
这是一个树形递归问题。你的实现应该尝试用不同的方式将 n 个不同的完全平方数相加，看它们的和是否为 total。以例子 (fit 10 2) 为例，对 (f 10 2 1) 的调用会返回：是否存在 2 个完全平方数，它们的和为 10，且每个都 1*1 或更大。要弄清楚这一点，你需要进行两个递归调用：
  • (f 10 2 2) 会返回：是否存在 2 个完全平方数，它们的和为 10，且每个都 2*2 或更大（否）
  • (f 9 1 2) 会返回：是否存在 1 个完全平方数，其和为 9，且该数 2*2 或更大（是：3*3）

一旦你的实现完成了这两个递归调用，就需要将它们合并为一个结果。

第一个递归调用应该从 k*k 中减去 total，并从 n 中减去 1；另一个递归调用应该保持 total 和 n 不变。

问题 2：最大公约数

最大公约数（GCD）是能同时整除两个正整数的最大整数。

编写过程 gcd，它计算数字 a 和 b，使用 欧几里得算法，该算法递归地利用一个事实：两个值的最大公约数必定是 以下两者之一：

  • 如果较小值能整除较大值，则为较小值；或者
  • 较小值与（较大值除以较小值的余数）之间的最大公约数

换句话说，如果 a 大于 b 和 a 不能被 b 整除， 则

gcd(a, b) = gcd(b, a % b)  # please note that this is Python syntax

你可能会发现提供的列表过程 min 和 max 很有帮助。你也可以使用内置的 modulo 和 zero? 过程。

>scm> (modulo 10 4)
>2
>scm> (zero? (- 3 3))
>#t
>scm> (zero? 3)
>#f
你的答案
解答 (define (max a b) (if (> a b) a b)) (define (min a b) (if (> a b) b a)) (define (gcd a b) 
(cond ((zero? a) b)
      ((zero? b) a)
      ((= (modulo (max a b) (min a b)) 0) (min a b))
      (else (gcd (min a b) (modulo (max a b) (min a b)))))

）

(expect (gcd 0 4) 4) (expect (gcd 10 0) 10) (expect (gcd 30 5) 5) (expect (gcd 24 60) 12) (expect (gcd 1071 462) 21)

Scheme 列表 & 引号

Scheme 列表是链表。快速回顾：

  • nil 和 () 是同一回事：空列表。
  • (cons first rest) 构造一个链表，其 first 作为第一个元素。 而 rest 作为列表的其余部分，而其余部分应当始终是一个列表。
  • (car s) 返回列表 s。
  • (cdr s) 返回列表 s。
  • (list ...) 接收 n 个参数，并返回一个长度为 n、以这些参数为元素的列表。
  • (append ...) 接收 n 个列表作为参数，并返回包含这些列表中所有元素的列表。
  • (draw s) 会绘制列表 s 的链表结构。它仅在 code.cs61a.org/scheme。现在就用类似 (draw (cons 1 nil))。

对表达式加引号会使其保持未求值状态。例如：

  • 'four 和 (quote four) 都会求值为符号 four。
  • '(2 3 4) 和 (quote (2 3 4)) 都会求值为一个包含三个元素的列表：2、3 和 4。
  • '(2 3 four) 和 (quote (2 3 four)) 会求值为一个包含 2、3 以及符号 four。

下面是一个重要的区别，介于 list 与引号之间：

scm> (list 2 (+ 3 4))
(2 7)
scm> '(2 (+ 3 4))
(2 (+ 3 4))

问题 3：移除

实现一个过程 remove，它接收一个数字列表 s 以及一个数字 x。它返回一个列表，其中移除了 x 的所有出现，从 s 中移除。你可以 假设 s 只包含数字，且不会出现嵌套列表。

你的答案
解答 
;;; Return a list with all numbers equal to x removed
;;;
;;; scm> (remove '(3 4 3 4 4 3) 3)
;;; (4 4 4)
;;; scm> (remove '(3 4 3 4 4 3) 4)
;;; (3 3 3)
(define (remove s x)
  (if (null? s) nil
    (if (equal? x (car s)) (remove (cdr s) x) (cons (car s) (remove (cdr s) x)))

))

(expect (remove '(3 4 3 4 4 3) 3) (4 4 4))
(expect (remove '(3 4 3 4 4 3) 4) (3 3 3))

问题 4：配对

实现 pair-up，它接收一个列表 s。它返回一个列表的列表， 其中包含 s 的全部元素，且顺序不变。结果中的每个列表 应当包含 2 个元素。最后一个最多可以有 3 个。

请查看示例，确保你理解这个过程的作用。

你的答案
解答 
;;; Return a list of pairs containing the elements of s.
;;;
;;; scm> (pair-up '(3 4 5 6 7 8))
;;; ((3 4) (5 6) (7 8))
;;; scm> (pair-up '(3 4 5 6 7 8 9))
;;; ((3 4) (5 6) (7 8 9))
(define (pair-up s)
    (if (<= (length s) 3)
        (list s)
        (cons (list (car s) (car (cdr s))) (pair-up (cdr (cdr s))))
    ))

(expect (pair-up '(3 4 5 6 7 8)) ((3 4) (5 6) (7 8)) )
(expect (pair-up '(3 4 5 6 7 8 9)) ((3 4) (5 6) (7 8 9)) )

pair-up 接收一个列表（数字列表）并返回一个列表的列表，因此当 (length s) 的长度小于或等于 3 时，返回一个包含列表 s 的列表。 例如，(pair-up (list 2 3 4)) 应当返回 ((2 3 4))。

使用 (cons _ (pair-up _)) 来构造结果，其中 传给 cons 的第一个参数是一个包含两个元素的列表：(car s) 和 (car (cdr s))。 传给 pair-up 的参数是前两个元素之后的所有内容。

你的答案
解答 
    (define (insert element lst index)
        (if (= index 0)
            (cons element lst)

问题 6：递增绳子

定义： 一个 rope 在 Scheme 中是一个非空列表，其中只包含数字， 除了最后一个元素可以是数字，也可以是一个 rope。

实现 up，这是一个 Scheme 过程，接收一个正整数 n。它返回 一个 rope，包含 n 的各位数字，并且是满足以下条件的最短 rope：同一列表中每对 相邻数字都是递增排列的。

提醒：quotient 过程执行整除（向下取整），类似于 Python 中的 //。 而 remainder 过程则类似于 Python 中的 %。

你的答案
解答 
(define (up n)
    (define (helper n result)
        (define first (remainder n 10))  ; Using first will shorten your code
        (if (zero? n) result
            (helper
                (quotient n 10)
                (if (< first (car result))
                    (cons first result)
                    (list first result))
                )))
    (helper
      (quotient n 10)
      (list (remainder n 10))
    ))

(expect (up 314152667899) (3 (1 4 (1 5 (2 6 (6 7 8 9 (9)))))))
将 first 与 (car result) 进行比较，以决定是 cons 将值 first 追加到 result 上，还是构成一个包含 first 和 result 的新列表。
要正确地调用 helper（在 up 内部），请构造一个只包含 n 最后一位数字的 rope：(remainder n 10)。
