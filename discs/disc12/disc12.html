高阶函数

Q1: 匹配器

实现 match_k，它接受一个整数 k，并返回一个函数；该返回的函数接受一个变量 x，如果 x 中所有相隔 k 位的数字都相同，则返回 True。

例如，match_k(2) 返回一个单参数函数，它接受 x 并检查 x 中相隔 2 位的数字是否相同。

match_k(2)(1010) 中 x = 1010，从左到右的数字为 1、0、1、0。1 == 1 且 0 == 0，因此 match_k(2)(1010) 的结果为 True。

match_k(2)(2010) 中 x = 2010，从左到右的数字为 2、0、1、0。2 != 1 但 0 == 0，因此 match_k(2)(2010) 的结果为 False。

重要： 你不能使用字符串或索引来解决本题。

提示： 对 10 的幂做整除可以去掉最右边的数字。

Q2: 中序遍历

编写一个返回生成器的函数，生成“中序”遍历：假设每个节点有 0 或 2 个子分支，我们按从左到右的顺序 yield 每个节点的值。

迭代器

Q3: 重复

实现 repeated，它接受一个迭代器 t 和一个大于 1 的整数 k。它返回 t 中第一个连续出现 k 次的值。

重要： 对 t 调用 next 的次数应当尽可能少。假设 t 中至少有一个元素连续重复至少 k 次。

提示： 如果你遇到 StopIteration 异常，说明你的 repeated 函数调用 next 的次数过多了。

链表

Q5: 隔一个取一个

实现 every_other，它接受一个链表 s。它修改 s，使所有奇数索引（使用从 0 开始的索引）的元素从列表中被移除。例如：

>>> s = Link('a', Link('b', Link('c', Link('d'))))
>>> every_other(s)
>>> s.first
'a'
>>> s.rest.first
'c'
>>> s.rest.rest is Link.empty
True

如果 s 包含的元素少于两个，则 s 保持不变。不要返回任何东西！ every_other 应当修改原列表。

Scheme

Q6: 开关

定义宏 switch，它接受一个表达式 expr 和一个名为 cases 的“配对列表”，其中每对的第一个元素是一个数字，第二个元素是一个单独的表达式。switch 会求值 cases 中对应于 expr 求值所得数字的那条表达式。

scm> (switch (+ 1 1) ((1 (print 'a))
                      (2 (print 'b))
                      (3 (print 'c))))
b

你可以假设 expr 求值所得的值总是一个数字，并且总出现在 cases 中某一对的第一个元素位置。你也可以假设 cases 中每对的第一个值是一个数字，且第二个表达式不包含符号 val。

使用 equal? 来检查两个数字是否相等。

对于上面所示的示例，构造如下表达式： 
(begin
     (define val (+ 1 1))
     (cond ((equal? val 1) (print 'a))
           ((equal? val 2) (print 'b))
           ((equal? val 3) (print 'c))))

这个表达式先给 val 赋值为 3，然后将 val 与 cases 中每对的第一个元素进行比较。
