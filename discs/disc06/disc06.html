面向对象编程

面向对象编程（object-oriented programming，OOP）是一种编程范式，它让我们可以像在现实生活中一样把数据当作对象来处理。

例如，考虑 类（class） Student。你们每一个人都是这个类的一个实例（instance）。

所有 CS 61A 学生都拥有的信息（例如 name）被称为实例变量（instance variable）。每个学生都有这些变量，但它们的值因人而异。在所有 Student 实例之间共享的变量被称为类变量（class variable）。例如，extension_days 属性就是一个类变量，因为它是所有学生共有的属性。

所有学生都能做作业、上课和参加答疑时间。当函数属于某个特定的对象时，它们被称为方法（method）。在这种情况下，这些行为就是 Student 对象的方法。

以下是我们上面讨论内容的回顾：

  • 类（class）：用于创建对象的模板
  • 实例（instance）：由类创建出的单个对象
  • 实例变量（instance variable）：对象的数据属性，特定于某个实例
  • 类变量（class variable）：对象的数据属性，由类的所有实例共享
  • 方法（method）：绑定到对象的函数，可以在类的所有实例上调用

实例变量、类变量和方法都被视为对象的属性（attributes）。

为了避免为相似的类重复定义属性和方法，我们可以编写一个基类（base class），让更具体的类从中继承（inherit）。例如，我们可以编写一个名为 Pet 的类，并把 Dog 定义为 Pet 的子类（subclass）：

class Pet:
    def __init__(self, name, owner):
        self.is_alive = True    # It's alive!!!
        self.name = name
        self.owner = owner
    def eat(self, thing):
        print(self.name + " ate a " + str(thing) + "!")
    def talk(self):
        print(self.name)

class Dog(Pet):
    def talk(self):
        super().talk()
        print('This Dog says woof!')

继承表示两个或多个类之间的层次关系，其中一个类是另一个类更具体的版本：狗是一种（is a）宠物。（我们在面向对象语言中用“is a”来描述这种关系，而不是指 Python 的 is 运算符。）

由于 Dog 继承自 Pet，Dog 类也会继承 Pet 类的方法，因此我们不需要重新定义 __init__ 或 eat。但我们希望每只 Dog 以 Dog 特有的方式 talk，所以我们可以重写（override） talk 方法。

我们可以使用 super() 来指代 self 的父类（superclass），并像自己是父类的一个实例那样访问父类的任何方法。例如，Dog 类中的 super().talk() 会调用 Pet 类的 talk 方法，但会把 Dog 实例作为 self 传入。

提示： 定义类的一个好开端是先确定必要的类属性和实例属性。在实现类之前，先描述每个属性的类型以及它将如何被使用。

Q1：键盘

概述： 键盘为字母表中的每个字母都设有一个按键。当某个按键被按下时，它会通过调用一个 output 函数（例如 print）来输出对应的字母。该字母是大写还是小写，取决于大写锁定（caps lock）键被按下了多少次。

第一步，实现 Button 类，它接收一个小写 letter（字符串）和一个单参数 output 函数，例如 Button('c', print)。

按钮的 press 方法会对其 letter 属性调用它的 output 属性（一个函数）：如果 caps_lock 被按下了奇数次，就输出大写字母，否则输出小写字母。press 方法还会让 pressed 自增，并返回被按下的按键。提示：'hi'.upper() 的值为 'HI'。

第二步，实现 Keyboard 类。Keyboard 有一个名为 keys 的字典，其中包含 LOWERCASE_LETTERS 中每个字母对应的一个 Button（以其 letter 作为键）。它还有一个记录已输入字母的列表 typed，其中可能混合了大写和小写字母。

type 方法接收一个只包含小写字母的字符串 word。它对 word 中的每个字母调用 keys 中对应 Button 的 press 方法，从而向 Keyboard 的 typed 列表中添加一个字母（根据 caps_lock 决定是大写还是小写）。重要： 在你的 type 实现中不要使用 upper 或 letter；只需调用 press 即可。也不要在你的 type 实现中使用 append；你必须只通过 press 来修改 typed 列表。

阅读 doctest 并讨论：

  • 为什么可以用 .press().press().press() 反复按下一个键。
  • 为什么反复按下一个键，有时只打印在同一行，有时却打印在多行。
  • 为什么 bored.typed 最后有 10 个元素。
由于 self.letter 始终是小写，使用 self.letter.upper() 来生成大写版本。
caps_lock 被按下的次数是 self.caps_lock.pressed 或 Button.caps_lock.pressed。
output 属性是一个可以被调用的函数：self.output(self.letter) 或 self.output(self.letter.upper())。你不需要返回其结果。
这些按键可以用字典推导式来创建：self.keys = {c: Button(c, ...) for c in LETTERS}。对 Button 的调用应传入 c 以及一个会把字母追加到 self.typed 的输出函数，这样每当这些按键中的一个被按下时，就会向 self.typed 追加一个字母。
对 word 中的每个 w，调用 self.key[w] 的 press 方法。当你调用 press 时，Button 应该已经在 Keyboard.__init__ 方法中设置好，会输出到这个 Keyboard 的 typed 列表。

字符串表示

我们已经学习了如何使用类把数据表示为对象，但有时我们需要对象的字符串表示。我们可以通过在类中定义特殊方法 str 和 repr 来自定义对象的显示方式。

class Penguin():
    def __init__(self, age, name):
        self.age = age
        self.name = name

peng = Penguin(3, 'Peng')

让我们以这个 Penguin 类为例！现在，如果我们尝试输出或打印 peng，会得到：

>>> peng
<__main__.Penguin object at 0x104cb9c40>
>>> print(peng)
<__main__.Penguin object at 0x104cb9c40>

这并没有告诉我们关于 peng 的多少信息！我们使用 str 和 repr 来输出更易理解的表示。

str 是表示对象的“非正式”表示，用作输出。当我们在对象上调用 print() 或 str()（例如 str(peng) 或 print(peng)）时，就会输出它。

def __str__(self):
    return self.name + ' is a ' + str(self.age) + ' year old penguin!'
>>> str(peng)
'Peng is a 3 year old penguin!'
>>> print(peng)
Peng is a 3 year old penguin!

repr 返回对象的正式字符串表示，通常用于调试，并在直接显示对象时出现，例如把 peng 放在解释器中。

def __repr__(self):
    return "Penguin(Name=\'" + self.name + "\', age=" + str(self.age)+")"
>>> peng
"Penguin(Name = Peng, Age = 3)"
