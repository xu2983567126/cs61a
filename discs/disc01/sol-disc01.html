While 与 If

学会使用 if 和 while 是一项重要的技能。在本次讨论中， 请专注于我们在前三节课中学习的内容：if, while， 赋值（=）、比较（<, >, ==）以及算术运算。请 不要使用我们尚未在课堂上讲过的 Python 特性，例如 for， range，以及列表。课程后期我们会有充足的时间讲解这些内容，但 现在正是练习使用 if 的时候（教材第 1.5.4 节） 以及 while（教材第 1.5.5 节）。

问题求解

实现一个函数的有效方法是：

  1. 选取一个示例输入及其对应的输出。
  2. 用简单的步骤描述一个从输入计算出输出的过程（用英语描述）。
  3. 弄清楚执行这个过程需要引入哪些额外的名称。
  4. 使用这些额外的名称在代码中实现该过程。
  5. 判断该实现在你最初的示例上是否真的有效。
  6. 判断该实现在其他示例上是否也有效。（如果无效，你可能需要修改第 2 步。）

重要的是，这种方法不会让你从读题直接跳到写代码。

例如，在下一页的 is_prime 问题中，你可以这样做：

  1. 选取 n 为输入（其值为 9），并选取 False 作为输出。
  2. 过程如下：验证 9（n）不能被 1 到 9（n）之间的任意整数整除。
  3. 引入 i 来表示 1 到 9 之间的每一个数字（n）。
  4. 实现 is_prime（这一部分由你和你的小组共同完成）。
  5. 验证 is_prime(9) 会返回 False，通过逐步思考代码的执行过程来验证。
  6. 验证 is_prime(3) 会返回 True 以及 is_prime(1) 会返回 False。

问题 1：是否为素数？

编写一个函数，当正整数 True 是素数时返回 n，否则返回 False。

素数 n 是指除了 1 和 n 自身之外不能被任何数整除的数。例如，13 是素数，因为它只能被 1 和 13 整除；而 14 不是素数，因为它可以被 1、2、7 和 14 整除。

使用 % 运算符：x % y 返回 x 除以 y 的余数。

你的答案
解答 
def is_prime(n):
    """
    >>> is_prime(2)
    True
    >>> is_prime(7)
    True
    >>> is_prime(9)
    False
    >>> is_prime(1) # one is not a prime number!!
    False
    """
    if n == 1:
        return False
    k = 2
    while k < n:
        if n % k == 0:
            return False
        k += 1
    return True

问题 2：Fizzbuzz

实现经典的 Fizz Buzz 序列。该 fizzbuzz 函数 接收一个正整数 n，并为每一个整数打印一行， 从 1 到 n. For each i：

  • 如果 i 能同时被 3 和 5 整除，则打印 fizzbuzz。
  • 如果 i 能被 3 整除（但不能被 5 整除），则打印 fizz。
  • 如果 i 能被 5 整除（但不能被 3 整除），则打印 buzz。
  • 否则，打印数字 i。

尽量让你对 fizzbuzz 的实现简洁。

你的答案
解答 
def fizzbuzz(n):
    """
    >>> result = fizzbuzz(16)
    1
    2
    fizz
    4
    buzz
    fizz
    7
    8
    fizz
    buzz
    11
    fizz
    13
    14
    fizzbuzz
    16
    >>> print(result)
    None
    """
    i = 1
    while i <= n:
        if i % 3 == 0 and i % 5 == 0:
            print('fizzbuzz')
        elif i % 3 == 0:
            print('fizz')
        elif i % 5 == 0:
            print('buzz')
        else:
            print(i)
        i += 1

问题 3：有序数字

实现函数 ordered_digits，它接收一个 正整数作为输入，并当True其数字从左到右 按非递减顺序排列时返回 False，否则返回 。例如，5、11、127、1357 的数字是有序的，但 21 或 1375 的数字则不是。

你的答案
解答 
def ordered_digits(x):
    """Return True if the (base 10) digits of X>0 are in non-decreasing
    order, and False otherwise.

    >>> ordered_digits(5)
    True
    >>> ordered_digits(11)
    True
    >>> ordered_digits(127)
    True
    >>> ordered_digits(1357)
    True
    >>> ordered_digits(21)
    False
    >>> result = ordered_digits(1375) # Return, don't print
    >>> result
    False
    """
    last = x % 10
    x = x // 10
    while x > 0:
        if last < x % 10:
            return False
        last = x % 10
        x = x // 10
    return True

我们从右往左依次切分出每一位数字，并将其与 上一位切分出的数字（即紧邻其右侧的那一位）进行比较。当数字 用完或者我们发现某一位顺序错乱时，就停止。

问题 4：唯一数字

编写一个函数，返回正整数中不同数字的个数。

提示：你可以利用 // 和 % 将一个正整数拆分为 它的个位数和其余部分。

你可能会发现，先定义一个函数 has_digit(n, k) 会很有帮助，该函数用于判断一个数字 n 是否包含数字 k。

你的答案
解答 
def unique_digits(n):
    """Return the number of unique digits in positive integer n.

    >>> unique_digits(8675309) # All are unique
    7
    >>> unique_digits(13173131) # 1, 3, and 7
    3
    >>> unique_digits(101) # 0 and 1
    2
    """
    unique = 0
    while n > 0:
        last = n % 10
        n = n // 10
        if not has_digit(n, last):
            unique += 1
    return unique

# 备选解法
def unique_digits_alt(n):
    unique = 0
    i = 0
    while i < 10:
        if has_digit(n, i):
            unique += 1
        i += 1
    return unique





def has_digit(n, k):
    """Returns whether k is a digit in n.

    >>> has_digit(10, 1)
    True
    >>> has_digit(12, 7)
    False
    """
    assert k >= 0 and k < 10
    while n > 0:
        last = n % 10
        n = n // 10
        if last == k:
            return True
    return False

我们提供了两种解法：

  • 在一种解法中，我们查看当前这一位数字，并检查该数 的其余部分是否包含这一位。只有当该位数字 在其余部分中不存在时，我们才认为它是唯一的。我们对每一位都这样做。
  • 在另一种解法中，我们遍历 0 到 9 的数字，并对每一个调用 has_digit。如果它返回真值，我们就知道整个数包含该 位数字，于是将唯一计数加一。

问题 5：重复序列

定义：正整数 n 是 重复序列 的正整数 m，如果 n 是由 m 的数字重复书写一次或多次得到的。例如，616161 是 61 的重复序列，但 61616 不是。

实现 repeating，它接收正整数 t 和 n。它返回 n 是否为某个 t 位整数的重复序列。

你的答案
解答 
def repeating(t, n):
    """Return whether t digits repeat to form positive integer n.

    >>> repeating(1, 6161)
    False
    >>> repeating(2, 6161)  # repeats 61 (2 digits)
    True
    >>> repeating(3, 6161)
    False
    >>> repeating(4, 6161)  # repeats 6161 (4 digits)
    True
    >>> repeating(5, 6161)  # there are only 4 digits
    False
    """
    if pow(10, t-1) > n:  # make sure n has at least t digits
        return False
    end = n % pow(10, t)
    rest = n
    while rest:
        if rest % pow(10, t) != end:
           return False
        rest = rest // pow(10, t)
    return True
实现该函数所需的迭代过程是：验证 t 的末 rest 位数字与 t 的末 n，然后去掉 t 的末 rest 位数字。
