Q1：跳过阶乘

为 skip_factorial 函数定义基准情形，该函数返回每隔一个的正整数的乘积，这些整数从 n.

你的答案
解答 
def skip_factorial(n):
    """Return the product of positive integers n * (n - 2) * (n - 4) * ...

    >>> skip_factorial(5) # 5 * 3 * 1
    15
    >>> skip_factorial(8) # 8 * 6 * 4 * 2
    384
    """
    if n <= 2:
        return n
    else:
        return n * skip_factorial(n - 2)
如果 n 是偶数，那么基准情形将是 2。如果 n 是奇数，那么基准情形将是 1。试着写一个能同时处理这两种情况的条件。

Q2：扫过

实现 swipe，它逐行打印参数 n 的各位数字，每行一个，先逆序再正序。最左边的数字只打印一次。不要使用 while 或 for 或 str。（当然要用递归！）

你的答案
解答 
def swipe(n):
    """Print the digits of n, one per line, first backward then forward.

    >>> swipe(283)
    3
    8
    2
    8
    3
    """
    if n < 10:
        print(n)
    else:
        print(n % 10)
        swipe(n // 10)
        print(n % 10)
首先 print 输出第一行，然后做递归调用，再 print 输出最后一行。

Q3：判断素数

实现 is_prime，它接收一个整数 n，该整数大于 1。它返回 True 如果 n 是素数，False 否则返回假值。请按照下面的思路来实现， 但要用递归方式实现，不要使用 while（或 for）循环。

你需要定义另一个“辅助”函数（一个仅用于 帮助实现当前函数的函数）。你在 is_prime 中定义它，还是把它作为全局帧中的一个独立函数来定义？试着把它定义成 接收尽可能少的参数。

你的答案
解答 
def is_prime(n):
    """Returns True if n is a prime number and False otherwise.
    >>> is_prime(9)
    False
    >>> is_prime(2)
    True
    >>> is_prime(16)
    False
    >>> is_prime(521)
    True
    """
    def check_all(i):
        "Check whether no number from i up to n evenly divides n."
        if i == n:      # could be replaced with i > (n ** 0.5)
            return True
        elif n % i == 0:
            return False
        return check_all(i + 1)
    return check_all(2)

Q4：递归冰雹序列

回忆一下 hailstone 函数，它来自 Homework 1.
  • 首先，选取一个正整数 n 作为起始值。如果 n 是偶数，则将其除以 2。
  • 如果 n 是奇数，则将其乘以 3 再加 1。重复这个过程，直到 n 变为 1。
  • 完成这个 hailstone 的递归版本，它打印出序列中的值并返回步数。
你的答案
解答 
def hailstone(n):
    """Print out the hailstone sequence starting at n, 
    and return the number of elements in the sequence.
    >>> a = hailstone(10)
    10
    5
    16
    8
    4
    2
    1
    >>> a
    7
    >>> b = hailstone(1)
    1
    >>> b
    1
    """
    print(n)
    if n % 2 == 0:
        return even(n)
    else:
        return odd(n)

def even(n):
    return 1 + hailstone(n // 2)

def odd(n):
    if n == 1:
        return 1
    else:
        return 1 + hailstone(3 * n + 1)
偶数永远不会是基准情形，因此 even 总是对 hailstone 做递归调用，并返回冰雹序列剩余部分长度加一的结果。

奇数可能是 1（基准情形），也可能大于 1（递归情形）。只有递归情形才应该调用 hailstone.

Q5：最大子序列

A 子序列 是指一个数字中按顺序排列的一系列数字（不一定连续）。例如，12345 有 123、234、124、245 等子序列。你的任务是找出 最大的子序列 中小于指定长度的那一个。

提示： 要将一个数字（d）添加到一个已有的数字（n）上，计算公式为：n * 10 + d。例如，要将数字 8 到 15 以得到 158，计算 15 * 10 + 8.

你的答案
解答 
def max_subseq(n, t):
    """
    Return the maximum subsequence of length at most t that can be found in the given number n.
    For example, for n = 2012 and t = 2, we have that the subsequences are
        2
        0
        1
        2
        20
        21
        22
        01
        02
        12
    and of these, the maximum number is 22, so our answer is 22.

    >>> max_subseq(2012, 2)
    22
    >>> max_subseq(20125, 3)
    225
    >>> max_subseq(20125, 5)
    20125
    >>> max_subseq(20125, 6) # note that 20125 == 020125
    20125
    >>> max_subseq(12345, 3)
    345
    >>> max_subseq(12345, 0) # 0 is of length 0
    0
    >>> max_subseq(12345, 1)
    5
    """
    if n == 0 or t == 0:
        return 0
    with_last = max_subseq(n // 10, t - 1) * 10 + n % 10
    without_last = max_subseq(n // 10, t)
    return max(with_last, without_last)

Q6：七的游戏

七的游戏：玩家们围成一圈，沿顺时针方向从 1 开始轮流报数。（起始玩家报 1，他左边的玩家报 2，依此类推。）如果某个数字能被 7 整除或含有数字 7（或两者兼具），就改变方向。数字必须按节奏在 每分钟 60 拍 的节拍上说出。如果有人在还没轮到他时报了数，或有人在轮到他时漏掉了节拍，游戏 就结束。

例如，5 个人会像下面这样数到 20：

Player 1 says 1
Player 2 says 2
Player 3 says 3
Player 4 says 4
Player 5 says 5
Player 1 says 6  # All the way around the circle
Player 2 says 7  # Switch to counterclockwise
Player 1 says 8
Player 5 says 9  # Back around the circle counterclockwise
Player 4 says 10
Player 3 says 11
Player 2 says 12
Player 1 says 13
Player 5 says 14 # Switch back to clockwise
Player 1 says 15
Player 2 says 16
Player 3 says 17 # Switch back to counterclockwise
Player 2 says 18
Player 1 says 19
Player 5 says 20

实现 sevens，它接收一个正整数 n 和 玩家数量 k。它返回 k 个玩家中由谁报出 n。你可以调用 has_seven.

解决这个问题的有效方法是模拟这个游戏，在第 n 回合时停止。 实现中必须记录以下信息：

  • 最终的数字 n
  • 当前的数字 i
  • 当前的玩家 who 将报出 i
  • 以及当前的 direction，它决定下一个玩家（递增或递减）。

用整数来表示所有这些量很合适，其中 direction 在 1 （递增）与 -1（递减）。

你的答案
解答 
def sevens(n, k):
    """Return the (clockwise) position of who says n among k players.

    >>> sevens(2, 5)
    2
    >>> sevens(6, 5)
    1
    >>> sevens(7, 5)
    2
    >>> sevens(8, 5)
    1
    >>> sevens(9, 5)
    5
    >>> sevens(18, 5)
    2
    """
    def f(i, who, direction):
        if i == n:
            return who
        if i % 7 == 0 or has_seven(i):
            direction = -direction
        who = who + direction
        if who > k:
            who = 1
        if who < 1:
            who = k
        return f(i + 1, who, direction)
    return f(1, 1, 1)

def has_seven(n):
    if n == 0:
        return False
    elif n % 10 == 7:
        return True
    else:
        return has_seven(n // 10)

首先检查 i 是否是 7 的倍数或包含数字 7，如果是，就切换 方向。然后，将方向加到 who 上，并确保 who 没有 变小到小于 1 或大于 k.
