面向对象编程（Object-oriented programming，OOP）使用对象和类来组织程序。下面是一个类的例子：

class Car:
    max_tires = 4

    def __init__(self, color):
        self.tires = Car.max_tires
        self.color = color

    def drive(self):
        if self.tires < Car.max_tires:
            return self.color + ' car cannot drive!'
        return self.color + ' car goes vroom!'

    def pop_tire(self):
        if self.tires > 0:
            self.tires -= 1

类（Class）：对象的类型。上面的 Car 类描述了所有 Car 对象的特征。

对象（Object）：类的一个单一实例。在 Python 中，调用一个类即可创建一个新的对象。

>>> ferrari = Car('red')

这里，ferrari 是一个绑定到 Car 对象的名字。

类属性（Class attribute）：属于类、通过点号表示法访问的变量。Car 类有一个 max_tires 属性。

>>> Car.max_tires
4

实例属性（Instance attribute）：属于某个特定对象的变量。每个 Car 对象都有一个 tires 属性和一个 color 属性。和类属性一样，实例属性也是通过点号表示法访问的。

>>> ferrari.color
'red'
>>> ferrari.tires
4
>>> ferrari.color = 'green'
>>> ferrari.color
'green'

方法（Method）：属于某个对象、通过点号表示法调用的函数。按照惯例，方法的第一个参数是 self。

当调用对象的方法时，该对象会被隐式地作为 self 的参数传入。例如，调用 ferrari 对象的 drive 方法时括号为空，是因为 self 被隐式地绑定到了 ferrari 对象上。

>>> ferrari = Car('red')
>>> ferrari.drive()
'red car goes vroom!'

我们也可以调用原始的 Car.drive 函数。原始函数不属于任何特定的 Car 对象，因此我们必须为 self 显式提供一个参数。

>>> ferrari = Car('red')
>>> Car.drive(ferrari)
'red car goes vroom!'

__init__：当创建一个类的新实例时，会自动调用的一个特殊函数。

注意 drive 方法接受 self 作为参数，但看起来我们并没有传入！这是因为点号表示法 隐式地将 ferrari 作为 self 传入。所以在这个例子中，self 被绑定到了 全局帧中名为 ferrari 的对象。

要对表达式 Car('red') 求值，Python 会创建一个新 Car 对象。然后，Python 调用 Car 类的 __init__ 函数，其中 self 绑定到这个新对象，color 绑定到 'red'。


树

回顾一下树的抽象数据类型：一棵树被定义为拥有一个标签和一些分支。之前，我们使用 Python 列表实现了树的抽象。让我们看看另一种使用对象来实现的方式：

class Tree:
    def __init__(self, label, branches=[]):
        for b in branches:
            assert isinstance(b, Tree)
        self.label = label
        self.branches = branches

    def is_leaf(self):
        return not self.branches

通过这种实现，我们可以使用属性赋值来修改一棵树，而这在之前使用列表的实现中是不可能的。这也是我们时而称这些对象为“可变树”的原因。

>>> t = Tree(3, [Tree(4), Tree(5)])
>>> t.label = 5
>>> t.label
5

为了避免为相似的类重复定义属性和方法，我们可以编写一个 单一的基类（base class），让更专门的类从中继承（inherit）。例如，我们可以编写一个名为 Pet 的类，并将 Dog 定义为 Pet 的一个子类（subclass）：

class Pet:
    def __init__(self, name, owner):
        self.is_alive = True    # It's alive!!!
        self.name = name
        self.owner = owner
    def eat(self, thing):
        print(self.name + " ate a " + str(thing) + "!")
    def talk(self):
        print(self.name)

class Dog(Pet):
    def talk(self):
        super().talk()
        print('This Dog says woof!')

继承表示两个或多个类之间的层次关系，其中一个类是另一个类 更具体的版本：狗是一种（is a）宠物。 （我们在面向对象编程语言中用“is a”来描述这种关系，而不是指 Python 的 is 运算符。）

由于 Dog 继承自 Pet，Dog 类也会继承 Pet 类的方法，因此我们不必重新定义 __init__ 或 eat。 我们希望每只 Dog 都以 Dog 特有的方式 talk， 因此我们可以重写（override） talk 方法。

我们可以使用 super() 来引用 self 的父类， 并像自己是父类的一个实例那样访问任何父类方法。 例如，Dog 类中的 super().talk() 会调用 Pet 类的 talk 方法，但将 Dog 实例作为 self 传入。
