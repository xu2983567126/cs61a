链表


Here is the implementation of the Link 类：

class Link:
    """A linked list is either a Link object or Link.empty

    >>> s = Link(3, Link(4, Link(5)))
    >>> s.rest
    Link(4, Link(5))
    >>> s.rest.rest.rest is Link.empty
    True
    >>> s.rest.first * 2
    8
    >>> print(s)
    (3 4 5)
    """
    empty = ()

    def __init__(self, first, rest=empty):
        assert rest is Link.empty or isinstance(rest, Link)
        self.first = first
        self.rest = rest

    def __repr__(self):
        if self.rest:
            rest_repr = ', ' + repr(self.rest)
        else:
            rest_repr = ''
        return 'Link(' + repr(self.first) + rest_repr + ')'

    def __str__(self):
        string = '('
        while self.rest is not Link.empty:
            string += str(self.first) + ' '
            self = self.rest
        return string + str(self.first) + ')'
可变链表 普通链表
特性 - Represented with custom object, Link
- Has methods and attributes
- Mutable 		- Represented with abstract data type
- Has selector functions
- Not mutable
示例 
>>> s = Link(1, Link(2, Link(3, Link(4))))
>>> s
Link(1, Link(2, Link(3, Link(4))))
>>> s.first = 9
>>> s
Link(9, Link(2, Link(3, Link(4))))

>>> s = link(1, link(2, link(3, link(4))))
>>> s
[1, [2, [3, [4, 'empty']]]]
>>> first(s) = 9
  File "", line 1
SyntaxError: can't assign to function call
解释 Link is mutable because we have created an object Link with attributes that allow direct access to the elements inside of it. This allows us to change the elements, thus mutating the Link link 不是可变的，因为它的选择器函数只向我们返回其元素的值。我们无法更改或重新赋值这些值。

第1题：添加链接

Write a function add_link that takes in two linked lists, link1 and link2, and returns a 新的 linked list that concatenates link2 to the end of link1.

你可以假设输入链表是浅层的；它的任何元素都不是另一个链表。

注意: You 可能不会 assume that the input lists are of the same length.

Challenge (Optional): Do NOT assume that the input list is shallow (i.e. your input can be a nested linked list). Hint: use the built-in type 函数。

def add_links(link1: Link, link2: Link) -> Link:
    """Adds two Links, returning a new Link

    >>> l1 = Link(1, Link(2))
    >>> l2 = Link(3, Link(4, Link(5)))
    >>> new = add_links(l1, l2)
    >>> print(new)
    (1 2 3 4 5)
    >>> new2 = add_links(l2,l1)
    >>> print(new2)
    (3 4 5 1 2)
    """

    if link1 is not Link.empty:
        return Link(link1.first, add_links(link1.rest, link2))
    elif link2 is not Link.empty:
        return Link(link2.first, add_links(link1, link2.rest))
    else:
        return Link.empty

# 迭代版本（使用 reverse）
def add_links(link1, link2):
    result = Link.empty
    while link1 is not Link.empty:
        result = Link(link1.first, result)
        link1 = link1.rest
    while link2 is not Link.empty:
        result = Link(link2.first, result)
        link2 = link2.rest
    return reverse(result)

python3 ok -q add_links

第2题：可变映射

Implement deep_map_mut(func, s), which applies the function func to each element in the linked list s. If an element is itself a linked list, recursively apply func 也作用于它的元素。

Your implementation should 改变 the original linked list. 不要创建任何新的链表。 The function returns None.

提示: You can use the built-in isinstance 函数来判断一个元素是否为链表。

>>> s = Link(1, Link(2, Link(3, Link(4))))
>>> isinstance(s, Link)
True
>>> isinstance(s, int)
False

构建检查：本题的最后一个测试用例检查你的函数没有创建任何新的链表。 如果你没有通过这个 doctest，请确保你不是通过调用构造函数来创建链表的，即

s = Link(1)
def deep_map_mut(func, s: Link) -> None:
    """Mutates a deep link s by replacing each item found with the
    result of calling func on the item. Does NOT create new Links (so
    no use of Link's constructor).

    Does not return the modified Link object.

    >>> link1 = Link(3, Link(Link(4), Link(5, Link(6))))
    >>> square = lambda x: x * x
    >>> print(link1)
    (3 (4) 5 6)
    >>> link2 = Link(1, Link(Link(Link(2, Link(3))), Link(4)))
    >>> double = lambda x: x * 2
    >>> print(link2)
    (1 ((2 3)) 4)
    >>> # Disallow the use of making new Links before calling deep_map_mut
    >>> Link.__init__, hold = lambda *args: print("Do not create any new Links."), Link.__init__
    >>> try:
    ...     deep_map_mut(square, link1)
    ...     deep_map_mut(double, link2)
    ... finally:
    ...     Link.__init__ = hold
    >>> print(link1)
    (9 (16) 25 36)
    >>> print(link2)
    (2 ((4 6)) 8)
    """

    if s is Link.empty:
        return None
    elif isinstance(s.first, Link):
        deep_map_mut(func, s.first)
    else:
        s.first = func(s.first)
    deep_map_mut(func, s.rest)

使用 Ok 测试你的代码：

python3 ok -q deep_map_mut

效率


棘手的效率例子是针对 61B 的，而不是 61A。我们只从基础层面探讨效率；例如，即使对于很大的输入，我们也将乘法和其他基本操作的运行时间视为常数。

除了将算法分类为指数、二次、线性、对数或常数级别，我们还介绍了大 Theta 记号，但不深入运行时间分析的细节。

这里有一个细微的差别：在 CS 61A 中，我们进行运行时间分析时 是相对于输入的。在后续课程中（如 61B、CS 170 等），运行时间分析是相对于 体型 (i.e. the number of bits) of the input. If this confuses you, don't worry about it too much. Just try to be consistent and tell students that we are considering how a function's runtime is affected when we change the input.

Throughout this class, we have mainly focused on 正确性 — whether a program produces the correct output. However, computer scientists are also interested in creating 高效 solutions to problems. One way to quantify efficiency is to determine how a function's 运行时间 changes as its input changes. In this class, we measure a function's runtime by the number of operations it performs.

A function f(n) 有……

  • constant runtime if the runtime of f does not depend on n。它的运行时间是 Θ(1）。
  • logarithmic runtime if the runtime of f is proportional to log(n)。它的运行时间是 Θ(log(n)）。
  • linear runtime if the runtime of f is proportional to n。它的运行时间是 Θ(n）。
  • quadratic runtime if the runtime of f is proportional to n^2。它的运行时间是 Θ(n^2）。
  • exponential runtime if the runtime of f is proportional to b^n, for some constant b。它的运行时间是 Θ(b^n）。

示例 1： It takes a single multiplication operation to compute square(1), and it takes a single multiplication operation to compute square(100). In general, calling square(n) results in a 常数 number of operations that does not vary according to n. We say square 的运行时间复杂度为 Θ(1)。

输入 函数调用 返回值 操作
1 square(1) 1*1 1
2 square(2) 2*2 1
... ... ... ...
100 square(100) 100*100 1
... ... ... ...
n square(n) n*n 1

示例 2： It takes a single multiplication operation to compute factorial(1), and it takes 100 multiplication operations to compute factorial(100). As n increases, the runtime of factorial increases 线性地. We say factorial 的运行时间复杂度为 Θ(n）。

输入 函数调用 返回值 操作
1 factorial(1) 1*1 1
2 factorial(2) 2*1*1 2
... ... ... ...
100 factorial(100) 100*99*...*1*1 100
... ... ... ...
n factorial(n) n*(n-1)*...*1*1 n

示例 3： Consider the following function:

def bar(n):
    for a in range(n):
        for b in range(n):
            print(a,b)

Evaulating bar(1) results in a single print call, while evalulating bar(100) results in 10,000 print calls. As n increases, the runtime of bar increases 二次地. We say bar 的运行时间复杂度为 Θ(n^2）。

输入 函数调用 操作（打印）
1 bar(1) 1
2 bar(2) 4
... ... ...
100 bar(100) 10000
... ... ...
n bar(n) n^2

示例 4： Consider the following function:

def rec(n):
    if n == 0:
        return 1
    else:
        return rec(n - 1) + rec(n - 1)

Evaluating rec(1) results in a single addition operation. Evaluating rec(4) results in 2^4 - 1 = 15 addition operations, as shown by the diagram below.

During the evaulation of rec(4), there are two calls to rec(3), four calls to rec(2), eight calls to rec(1), and 16 calls to rec(0).

So we have eight instances of rec(0) + rec(0), four instances of rec(1) + rec(1), two instances of rec(2) + rec(2), and a single instance of rec(3) + rec(3)，总共为 1 + 2 + 4 + 8 = 15 次加法操作。

As n increases, the runtime of rec increases 指数地. In particular, the runtime of rec approximately doubles when we increase n by 1. We say rec 的运行时间复杂度为 Θ(2^n）。

输入 函数调用 返回值 操作
1 rec(1) 2 1
2 rec(2) 4 3
... ... ... ...
10 rec(10) 1024 1023
... ... ... ...
n rec(n) 2^n 2^n - 1

寻找函数运行时间增长阶的提示：

  • 如果函数是递归的，确定递归调用的数量以及每次递归调用的运行时间。
  • 如果函数是迭代的，确定内层循环的数量以及每个循环的运行时间。
  • Ignore coefficients. A function that performs n operations and a function that performs 100 * n 操作都是线性的。
  • 选择最大的增长阶。如果一个函数的第一部分具有线性运行时间，第二部分具有二次运行时间，那么整体函数具有二次运行时间。

  • 在本课程中，我们只考虑常数、对数、线性、二次和指数级别的运行时间。

第3题：素数

写一个函数，判断一个数是否为素数，时间复杂度为 O(sqrt(n))，其中 sqrt 表示平方根。你可以假设 n >= 2。

提示： 你不需要检查每一个小于 n 的数是否能整除 n

from math import sqrt
def is_prime_sqrt(n: int) -> bool:
    """Tests whether a number N is prime or not. Implement this function
    in O(sqrt(n)) time. You can assume n >= 2

    >>> is_prime_sqrt(2)
    True
    >>> is_prime_sqrt(67092481)
    False
    >>> is_prime_sqrt(524287)
    True
    >>> is_prime_sqrt(2251748274470911)
    False
    >>> is_prime_sqrt(6700417)
    True
    >>> is_prime_sqrt(44895587973889)
    False
    >>> is_prime_sqrt(2147483647)
    True
    >>> is_prime_sqrt(67280421310721)
    True
    """
    # sqrt(k) 会给出 k 的平方根，作为浮点数（小数）

    if sqrt(n) < 2:
        return True
    for i in range(2, int(sqrt(n)) + 1):
        if n % i == 0:
            return False
    return True

使用 Ok 测试你的代码：

python3 ok -q is_prime_sqrt

Scheme


Scheme uses Polish prefix notation, in which the operator expression comes before the operand expressions. For example, to evaluate 3 * (4 + 2)，我们写： 
scm> (* 3 (+ 4 2))
18

就像在 Python 中一样，要求值一个调用表达式：

  1. 求值运算符。它应求值为一个过程。
  2. 从左向右求值操作数。
  3. 将该过程应用于已求值的操作数。

以下是一些使用内置过程的例子：

scm> (+ 1 2)
3
scm> (- 10 (/ 6 2))
7
scm> (modulo 35 4)
3
scm> (even? (quotient 45 2))
#t

The define 形式用于给符号赋值。它具有以下语法： 
(define <symbol> <expression>)
scm> (define pi (+ 3 0.14))
pi
scm> pi
3.14

To evaluate the define 表达式：

  1. 求值最后一个子表达式（<expression>), which in this case evaluates to 3.14.
  2. 将该值绑定到符号（symbol), which in this case is pi.
  3. 返回该符号。

The define 形式也可以定义新的过程，如“定义函数”一节所述。


The cond special form can include multiple predicates (like if/elif in Python):

(cond
    (<p1> <e1>)
    (<p2> <e2>)
    ...
    (<pn> <en>)
    (else <else-expression>))

The first expression in each clause is a predicate. The second expression in the clause is the return expression corresponding to its predicate. The else clause is optional; its <else-expression> 是当所有谓词都不为真时的返回表达式。

求值规则如下：

  1. Evaluate the predicates <p1>, <p2>, ..., <pn> in order until one evaluates to a true value (anything but #f）。
  2. 求值并返回与第一个为真的谓词表达式相对应的返回表达式的值。
  3. If none of the predicates evaluate to true values and there is an else clause, evaluate and return <else-expression>.

For example, this cond expression returns the nearest multiple of 3 to x:

scm> (define x 5)
x
scm> (cond ((= (modulo x 3) 0) x)
            ((= (modulo x 3) 1) (- x 1))
            ((= (modulo x 3) 2) (+ x 1)))
6

第4题：幂

Implement a procedure pow that raises a number base to the power of a nonnegative integer exp. The number of recursive pow calls should grow logarithmically with respect to exp, rather than linearly. For example, (pow 2 32) should result in 5 recursive pow calls rather than 32 recursive pow 调用。

提示：

  1. x2y = (xy)2
  2. x2y+1 = x(xy)2

例如，216 = (28)2 and 217 = 2 * (28)2.

You may use the built-in predicates even? and odd?. Also, the square 过程已经为你定义好了。

Scheme doesn't have while or for statements, so use recursion to solve this problem.

(define (square n) (* n n))

(define (pow base exp)

  (cond ((= exp 0) 1)
        ((even? exp) (square (pow base (/ exp 2))))
        (else (* base (pow base (- exp 1)))))
)

使用 Ok 测试你的代码：

python3 ok -q pow

We avoid unnecessary pow calls by squaring the result of base^(exp/2) when exp 是偶数。

The else clause, which is for odd values of exp, multiplies the result of base^(exp-1) by base.

When exp is even, computing base^exp requires one more call than computing base^(exp/2). When exp is odd, computing base^exp requires two more calls than computing base^((exp-1)/2).

So we have a logarithmic runtime for pow with respect to exp.

第5题：反复立方

Implement repeatedly-cube, which receives a number x and cubes it n 次。

Here are some examples of how repeatedly-cube 应该表现出：

scm> (repeatedly-cube 100 1) ; 1 cubed 100 times is still 1
1
scm> (repeatedly-cube 2 2) ; (2^3)^3
512
scm> (repeatedly-cube 3 2) ; ((2^3)^3)^3
134217728
(define (repeatedly-cube n x)
    (if (zero? n)
        x
        (begin

            (define y (repeatedly-cube (- n 1) x))
            (* y y y))))

使用 Ok 测试你的代码：

python3 ok -q repeatedly-cube

我们知道我们的解答必须是递归的，因为 Scheme 处理递归比处理迭代要好得多。

The provided code returns x when n is zero. This is the correct base case for repeatedly-cube；我们只需要写递归的情况。

In the recursive case, the provided code returns (* y y y), which is the cube of y. We use recursion to set y to the result of cubing x n - 1 times. Then the cube of y is the result of cubing x n 次，根据需要。

第6题：Cadr 与 Caddr

Define the procedure cadr, which returns the second element of a list. Also define caddr, which returns the third element of a list. Try writing cadr and caddr in terms of car and cdr.

(define (cddr s)
  (cdr (cdr s)))

(define (cadr s)

  (car (cdr s))
)

(define (caddr s)

  (car (cddr s))
)

The second element of a list s is the first element of the rest of s. So we define (cadr s) as the car of the cdr 的 s。

The provided cddr procedure takes a list s and returns a list that starts at the third element of s. So we define (caddr s) as the car of the cddr of s.
