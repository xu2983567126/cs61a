链表


下面是 Link 类的实现：

class Link:
    """A linked list is either a Link object or Link.empty

    >>> s = Link(3, Link(4, Link(5)))
    >>> s.rest
    Link(4, Link(5))
    >>> s.rest.rest.rest is Link.empty
    True
    >>> s.rest.first * 2
    8
    >>> print(s)
    (3 4 5)
    """
    empty = ()

    def __init__(self, first, rest=empty):
        assert rest is Link.empty or isinstance(rest, Link)
        self.first = first
        self.rest = rest

    def __repr__(self):
        if self.rest:
            rest_repr = ', ' + repr(self.rest)
        else:
            rest_repr = ''
        return 'Link(' + repr(self.first) + rest_repr + ')'

    def __str__(self):
        string = '('
        while self.rest is not Link.empty:
            string += str(self.first) + ' '
            self = self.rest
        return string + str(self.first) + ')'

效率


棘手的效率例子属于 61B 的内容，而非 61A。我们只从基础层面探讨效率；例如，即使对于很大的输入，我们也把乘法和其他基本操作的运行时间视为常数。

除了将算法分类为指数级、二次、线性、对数级或常数级之外，我们还引入了大 Theta 记号，但不深入探讨运行时间分析的细节。

这里有一点细微差别：在 CS 61A 中，我们针对输入进行运行时间分析。在后续课程（如 61B、CS 170 等）中，运行时间分析是针对输入的大小（即比特数）进行的。如果这让你感到困惑，不用太担心。只需保持一致，并告诉学生：我们考虑的是当输入改变时，函数的运行时间会受到怎样的影响。

在整个课程中，我们主要关注正确性——程序是否产生正确的输出。 然而，计算机科学家也对创建高效的解决方案感兴趣。 量化效率的一种方法是确定函数的运行时间如何随其输入的变化而变化。 在本课程中，我们通过函数执行的操作数量来衡量其运行时间。

函数 f(n) 具有……

  • 常数级运行时间：f 的运行时间不依赖于 n。其运行时间为 Θ(1)。
  • 对数级运行时间：f 的运行时间与 log(n) 成正比。其运行时间为 Θ(log(n))。
  • 线性运行时间：f 的运行时间与 n 成正比。其运行时间为 Θ(n)。
  • 二次运行时间：f 的运行时间与 n^2 成正比。其运行时间为 Θ(n^2)。
  • 指数级运行时间：对于某个常数 b，f 的运行时间与 b^n 成正比。其运行时间为 Θ(b^n)。

例 1： 计算 square(1) 需要一次乘法运算，计算 square(100) 也需要一次乘法运算。一般来说，调用 square(n) 所执行的操作数量是常数，不随 n 变化。我们说 square 的运行时间复杂度为 Θ(1)。

输入 函数调用 返回值 操作数
1 square(1) 1*1 1
2 square(2) 2*2 1
... ... ... ...
100 square(100) 100*100 1
... ... ... ...
n square(n) n*n 1

例 2： 计算 factorial(1) 需要一次乘法运算，计算 factorial(100) 需要 100 次乘法运算。随着 n 增大，factorial 的运行时间线性增长。我们说 factorial 的运行时间复杂度为 Θ(n)。

输入 函数调用 返回值 操作数
1 factorial(1) 1*1 1
2 factorial(2) 2*1*1 2
... ... ... ...
100 factorial(100) 100*99*...*1*1 100
... ... ... ...
n factorial(n) n*(n-1)*...*1*1 n

例 3： 考虑以下函数：

def bar(n):
    for a in range(n):
        for b in range(n):
            print(a,b)

计算 bar(1) 会产生一次 print 调用，而计算 bar(100) 会产生 10,000 次 print 调用。随着 n 增大，bar 的运行时间二次增长。我们说 bar 的运行时间复杂度为 Θ(n^2)。

输入 函数调用 操作数（打印次数）
1 bar(1) 1
2 bar(2) 4
... ... ...
100 bar(100) 10000
... ... ...
n bar(n) n^2

例 4： 考虑以下函数：

def rec(n):
    if n == 0:
        return 1
    else:
        return rec(n - 1) + rec(n - 1)

计算 rec(1) 会产生一次加法运算。计算 rec(4) 会产生 2^4 - 1 = 15 次加法运算，如下图所示。

在计算 rec(4) 的过程中，有两次对 rec(3) 的调用、四次对 rec(2) 的调用、八次对 rec(1) 的调用，以及 16 次对 rec(0) 的调用。

所以我们共有八次 rec(0) + rec(0)、四次 rec(1) + rec(1)、两次 rec(2) + rec(2)，以及一次 rec(3) + rec(3)，总共 1 + 2 + 4 + 8 = 15 次加法运算。

随着 n 增大，rec 的运行时间指数级增长。具体来说，当 n 增加 1 时，rec 的运行时间大约翻倍。我们说 rec 的运行时间复杂度为 Θ(2^n)。

输入 函数调用 返回值 操作数
1 rec(1) 2 1
2 rec(2) 4 3
... ... ... ...
10 rec(10) 1024 1023
... ... ... ...
n rec(n) 2^n 2^n - 1

判断函数运行时间增长量级的方法：

  • 如果函数是递归的，确定递归调用的次数，以及每次递归调用的运行时间。
  • 如果函数是迭代的，确定内层循环的次数，以及每次循环的运行时间。
  • 忽略系数。执行 n 次操作的函数与执行 100 * n 次操作的函数都是线性的。
  • 选择最大的增长量级。如果函数的第一部分运行时间为线性，第二部分为二次，则整体函数的运行时间为二次。

  • 在本课程中，我们仅考虑常数、对数、线性、二次和指数级的运行时间。

Scheme


Scheme 使用波兰前缀表示法，即运算符表达式出现在操作数表达式之前。例如，要计算 3 * (4 + 2)，我们写成： 
scm> (* 3 (+ 4 2))
18

与 Python 一样，要求值一个调用表达式：

  1. 求值运算符。它应当求值为一个过程。
  2. 从左到右求值操作数。
  3. 将过程应用于已求值的操作数。

以下是使用内置过程的一些示例：

scm> (+ 1 2)
3
scm> (- 10 (/ 6 2))
7
scm> (modulo 35 4)
3
scm> (even? (quotient 45 2))
#t

define 形式用于给符号赋值。它具有以下语法： 
(define <symbol> <expression>)
scm> (define pi (+ 3 0.14))
pi
scm> pi
3.14

要求值 define 表达式：

  1. 求值最后的子表达式（<expression>），在本例中它求值为 3.14。
  2. 将该值绑定到符号（symbol），在本例中是 pi。
  3. 返回该符号。

define 形式也可以定义新的过程，详见“定义函数”一节。


cond 特殊形式可以包含多个谓词（类似于 Python 中的 if/elif）：

(cond
    (<p1> <e1>)
    (<p2> <e2>)
    ...
    (<pn> <en>)
    (else <else-expression>))

每个子句的第一个表达式是谓词。子句中的第二个表达式是与该谓词对应的返回值表达式。else 子句是可选的；如果没有任何谓词为真，其 <else-expression> 即为返回值表达式。

求值规则如下：

  1. 按顺序求值谓词 <p1>、<p2>、…、<pn>，直到其中一个求值为真值（除 #f 以外的任何值）。
  2. 求值并返回与第一个为真值的谓词表达式相对应的返回值表达式的值。
  3. 如果没有任何谓词求值为真值，并且存在 else 子句，则求值并返回 <else-expression>。

例如，下面的 cond 表达式返回最接近 x 的 3 的倍数：

scm> (define x 5)
x
scm> (cond ((= (modulo x 3) 0) x)
            ((= (modulo x 3) 1) (- x 1))
            ((= (modulo x 3) 2) (+ x 1)))
6
