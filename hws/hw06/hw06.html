SQL 基础

示例表

下面是一个名为 big_game 的表，用于下面的示例，它记录了每年 Big Game 的比分。该表有三列：berkeley、 stanford 和 year。

CREATE TABLE big_game (
    berkeley INTEGER, stanford INTEGER, year INTEGER);

INSERT INTO big_game (berkeley, stanford, year) VALUES
    (30, 7, 2002),
    (28, 16, 2003),
    (17, 38, 2014);

你可以在 sqlite 中这样查看它：

sqlite> .mode column
sqlite> SELECT * FROM big_game;
berkeley  stanford  year
--------  --------  ----
30        7         2002
28        16        2003
17        38        2014

如果你的 sqlite 版本中 .mode column 命令不起作用，也没关系。忽略它即可。

从表中选择

通常，我们会使用一条 SELECT 语句从已有的表创建一个新的表：

SELECT [columns] FROM [tables] WHERE [condition] ORDER BY [columns] LIMIT [limit];

让我们拆解这条语句：

  • SELECT [columns] 告诉 SQL 我们想要在输出表中包含给定的列；[columns] 是逗号分隔的列名列表，可以用 * 选择所有列
  • FROM [table] 告诉 SQL 我们想要选择的列来自给定的表
  • WHERE [condition] 通过只包含值满足给定 [condition]（一个布尔表达式）的行来过滤输出表
  • ORDER BY [columns] 根据给定的逗号分隔列列表对输出表中的行进行排序；默认按升序（ASC）排列，你也可以使用 DESC 按降序排列
  • LIMIT [limit] 将输出表中的行数限制为整数 [limit]

以下是一些示例：

从 big_game 表中选择 Berkeley 的所有得分，但只包含 2002 年之后的得分：

sqlite> SELECT berkeley FROM big_game WHERE year > 2002;
28
17

选择 Berkeley 获胜年份两所学校的得分：

sqlite> SELECT berkeley, stanford FROM big_game WHERE berkeley > stanford;
30|7
28|16

选择 Stanford 得分超过 15 分的年份：

sqlite> SELECT year FROM big_game WHERE stanford > 15;
2003
2014

SQL 运算符

SELECT、WHERE 和 ORDER BY 子句中的表达式可以包含一个或多个以下运算符：

  • 比较运算符：=、>、<、<=、>=、<> 或 !=（“不等于”）
  • 布尔运算符：AND、OR
  • 算术运算符：+、-、*、/
  • 连接运算符：||

输出每年 Berkeley 得分与 Stanford 得分的比值：

sqlite> select berkeley * 1.0 / stanford from big_game;
0.447368421052632
1.75
4.28571428571429

输出两支队伍得分都超过 10 分的年份的得分总和：

sqlite> select berkeley + stanford from big_game where berkeley > 10 and stanford > 10;
55
44

输出一个只有一列一行、包含值 "hello world" 的表：

sqlite> SELECT "hello" || " " || "world";
hello world

SQL 聚合

下面是另一个示例表，这次是关于航班的：

CREATE TABLE flights (
    departure TEXT, arrival TEXT, price INTEGER);

INSERT INTO flights (departure, arrival, price) VALUES
    ('SFO', 'LAX', 97),
    ('SFO', 'AUH', 848),
    ('LAX', 'SLC', 115),
    ('SFO', 'PDX', 192),
    ('AUH', 'SEA', 932),
    ('SLC', 'PDX', 79),
    ('SFO', 'LAS', 40),
    ('SLC', 'LAX', 117),
    ('SEA', 'PDX', 32),
    ('SLC', 'SEA', 42),
    ('SFO', 'SLC', 97),
    ('LAS', 'SLC', 50),
    ('LAX', 'PDX', 89);

应用诸如 MAX(column) 这样的聚合函数 会将多行的值合并为一行输出。

默认情况下，我们合并表中所有行的值。例如，如果我们想统计 flights 表中的行数，可以使用：

sqlite> SELECT COUNT(*) from FLIGHTS;
13

如果我们想将相似行中的值分组，并在这些组内执行聚合操作，该怎么办？我们使用 GROUP BY 子句。

再举一个例子。对于每个唯一的出发地，将所有具有相同出发机场的行收集到一个组中。然后，选择 price 列并应用 MIN 聚合，得到该组中出发地最便宜的价格。最终结果是一个包含出发机场和最便宜出发航班的表。

sqlite> SELECT departure, MIN(price) FROM flights GROUP BY departure;
departure  MIN(price)
---------  ----------
AUH        932
LAS        50
LAX        89
SEA        32
SFO        40
SLC        42

就像我们可以用 WHERE 过滤行一样，我们也可以用 HAVING 过滤组。通常，HAVING 子句应当使用聚合函数。假设我们想查看所有至少有两次出发的机场：

sqlite> SELECT departure FROM flights GROUP BY departure HAVING COUNT(*) >= 2;
departure
---------
LAX
SFO
SLC

注意，COUNT(*) 聚合只是统计每组中的行数。假设我们想改为统计不同机场的数量。那么，我们可以使用以下查询：

sqlite> SELECT COUNT(DISTINCT departure) AS destinations FROM flights;
destinations
-----------
6

这列举了 flights 表中所有可用的不同出发机场（本例中为：SFO、LAX、AUH、SLC、SEA 和 LAS）。

狗狗数据

在下面的每个问题中，你将基于以下关于狗狗的表来定义一个新的表。

CREATE TABLE parents (parent TEXT, child TEXT);

INSERT INTO parents VALUES
  ('ace', 'bella'),
  ('ace', 'charlie'),
  ('daisy', 'hank'),
  ('finn', 'ace'),
  ('finn', 'daisy'),
  ('finn', 'ginger'),
  ('ellie', 'finn');

CREATE TABLE dogs (name TEXT, fur TEXT, height INTEGER);

INSERT INTO dogs VALUES
  ('ace',     'long',  26),
  ('bella',   'short', 52),
  ('charlie', 'long',  47),
  ('daisy',   'long',  46),
  ('ellie',   'short', 35),
  ('finn',    'curly', 32),
  ('ginger',  'short', 28),
  ('hank',    'curly', 31);

CREATE TABLE sizes (size TEXT, min INTEGER, max INTEGER);

INSERT INTO sizes VALUES
  ('toy',      24, 28),
  ('mini',     28, 35),
  ('medium',   35, 45),
  ('standard', 45, 60);

parents 表为每一对亲子关系包含一行；例如，第一行描述了狗狗 "ace" 是狗狗 "bella" 的父代。 dogs 表包含每只狗狗的名字、毛发类型和身高。sizes 表为每种狗狗分类包含一行。如果一只狗狗的身高大于 min 且小于或等于 max，则它属于该分类。

即使这些表中的值发生变化，你的查询也应正确运行。例如，如果要求列出所有名字以 h 开头的狗狗，你应该写成：

SELECT name FROM dogs WHERE name LIKE "h%";

% 符号匹配任意数量的字符，而 sqlite 中的模式不区分大小写，因此模式 "h%" 匹配所有以 h 或 H 开头的字符串。如果添加一行名字为 harry 的数据，该查询仍然正确。相反，写成 SELECT "hank"; 这样的查询则不行，它只适用于示例输入。

Q4：低方差

* There are no heights greater than 1.3 (i.e. 130%) of the average.
