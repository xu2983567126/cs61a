SQL 基础

示例表

Here's a table called big_game used in the examples below, which records the scores for the Big Game each year. This table has three columns: berkeley, stanford, and year.

CREATE TABLE big_game (
    berkeley INTEGER, stanford INTEGER, year INTEGER);

INSERT INTO big_game (berkeley, stanford, year) VALUES
    (30, 7, 2002),
    (28, 16, 2003),
    (17, 38, 2014);

你可以像这样在 sqlite 中查看它：

sqlite> .mode column
sqlite> SELECT * FROM big_game;
berkeley  stanford  year
--------  --------  ----
30        7         2002
28        16        2003
17        38        2014
If the .mode column 命令在你的 sqlite 版本中不起作用，没关系。忽略它即可。

从表中选择

Typically, we will create a new table from existing tables using a SELECT statement:

SELECT [columns] FROM [tables] WHERE [condition] ORDER BY [columns] LIMIT [limit];

让我们来拆解这条语句：

  • SELECT [columns] tells SQL that we want to include the given columns in our output table; [columns] is a comma-separated list of column names, and * can be used to select all columns
  • FROM [table] 告诉 SQL 我们想要选择的列来自给定的表
  • WHERE [condition] filters the output table by only including rows whose values satisfy the given [condition]，一个布尔表达式
  • ORDER BY [columns] 按照给定的以逗号分隔的列列表对输出表中的行进行排序；默认情况下，值按升序（ASC）排序，但你可以使用 DESC 按降序排序
  • LIMIT [limit] 将输出表中的行数限制为整数 [limit]

以下是一些例子：

Select all of Berkeley's scores from the big_game 表，但只包含 2002 年之后的得分：

sqlite> SELECT berkeley FROM big_game WHERE year > 2002;
28
17

选择伯克利获胜的那些年份中两所学校的得分：

sqlite> SELECT berkeley, stanford FROM big_game WHERE berkeley > stanford;
30|7
28|16

选择斯坦福得分超过 15 分的那些年份：

sqlite> SELECT year FROM big_game WHERE stanford > 15;
2003
2014

SQL 运算符

Expressions in the SELECT, WHERE, and ORDER BY 子句可以包含一个或多个以下运算符：

  • comparison operators: =, >, <, <=, >=, <> or != ("not equal")
  • boolean operators: AND, OR
  • arithmetic operators: +, -, *, /
  • concatenation operator: ||

输出每年伯克利得分与斯坦福得分的比值：

sqlite> select berkeley * 1.0 / stanford from big_game;
0.447368421052632
1.75
4.28571428571429

输出两支队伍得分都超过 10 分的那些年份的得分之和：

sqlite> select berkeley + stanford from big_game where berkeley > 10 and stanford > 10;
55
44

输出一个只有一列一行、包含值“hello world”的表：

sqlite> SELECT "hello" || " " || "world";
hello world

SQL 聚合

这是另一个示例表，这次是关于航班的：

CREATE TABLE flights (
    departure TEXT, arrival TEXT, price INTEGER);

INSERT INTO flights (departure, arrival, price) VALUES
    ('SFO', 'LAX', 97),
    ('SFO', 'AUH', 848),
    ('LAX', 'SLC', 115),
    ('SFO', 'PDX', 192),
    ('AUH', 'SEA', 932),
    ('SLC', 'PDX', 79),
    ('SFO', 'LAS', 40),
    ('SLC', 'LAX', 117),
    ('SEA', 'PDX', 32),
    ('SLC', 'SEA', 42),
    ('SFO', 'SLC', 97),
    ('LAS', 'SLC', 50),
    ('LAX', 'PDX', 89);

Applying an 聚合函数 such as MAX(column) 将多行中的值合并为一行输出。

By default, we combine the values of all rows in the table. For example, if we wanted to count the number of rows in our flights 表，我们可以使用：

sqlite> SELECT COUNT(*) from FLIGHTS;
13

What if we wanted to group together the values in similar rows and perform the aggregation operations within those groups? We use a GROUP BY 子句。

Here's another example. For each unique departure, collect all of the rows having the same departure airport into a group. Then, select the price column and apply the MIN aggregation to recover the price of the cheapest departure from that group. The end result is a table of departure airports and the cheapest departing flight.

sqlite> SELECT departure, MIN(price) FROM flights GROUP BY departure;
departure  MIN(price)
---------  ----------
AUH        932
LAS        50
LAX        89
SEA        32
SFO        40
SLC        42

Just like how we can filter out rows with WHERE, we can also filter out groups with HAVING. Typically, a HAVING 子句应该使用一个聚合函数。假设我们想看到所有至少有两次起飞的机场：

sqlite> SELECT departure FROM flights GROUP BY departure HAVING COUNT(*) >= 2;
departure
---------
LAX
SFO
SLC

Note that the COUNT(*) aggregate just counts the number of rows in each group. Say we want to count the number of 去重 机场。然后，我们可以使用以下查询：

sqlite> SELECT COUNT(DISTINCT departure) AS destinations FROM flights;
destinations
------------
6

This enumerates all the different departure airports available in our flights 表（在本例中：SFO、LAX、AUH、SLC、SEA 和 LAS）。

狗狗数据

在下面的每个问题中，你将基于以下关于狗的表定义一个新的表。

CREATE TABLE parents (parent TEXT, child TEXT);

INSERT INTO parents VALUES
  ('ace', 'bella'),
  ('ace', 'charlie'),
  ('daisy', 'hank'),
  ('finn', 'ace'),
  ('finn', 'daisy'),
  ('finn', 'ginger'),
  ('ellie', 'finn');

CREATE TABLE dogs (name TEXT, fur TEXT, height INTEGER);

INSERT INTO dogs VALUES
  ('ace',     'long',  26),
  ('bella',   'short', 52),
  ('charlie', 'long',  47),
  ('daisy',   'long',  46),
  ('ellie',   'short', 35),
  ('finn',    'curly', 32),
  ('ginger',  'short', 28),
  ('hank',    'curly', 31);

CREATE TABLE sizes (size TEXT, min INTEGER, max INTEGER);

INSERT INTO sizes VALUES
  ('toy',      24, 28),
  ('mini',     28, 35),
  ('medium',   35, 45),
  ('standard', 45, 60);

The parents table contains one row for each parent-child relationship; for example, the first row describes that the dog "ace" is the parent of the dog "bella". The dogs table contains the name, fur type, and height for each dog. The sizes table has one row for each classification of dog. A dog matches a particular classification if its height is greater than min and less than or equal to max.

Your queries should still perform correctly 即使这些表中的值 发生变化. For example, if you are asked to list all dogs with a name that starts with h，你应该写：

SELECT name FROM dogs WHERE name LIKE "h%";

The % sign matches any number of characters, and patterns in sqlite are case in-sensitive, so the pattern "h%" matches all strings that begin with h or H. This query would still be correct if a row was added with the name harry. Contrastingly, writing a query like SELECT "hank"; 则不会，并且只对示例输入有效。

第1题：按父代身高

Create a table by_parent_height that has a column of the names of all dogs that have a parent，按父代狗的身高从高到矮排序。

-- All dogs with parents ordered by decreasing height of their parent
CREATE TABLE by_parent_height AS

  SELECT child FROM parents, dogs WHERE name = parent ORDER BY height desc;

For example, finn has a parent ellie with height 35, and so should appear before ginger who has a parent finn with height 32. The names of dogs with parents of the same height should appear together in any order. For example, bella and charlie 都应该出现在末尾，但任何一个都可以在另一个之前。

For our example tables, the by_parent_height 表应该如下所示：

+----------+
| chil     |
+----------+
| hank     |
| finn     |
| ace      |
| daisy    |
| ginger   |
| bella    |
| charlie  |
+----------+

We need information from both the parents and the dogs 表。这一次，唯一合理的行是那些孩子与其父代匹配的行。最后，我们按身高降序排列结果。

第2题：狗的体型

The Fédération Cynologique Internationale classifies a standard poodle as over 45 cm and up to 60 cm. The sizes table describes this and other such classifications, where a dog must be over the min and less than or equal to the max in height to qualify as size.

Create a size_of_dogs table with two columns, one for each dog's name and another for its size.

-- The size of each dog
CREATE TABLE size_of_dogs AS

  SELECT name, size FROM dogs, sizes
    WHERE height > min AND height <= max;

The size_of_dogs 表应该如下所示：

+----------+----------+
| name     | size     |
+----------+----------+
| ace      | toy      |
| bella    | standard |
| charlie  | standard |
| daisy    | standard |
| ellie    | mini     |
| finn     | mini     |
| ginger   | toy      |
| hank     | mini     |
+----------+----------+

使用 Ok 测试你的代码：

python3 ok -q size_of_dogs

We know that at a minimum, we need information from both the dogs and sizes 表。最后，我们过滤并只保留合理的行：一个对应于我们正在考虑的狗的体型的大小。

第3题：句子

兄弟姐妹是指拥有同一父代的一对狗。创建一个表， 为每对具有相同体型分类的兄弟姐妹包含一行， 并用一列包含一句根据体型描述这对兄弟姐妹的话。

-- [Optional] Filling out this helper table is recommended
CREATE TABLE siblings AS

  SELECT a.child AS first, b.child AS second FROM parents AS a, parents AS b
    WHERE a.parent = b.parent AND a.child < b.child;

-- Sentences about siblings that are the same size
CREATE TABLE sentences AS

  SELECT "The two siblings, " || first || " and " || second || ", have the same size: " || a.size
    FROM siblings, size_of_dogs AS a, size_of_dogs AS b
    WHERE a.size = b.size AND a.name = first AND b.name = second;

Each sibling pair should appear only once in the output, and siblings should be listed in alphabetical order (e.g. "bella and charlie..." 而不是 "charlie and bella..."），如下所示：

sqlite> SELECT * FROM sentences;
The two siblings, bella and charlie, have the same size: standard
The two siblings, ace and ginger, have the same size: toy

提示：首先，创建一个辅助表，包含每对兄弟姐妹的名字。这 将在构建主表时更容易比较兄弟姐妹的体型。确保不要将孩子与自己配对，也不要包含重复的对。

提示: If you join a table with itself, use AS within the FROM 子句来给每个表一个别名。

提示: In order to concatenate two strings into one, use the || operator, e.g. SELECT "hello" || "world"; will return helloworld.

使用 Ok 测试你的代码：

python3 ok -q sentences

大致来说，我们需要在这里解决两个任务：

找出哪些狗是兄弟姐妹

兄弟姐妹是与你共享一个父代的人。这很可能涉及 parents 表。

It might be tempting to join this with dogs, but there isn't any extra information provided by a dogs table that we need at this time. Furthermore, we still need information on sibling for a given dog, since the parents 表只是将每只狗与一个个父代关联起来。

因此，下一步是通过将 parents 表与自身连接，把所有孩子与其他所有孩子匹配起来。这里唯一合理的行是代表兄弟姐妹关系的行，因为它们拥有相同的父代。

记住，我们要避免重复！如果狗 A 和 B 是兄弟姐妹，我们不希望 A/B 和 B/A 都出现在最终结果中。我们也绝对不希望 A/A 成为一对兄弟姐妹。对兄弟姐妹的名字施加顺序约束可以确保我们不会出现上述任一问题。

根据兄弟姐妹信息构建句子

After determining the siblings, constructing the sentences just requires us to get the size of each sibling. We could join on the dogs and sizes tables as we did in an earlier problem, but there's no need to redo that work. Instead, we'll reuse our size_of_dogs 表来弄清楚每对中每只兄弟姐妹的体型。

第4题：低方差

We want to create a table that contains the 身高范围 (defined as the difference between maximum and minimum height) of all dogs that share a fur type. However, we'll only consider fur types where each dog with that fur type is within 30% of the average height of all dogs with that fur type; we call this the 低方差 标准。

For example, if the average height for short-haired dogs is 10, then in order to be included in our output, all dogs with short hair must have a height 最多 13 且至少 7（包含）。

提示: MIN, MAX, and AVG 在这里会很有用。

提示：你可能想先找到平均身高并确保：

* There are no heights smaller than 0.7 (i.e. 70%) of the average.
* There are no heights greater than 1.3 (i.e. 130%) of the average.
-- Height range for each fur type where all of the heights differ by no more than 30% from the average height
CREATE TABLE low_variance AS

  SELECT fur, MAX(height) - MIN(height) AS height_range FROM dogs GROUP BY fur
      HAVING MIN(height) >= .7 * AVG(height) AND MAX(height) <= 1.3 * AVG(height);

Your output should have two columns, in this order: the fur type and the height_range for the fur 满足此标准的类型。对于示例表，它应该如下所示：

+------------+--------------+
| fur        | height_range |
+------------+--------------+
| Curly      | 1            |
+------------+--------------+

The average height of long-haired dogs is 39.7, so the low variance criterion requires the height of each long-haired dog to be between 27.8 and 51.6. However, ace is a long-haired dog with height 26, which is outside this range. For short-haired dogs, bella falls outside the valid range (check!). Thus, neither short nor long haired dogs are included in the output. There are two curly haired dogs: finn with height 32 and hank 身高 31。这给出一个高度为 1 的范围。

python3 ok -q low_variance
