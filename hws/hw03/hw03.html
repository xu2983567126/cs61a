如果你需要复习可变性相关内容，可以查看下面的下拉框。也可以 直接跳到题目，遇到问题时再回来查阅。

Python 中有些对象，例如列表和字典，是可变的（mutable）， 也就是说它们的内容或状态可以被改变。 另一些对象，例如数值类型、元组和字符串，是不可变的（immutable）， 也就是说它们一旦创建就无法再被改变。

列表最常见的两种变更操作是项赋值（item assignment）和 append 方法。

>>> s = [1, 3, 4]
>>> t = s  # 同一个列表的第二个名字
>>> t[0] = 2  # 将列表的第一个元素改为 2，s 和 t 都会受到影响
>>> s
[2, 3, 4]
>>> s.append(5)  # 将 5 添加到列表末尾，s 和 t 都会受到影响
>>> t
[2, 3, 4, 5]

还有许多其他的列表变更方法：

  • append(elem)： 将 elem 添加到列表末尾。返回 None。
  • extend(s)： 将可迭代对象 s 的所有元素添加到列表末尾。返回 None。
  • insert(i, elem)： 在索引 i 处插入 elem。如果 i 大于或等于列表的长度， 则 elem 被插入到末尾。这不会替换任何已存在的元素，而只是添加新元素 elem。返回 None。
  • remove(elem)： 移除列表中第一次出现的 elem。返回 None。 如果 elem 不在列表中则报错。
  • pop(i)： 移除并返回索引 i 处的元素。
  • pop()： 移除并返回最后一个元素。

字典也有项赋值（常用）和 pop（很少用）。

>>> d = {2: 3, 4: 16}
>>> d[2] = 4
>>> d[3] = 9
>>> d
{2: 4, 4: 16, 3: 9}
>>> d.pop(4)
16
>>> d
{2: 4, 3: 9}

如果你需要复习生成器的内容，下面的内容可能有助于理解：

我们可以通过编写生成器函数（generator function）来创建自定义的迭代器， 生成器函数返回一种特殊的迭代器，称为生成器（generator）。生成器函数的函数体中使用 yield 语句，而不是 return 语句。调用生成器函数会返回一个生成器对象，并且 不会执行函数体。

例如，考虑下面的生成器函数：

def countdown(n):
    print("Beginning countdown!")
    while n >= 0:
        yield n
        n -= 1
    print("Blastoff!")

调用 countdown(k) 会返回一个从 k 倒数到 0 的生成器对象。由于生成器是迭代器，我们可以对其结果对象调用 iter， 它会直接返回同一个对象。注意，此时函数体并未执行；没有任何内容被打印，也没有数字被输出。

>>> c = countdown(5)
>>> c
<generator object countdown ...>
>>> c is iter(c)
True

那么倒计数是如何进行的呢？同样地，由于生成器是迭代器，我们调用 next 来获取下一个元素！第一次调用 next 时， 执行从函数体的第一行开始，一直进行到遇到 yield 语句。对 yield 语句中表达式求值的结果会被返回。下面的交互会话承接上面的内容。

>>> next(c)
Beginning countdown!
5

与我们在本课程中见过的函数不同，生成器函数可以 记住自己的状态。在之后连续调用 next 时，执行会从 上一次执行的 yield 语句之后的那一行继续。与 第一次调用 next 一样，执行会一直进行到下一个 yield 语句。注意，正因为如此，Beginning countdown! 不会被再次打印。

>>> next(c)
4
>>> next(c)
3

接下来 3 次调用 next 会依次产出递减的整数，直到 0。在下一次调用时，会抛出 StopIteration 错误， 因为已经没有更多的值可以产出了（即函数体已经到达末尾，而没有遇到 yield 语句）。

>>> next(c)
2
>>> next(c)
1
>>> next(c)
0
>>> next(c)
Blastoff!
StopIteration

对 countdown 的两次独立调用会创建各自拥有独立状态的生成器对象。通常，生成器不应重启。如果你希望重置 序列，请再次调用生成器函数来创建另一个生成器对象。

>>> c1, c2 = countdown(5), countdown(5)
>>> c1 is c2
False
>>> next(c1)
5
>>> next(c2)
5

以上是上述内容的总结：

  • 一个生成器函数包含 yield 语句，并返回一个生成器对象。
  • 对生成器对象调用 iter 函数会返回同一个对象， 且不改变其当前状态。
  • 生成器函数的函数体不会被求值，直到对 生成的生成器对象调用 next。对生成器对象调用 next 函数会计算并返回其序列中的下一个对象。如果序列 已耗尽，则会抛出 StopIteration。

  • 生成器会为下一次 next 调用“记住”自己的状态。因此，

    • 第一次 next 调用的工作方式如下：

      1. 进入函数，运行直到出现 yield 的那一行。
      2. 返回 yield 语句中的值，但为将来的 next 调用记住函数的状态。

    • 之后的 next 调用工作方式如下：

      1. 重新进入函数，从上一次执行过的 yield 语句之后的那一行开始，运行到下一个 yield 语句。
      2. 返回 yield 语句中的值，但为将来的 next 调用记住函数的状态。
  • 调用生成器函数会返回一个全新的生成器对象（就像 对可迭代对象调用 iter 一样）。
  • 生成器不应重启，除非它被定义成那样。要从第一个元素重新开始 一个生成器，只需再次调用该生成器函数来创建一个新的生成器。

生成器的另一个有用工具是 yield from 语句。yield from 会从一个迭代器或可迭代对象中产出所有的值。

>>> def gen_list(lst):
...     yield from lst
...
>>> g = gen_list([1, 2, 3, 4])
>>> next(g)
1
>>> next(g)
2
>>> next(g)
3
>>> next(g)
4
>>> next(g)
StopIteration

接下来是迭代器的复习内容：

可迭代对象（iterable）是指我们可以逐一访问其元素的对象。 可迭代对象可用于 for 循环和列表推导式。可迭代对象也可以 使用 list 函数转换为列表。 到目前为止我们在 Python 中见过的可迭代对象的例子包括字符串、 列表、元组和 range。

>>> for x in "cat":
...     print(x)
c
a
t
>>> [x*2 for x in (1, 2, 3)]
[2, 4, 6]
>>> list(range(4))
[0, 1, 2, 3]

注意这里存在的抽象：给定某个可迭代对象，我们有一组 可以对其执行的定义好的操作。 在讨论中，我们将窥探抽象屏障之下，了解 可迭代对象在“幕后”是如何实现的。

在 Python 中，可迭代对象在形式上被实现为可以传入内建 iter 函数以产生一个迭代器（iterator）的对象。而迭代器是另一种类型的对象， 它可以使用 next 函数逐一产生元素。

  • iter(iterable)：返回一个遍历给定可迭代对象元素的迭代器。
  • next(iterator)：返回迭代器中的下一个元素，如果没有剩余元素则抛出 StopIteration 异常。

例如，一个数字列表是一个可迭代对象， 因为 iter 会为我们提供该序列上的迭代器，我们可以用 next 函数进行遍历：

>>> lst = [1, 2, 3]
>>> lst_iter = iter(lst)
>>> lst_iter
<list_iterator object ...>
>>> next(lst)
1
>>> next(lst)
2
>>> next(lst)
3
>>> next(lst)
StopIteration

迭代器非常简单。它只有一种获取迭代器中下一个元素的机制： next。无法对迭代器进行下标索引，也无法向后访问。一旦迭代器产出了一个元素， 除非我们将其保存下来，否则无法再次获取该元素。

注意，迭代器本身也是可迭代的：对迭代器调用 iter 只会返回同一个迭代器对象。

例如，我们可以看到对列表使用 iter 和 next 时会发生什么：

>>> lst = [1, 2, 3]
>>> next(lst)             # 对可迭代对象调用 next
TypeError: 'list' object is not an iterator
>>> list_iter = iter(lst) # 为列表创建一个迭代器
>>> next(list_iter)       # 对迭代器调用 next
1
>>> next(iter(list_iter)) # 对迭代器调用 iter 会返回其自身
2
>>> for e in list_iter:   # 耗尽 list_iter 的剩余元素
...     print(e)
3
>>> next(list_iter)       # 没有剩余元素了！
StopIteration
>>> lst                   # 原始可迭代对象不受影响
[1, 2, 3]

我们之前在课上学过的 map 和 filter 函数会返回迭代器对象。

如你所见，与自然界的树不同，树这种抽象数据类型的画法是将根画在顶部、叶子画在底部。

对于一棵树的 t：

  • 它的根标签可以是任意值，label(t) 会返回它。
  • 它的分支是树，branches(t) 返回分支的列表。
  • 可以用 tree(label(t), branches(t)) 构造出一棵相同的树。
  • 你可以调用以树为参数的函数，例如 is_leaf(t)。
  • 这就是操作树的方式。不要使用 t == x、t[0]、x in t 或 list(t) 等。
  • 无法改变一棵树（那会违反抽象屏障）。

以下是例子树 t1，它的分支 branches(t1)[1] 是 t2。

t2 = tree(5, [tree(6), tree(7)])
t1 = tree(3, [tree(4), t2])

路径（path）是一系列树，其中每一棵都是下一棵的父节点。

Q5：合并

实现 merge(incr_a, incr_b)，它接受两个元素有序的可迭代对象 incr_a 和 incr_b。 merge 按排序顺序产出 incr_a 和 incr_b 中的元素，并去除重复。 你可以假设 incr_a 和 incr_b 自身不包含重复元素，并且两者中的元素都不是 None。 你不能假设这些可迭代对象是有限的；它们中的任何一个都可能产生无限的结果流。

你可能会发现使用内建 next 函数的双参数版本很有帮助：next(incr, v) 与 next(incr) 相同，只是在 incr 耗尽元素时不抛出 StopIteration，而是返回 v。

参见 doctest 了解行为示例。

def merge(incr_a, incr_b):
    """Yield the elements of strictly increasing iterables incr_a and incr_b, removing
    repeats. Assume that incr_a and incr_b have no repeats. incr_a or incr_b may or may not
    be infinite sequences.

    >>> m = merge([0, 2, 4, 6, 8, 10, 12, 14], [0, 3, 6, 9, 12, 15])
    >>> type(m)
    <class 'generator'>
    >>> list(m)
    [0, 2, 3, 4, 6, 8, 9, 10, 12, 14, 15]
    >>> def big(n):
    ...    k = 0
    ...    while True: yield k; k += n
    >>> m = merge(big(2), big(3))
    >>> [next(m) for _ in range(11)]
